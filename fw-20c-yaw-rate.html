1. 개요 — 차체가 명령한 만큼만 돌게 한다

바퀴 속도 PID 는 바퀴마다 목표를 맞출 뿐, 한 바퀴가 걸리거나 미끄러져 차체가 틀어지는 것은 보지 못한다. 이 쪽은 자이로로 차체의 수직축 회전 속도를 재고, 명령한 회전 속도와의 차이를 좌우 목표에 Δ 로 더하는 고리를 만든다. 롤 · 피치가 있는 바닥에서도 수직축 회전을 바르게 읽도록 자세 추정(attitude.h)을 함께 넣고, 이 층이 한 일을 출력 제어 프레임 0x85 로 Pi 에 보낸다.

새로 쓰는 코드는 yaw.h · attitude.h 와 control.c 의 한 층 · 스냅숏 · CLI 다. 묶음 전체의 순서는 fw-20a §1 에 있다.

2. 원리 — 회전 속도 고리와 자세 추정

2-11. 회전 속도 되먹임 — 바퀴 속도가 아니라 차체 회전을 맞춘다

회전 속도 되먹임은 좌우 목표 속도가 뜻하는 회전 속도를 자이로로 잰 차체의 실제 회전 속도와 견주고, 그 차이만큼 좌우 목표에 반대로 보정을 더하는 층이다. 쓰는 곳은 1 kHz 루프의 목표 정리 뒤, 바퀴 반복 앞이다. 실습 H(§3-H)가 만든다.

바퀴 PID 넷은 바퀴마다 속도만 맞춘다. 차체가 어느 쪽을 보고 있는지는 모른다. 그래서 다음 경우에는 네 바퀴가 다 목표 속도로 돌아도 차체가 돈다.

  • 한 바퀴가 무언가에 걸린다 — 그 바퀴가 순간 느려지는 동안 반대쪽이 앞서 나가 차체가 틀어진다. PID 가 바퀴 속도를 되찾아도 틀어진 각은 남는다.
  • 한쪽 바퀴만 둔덕에 오른다 — 서스펜션이 없는 강체 섀시라 대각 위치의 바퀴 하중이 빠진다. 하중이 빠진 바퀴는 같은 속도로 돌아도 땅을 덜 민다.
  • 짐이 한쪽으로 쏠린다 — 무거운 쪽 바퀴가 더 큰 힘을 써야 같은 속도가 나온다. 쏠림은 가속도계에 나타나지 않는다(가속도계는 움직임만 잰다).
  • 완만하게 회전한다 — 스키드 스티어는 바퀴를 옆으로 끌며 돌기 때문에, 바퀴 속도로 계산한 것보다 덜 돈다.

① 슬립 억제와의 관계 — 상충이 아니라 순서

슬립 억제(fw-20a §2-2)는 바퀴 하나가 땅을 잡고 있는지 보고 헛도는 바퀴의 출력을 줄인다. 회전 속도 되먹임은 차체 전체가 명령만큼 도는지 보고 좌우 목표를 고친다. 평소(접지가 충분할 때)에는 슬립 억제가 쉬고 이 층은 작은 보정만 한다.

둘이 엇갈리는 것은 명령한 회전이 바닥 마찰로 낼 수 있는 것보다 클 때 한 경우다: 이 층이 좌우 차이를 키우고 → 바퀴가 미끄러지고 → 슬립 억제가 출력을 줄이고 → 이 층이 차이를 더 키운다. 그때 맞는 답은 "덜 도는 것을 받아들인다"이다. 그래서 슬립 억제가 어느 바퀴든 출력을 줄이는 동안 이 층은 적분을 멈추고, Δ 는 상한 안에 둔다. 남은 방향 오차는 바퀴가 다시 접지한 뒤 이어서 되돌리거나 바깥 고리가 맡는다.

② 치우침 · 불감대 · 끄는 조건

  • 치우침 — 자이로는 멈춰 있어도 0 이 아닌 값을 낸다. 그 값이 남으면 적분이 그것까지 쌓아 방향이 천천히 흐른다. 그래서 목표 둘이 0 이고 네 바퀴가 멈춘 상태가 YAW_STILL_MS 이어질 때마다 치우침을 저역 통과로 다시 잰다. 멈춘 직후는 차체가 흔들리므로 그 시간만큼 건너뛴다.
  • 불감대 — 치우침을 빼고도 남는 잡음 폭보다 작은 오차는 P 몫에서 0 으로 본다. Δ 가 잡음에 떨지 않게 한다. 적분에는 쓰지 않는다 — 적분이 불감대보다 느린 틀어짐까지 쌓아야 원래 방향으로 돌아온다. 잡음은 평균이 0 이라 적분에서 거의 지워지고, 남는 것은 치우침이다(위 줄).
  • 끄는 조건 — 꺼짐(yaw off) · 명령 워치독 정지 · ARMED 아님 · 지난 틱의 안전 조건 · IMU 샘플 끊김(IMU_TIMEOUT_MS) · 목표 둘이 0. 이때 Δ = 0 이고 적분을 버린다. 멈추라는 명령에서 적분을 버리므로, 다음 출발은 그때의 방향을 새 기준으로 삼는다.
받침대(바퀴를 띄운 상태)에서는 켜지 않는다

바퀴가 공중에 있으면 차체가 돌지 않으므로 ω_자이로 는 늘 0 이다. 회전 명령이 오면 오차가 줄지 않아 적분이 상한까지 차고, Δ 가 상한에 붙어 좌우 차이가 명령보다 훨씬 커진다. 그래서 부팅하면 이 층은 늘 꺼져 있고, 켜는 것은 바닥에 내린 뒤의 CLI yaw on 이다(RAM, 다시 부팅하면 꺼짐).

③ 출력 제어 프레임 0x85 — MCU 가 바꾼 것을 Pi 가 본다

Pi 는 명령(0x01)과 결과(0x81 엔코더 · 0x82 IMU)만 본다. MCU 안에서 출력을 바꾸는 층 — 이 층, 슬립 억제, 경사 가중치, 주행 불가 가공, 버팀 — 이 이번 틱에 무엇을 했는지는 보이지 않는다. 그래서 실습 H 는 계약에 TYPE_CTRL (0x85) 를 더한다.1 50 Hz 로 바퀴별 최종 목표 · 듀티 · PID 몫 · 가중치 · 슬립 억제 계수와 이 층의 명령 · 수직축 회전 속도(④) · 치우침 · Δ · 적분 몫 · 플래그, 그리고 실습 I 가 채우는 들림 여유와 그 변을 싣는다(06a §4-2 의 표). 브리지는 이것을 /mcu/control 로 내고(06 §3-4), probe 는 0.5 초에 한 줄씩 찍는다. 링크 여유가 문제될 때는 link ctrl off 로 끈다. 460800 bps 에서 링크 사용률은 14 % 에서 20 % 가 된다(06a 의 대역폭 계산).

④ 기울어진 차체에서는 z 자이로가 수직축 회전이 아니다 — 자세 추정과 수직축 회전 속도

수직축 회전 속도 ψ' 는 중력 방향을 축으로 차체가 도는 속도, 곧 지도 위에서 방향이 바뀌는 속도다. 차체가 평평하면 z 자이로와 같다. 롤 φ · 피치 θ 가 있으면 자이로의 y 축(q)과 z 축(r)이 섞여 들어온다.

ψ' = (q · sinφ + r · cosφ) / cosθ          p q r = 차체 x(앞) · y(왼쪽) · z(위) 축 자이로
예: 롤 20° 로 기운 채 수직축으로 30 °/s → r = 30 × cos20° = 28.2 °/s, ψ' = 30.0 °/s

그래서 φ · θ 가 필요하다. 이 값은 attitude.h 의 상보 필터가 낸다.2

  • 자이로로 이어 간다 — 샘플마다 φ · θ 를 각속도로 적분한다. 충격에도 흔들리지 않지만, 자이로 치우침만큼 천천히 흐른다.
  • 가속도로 천천히 바로잡는다 — 멈춰 있거나 일정하게 움직일 때 가속도계는 중력 방향을 가리킨다. 그 방향의 롤 · 피치 쪽으로 시간 상수 ATT_TAU_MS 만큼 천천히 끌어온다. 흐름을 지우는 쪽이다.
  • 가속도 크기가 1 g 에서 멀면 바로잡기를 줄인다 — 판자 쐐기에 부딪힐 때 · 급가감속 때 가속도계는 중력이 아닌 방향을 가리킨다. 크기가 ATT_ACC_DEV_LO 안이면 가중치 1, ATT_ACC_DEV_HI 밖이면 0, 사이는 직선이다. 그 순간은 자이로로만 이어 간다.

시뮬레이터(Gazebo, 한쪽 바퀴만 5 cm 판자를 넘는 직진, 방향 유지 없음, 끔 / 켬 각 3 회 평균)에서 잰 값이다. 가상봇의 크기는 아직 자리 채움값이다(바퀴 반지름 3.25 cm 가 판자 5 cm 보다 작아 롤이 약 20° 까지 튄다) — 실제 로봇의 수치가 아니라 방식 사이의 비교로 읽는다.

3. 실습

실습 H 는 바닥(09a 세팅 D)에서, fw-20b 의 실습 G 뒤에 한다. 호스트 시험은 차체가 없는 날 Mac 에서 먼저 해 둔다.

채울 자리마다 힌트 카드가 있다 — 읽는 순서

골격의 채울 자리에는 TODO(you) [T1] 처럼 번호가 붙어 있고(이 쪽은 T1 ~ T4 — yaw.h · control.c), 그 주석 안에 번호 걸음이 있다. 먼저 걸음을 보고 직접 써 본다. 막히면 "직접 채우기" 절(§3-H-3)에서 같은 번호의 힌트 카드를 연다. 카드에는 그 자리의 완결 코드와, 그 코드를 줄마다 풀어 쓴 설명이 있다. 칸은 언제나 같다: 할 일 · 완결 코드 · 코드 설명 · 쓰는 API · 흔한 실수 · 확인.

Mac 의 호스트 시험은 PASS yaw 38 cases · PASS attitude 17 cases 이고, -fsanitize=undefined,address 를 붙여도 경고와 오류가 없다. arm-none-eabi-gcc 컴파일(-c -Wall -Wextra)은 경고 0 이다. T1 · T2 는 순수 파일이라 보드 없이 Mac 에서 끝까지 채점된다. T3 · T4 는 펌웨어 빌드와 보드의 관찰로 확인한다.

붙여 넣는 것으로 끝내지 않는다 — 설명을 읽고 줄마다 "왜 이 줄이 여기 있는가"를 말할 수 있게 된 뒤, 카드를 접고 직접 친다.

/* User/Inc/Control/yaw.h - 회전 속도 되먹임: 좌우 목표 속도로 명령한 회전 속도를 자이로로 잰 차체 회전 속도에 맞춘다.
 * 순수: HAL 도 robot_params.h 도 없다 - 값은 전부 cfg 구조체로 들어온다(slope.h · mix.h 와 같은 꼴).
 * host_tests/test_yaw.c 가 이 .h 하나만으로 Mac 에서 빌드된다. 쓰는 곳은 control_step_1khz() 의 명령 가공 뒤 · 바퀴 반복 앞이다(fw-20).
 *
 *   ω_명령 = (v_R - v_L) / W                    W = 유효 트랙 폭(슬립 억제와 같은 TRACK_WIDTH_MM)
 *   e      = ω_명령 - (ω_측정 - 치우침)         [deg/s], REP-103: 반시계가 +
 *            ω_측정 = 수직축(중력 축) 회전 속도 - attitude.h 의 att_yaw_rate_dps(). 기울어진 차체의 z 자이로가 아니다
 *   Δ      = kp · e + ki · ∫e dt                ∫e 는 "명령한 방향 변화 - 실제 방향 변화" = 방향 오차 [deg]
 *   v_L'   = v_L - Δ/2,  v_R' = v_R + Δ/2       평균 속도(전진 성분)는 바뀌지 않는다
 * P 몫은 지금 생기는 회전에 맞서고, I 몫은 이미 틀어진 각도를 기억해 그만큼 되돌린다.
 * 끄는 조건(꺼짐 · ARMED 아님 · 안전 조건 · IMU 끊김 · 명령 워치독 · 정지)은 호출자가 enable 로 넘긴다 - 꺼지면 Δ = 0, 적분 리셋.
 * 슬립 억제가 동작하는 동안은 freeze_i 로 적분만 멈춘다(슬립 억제가 우선 - 마찰 한계 이상으로 밀지 않는다). */
#ifndef YAW_H
#define YAW_H
#include <stdint.h>
#include <stdbool.h>

#define YAW_RAD2DEG  57.29577951f

typedef struct {
  float    w_mm;            /* 유효 트랙 폭 W [mm]. 0 이하 = 모름 -> 고리는 늘 Δ = 0 */
  float    kp;              /* 비례 [(mm/s) / (deg/s)] */
  float    ki;              /* 적분 [(mm/s) / deg] - ∫e 의 단위가 deg 다 */
  float    i_max_deg;       /* 기억하는 방향 오차의 상한 [deg] - 큰 오차를 한 번에 되돌리려 급회전하지 않게 */
  float    delta_max_mm_s;  /* Δ 의 상한 [mm/s] - 접지를 잃은 바퀴를 끝없이 밀지 않게 */
  float    deadband_dps;    /* |e| 가 이보다 작으면 P 몫을 0 으로 본다 [deg/s] - 자이로 잡음에 Δ 가 떨지 않게. 적분에는 쓰지 않는다 */
  float    bias_alpha;      /* 정지 중 치우침 저역 통과 계수 (0..1] */
  uint32_t still_ms;        /* 정지가 이만큼 이어져야 치우침을 잰다 [ms] - 멈춘 직후의 흔들림을 빼려고 */
  uint32_t imu_timeout_ms;  /* IMU seq 가 이만큼 그대로면 끊긴 것으로 본다 [ms] */
} yaw_cfg_t;

typedef struct {
  float    i_deg;           /* ∫e = 기억하는 방향 오차 [deg] */
  float    bias_dps;        /* 자이로 치우침 [deg/s] */
  uint32_t still_cnt_ms;    /* 정지가 이어진 시간 */
  uint16_t last_seq;        /* 마지막으로 본 IMU seq */
  uint32_t seq_age_ms;      /* seq 가 그대로인 시간 */
  /* 관측용(원격 측정 0x84) - 마지막 yaw_step() 의 값 */
  float    cmd_dps;         /* ω_명령 */
  float    rate_dps;        /* ω_측정(수직축 회전 속도) - 치우침 */
  float    delta_mm_s;      /* Δ */
  bool     enabled;         /* 이번 틱에 고리가 돌았는가 */
  bool     saturated;       /* Δ 가 상한에 걸렸는가 */
  bool     frozen;          /* 적분을 멈췄는가 */
} yaw_t;

static inline float yaw_absf(float x) { return (x < 0.0f) ? -x : x; }   /* libm 없이 */

static inline void yaw_reset(yaw_t *y)   /* 적분만 버린다. 치우침 · seq 감시는 남긴다 */
{
  y->i_deg = 0.0f; y->delta_mm_s = 0.0f; y->saturated = false; y->frozen = false; y->enabled = false;
}

/* 좌우 목표 [mm/s] -> 명령 회전 속도 [deg/s]. W 를 모르면 0 */
static inline float yaw_cmd_dps(const yaw_cfg_t *c, float vl_mm_s, float vr_mm_s)
{
  if (c->w_mm <= 0.0f) { return 0.0f; }
  return (vr_mm_s - vl_mm_s) / c->w_mm * YAW_RAD2DEG;
}

/* IMU 끊김 감시. 틱마다 부른다. seq 가 바뀌면 나이를 0 으로, 0(샘플 없음)이거나 그대로면 나이를 올린다.
 * 반환: 살아 있으면 true */
static inline bool yaw_imu_fresh(yaw_t *y, const yaw_cfg_t *c, uint16_t seq, uint32_t dt_ms)
{
  if (seq != 0u && seq != y->last_seq) { y->last_seq = seq; y->seq_age_ms = 0u; }
  else if (y->seq_age_ms < 0xFFFF0000u) { y->seq_age_ms += dt_ms; }
  return (seq != 0u) && (y->seq_age_ms < c->imu_timeout_ms);
}

   *   4) e = 명령 - rate. P 몫에 쓸 e_p 는 |e| 가 불감대보다 작으면 0, 아니면 e (적분은 e 를 그대로)
   *   5) 적분 전의 값을 i_prev 에 두고, freeze_i 가 아니면 i_deg += e * dt_s 를 ±i_max_deg 로 자른다
   *   6) d = kp * e + ki * i_deg. 상한 밖이면 saturated = true, e 와 d 가 같은 쪽이면 i_deg = i_prev, d 를 상한으로
   *   7) delta_mm_s 에 d 를 남기고 돌려준다 */
  (void)y; (void)c; (void)cmd_dps; (void)gyro_dps; (void)enable; (void)freeze_i; (void)dt_s;
  return 0.0f;
}

static inline int16_t yaw_sat16(float v)   /* 반올림 + int16 범위로 자름 */
{

  if (v >  32767.0f) { return  32767; }
  if (v < -32768.0f) { return -32768; }
  return (int16_t)v;
}

/* Δ 를 좌우에 반대로 나눠 더한다. 평균은 그대로 */

{

  const float r = (float)*vr + 0.5f * delta_mm_s;

}

 *                               φ += k·w·(φ_a − φ),  k = dt / (τ + dt),  w = 가속도 크기가 1 g 에 가까울수록 1, 멀면 0

#ifndef ATTITUDE_H
#define ATTITUDE_H
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

#define ATT_DEG2RAD  0.017453292519943f
#define ATT_RAD2DEG  57.29577951308232f

typedef struct {
  float    tau_s;           /* 가속도 바로잡기의 시간 상수 [s] - 길수록 충격에 덜 흔들리고, 짧을수록 자이로 치우침을 빨리 지운다 */
  float    acc_dev_lo;      /* |a|/g − 1 의 절댓값이 이보다 작으면 가중치 1 */
  float    acc_dev_hi;      /* 이보다 크면 가중치 0 (사이는 직선) */
  float    shock_dev;       /* 충격 판정: 가속도 크기 편차 문턱 */
  float    shock_rate_dps;  /* 충격 판정: 롤 · 피치 각속도(|p| 또는 |q|) 문턱 [deg/s] */
  uint32_t shock_hold_ms;   /* 충격이 끝난 뒤에도 이만큼 shock 을 유지 [ms] */
} att_cfg_t;

typedef struct {
  float    roll_rad, pitch_rad;   /* 추정 자세 */
  bool     init;                  /* 첫 샘플에서 가속도로 바로 맞춘다 */
  float    acc_w;                 /* 마지막 가속도 가중치 (관측용) */
  bool     shock;                 /* 충격 중 (hold 포함) */
  uint32_t shock_left_ms;
} att_t;

static inline float att_clampf(float x, float lo, float hi) { return (x < lo) ? lo : ((x > hi) ? hi : x); }

static inline float att_wrap(float a)   /* (−π, π] */
{
  while (a >   3.14159265f) { a -= 6.28318531f; }
  while (a <= -3.14159265f) { a += 6.28318531f; }
  return a;
}

/* 한 샘플. 자이로 [deg/s], 가속도 [어떤 단위든, g_ref 와 같은 단위 - mg 면 1000], dt [s], dt_ms [ms].
 * 가속도가 0(샘플 없음)이면 자이로로만 이어 간다 */
static inline void att_step(att_t *a, const att_cfg_t *c, float p_dps, float q_dps, float r_dps,
                            float fx, float fy, float fz, float g_ref, float dt, uint32_t dt_ms)
{
  const float p = p_dps * ATT_DEG2RAD, q = q_dps * ATT_DEG2RAD, r = r_dps * ATT_DEG2RAD;
  const float n = sqrtf(fx * fx + fy * fy + fz * fz);
  const float dev = (g_ref > 0.0f && n > 0.0f) ? fabsf(n / g_ref - 1.0f) : 1.0f;
  const float ra = atan2f(fy, fz);
  const float pa = atan2f(-fx, sqrtf(fy * fy + fz * fz));
  if (!a->init) {
    if (n <= 0.0f) { return; }
    a->roll_rad = ra; a->pitch_rad = pa; a->init = true; a->acc_w = 1.0f;
    return;
  }
  /* 1) 자이로로 이어 간다 */
  const float sr = sinf(a->roll_rad), cr = cosf(a->roll_rad);
  const float cp = cosf(a->pitch_rad);
  const float tp = (fabsf(cp) > 1e-3f) ? sinf(a->pitch_rad) / cp : 0.0f;
  a->roll_rad  = att_wrap(a->roll_rad + (p + (q * sr + r * cr) * tp) * dt);
  a->pitch_rad = a->pitch_rad + (q * cr - r * sr) * dt;
  a->pitch_rad = att_clampf(a->pitch_rad, -1.55f, 1.55f);
  /* 2) 가속도로 천천히 바로잡는다 - 크기가 1 g 에서 멀면 가중치를 줄인다 */
  float w = 0.0f;
  if (dev <= c->acc_dev_lo) { w = 1.0f; }
  else if (dev < c->acc_dev_hi) { w = (c->acc_dev_hi - dev) / (c->acc_dev_hi - c->acc_dev_lo); }
  const float k = (c->tau_s > 0.0f) ? dt / (c->tau_s + dt) : 1.0f;
  a->acc_w = w;
  a->roll_rad  = att_wrap(a->roll_rad + k * w * att_wrap(ra - a->roll_rad));
  a->pitch_rad = a->pitch_rad + k * w * (pa - a->pitch_rad);
  /* 3) 충격 판정 - 이번 샘플이 크면 hold 를 다시 채운다 */
  const bool hit = (dev > c->shock_dev) || (fabsf(p_dps) > c->shock_rate_dps) || (fabsf(q_dps) > c->shock_rate_dps);
  if (hit) { a->shock_left_ms = c->shock_hold_ms; }
  else if (a->shock_left_ms > dt_ms) { a->shock_left_ms -= dt_ms; }
  else { a->shock_left_ms = 0u; }
  a->shock = hit || (a->shock_left_ms > 0u);
}

/* 수직축 회전 속도 [deg/s] = (q·sinφ + r·cosφ) / cosθ. 자세가 아직 없으면 r 그대로 */
static inline float att_yaw_rate_dps(const att_t *a, float q_dps, float r_dps)
{
  if (!a->init) { return r_dps; }
  const float cp = cosf(a->pitch_rad);
  if (fabsf(cp) < 1e-3f) { return r_dps; }
  return (q_dps * sinf(a->roll_rad) + r_dps * cosf(a->roll_rad)) / cp;
}

/* firmware/host_tests/test_yaw.c - 회전 속도 되먹임(yaw.h)을 Mac 에서. MCU 도 HAL 도 없다. */
#include <stdio.h>
#include "Control/yaw.h"

static int cases = 0;
#define CHECK(c) do { cases++; if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); return 1; } } while (0)
#define NEAR(a, b, t) ((a) - (b) < (t) && (b) - (a) < (t))

/* 시험용 고정값이지 권고가 아니다 */
static const yaw_cfg_t C = { 400.0f,   /* W [mm] */
                             2.0f,     /* kp [(mm/s)/(deg/s)] */
                             4.0f,     /* ki [(mm/s)/deg] */
                             10.0f,    /* i_max [deg] */
                             60.0f,    /* Δ 상한 [mm/s] */
                             0.2f,     /* 불감대 [deg/s] */
                             0.01f,    /* 치우침 계수 */
                             500u,     /* 정지 판정 [ms] */
                             50u };    /* IMU 끊김 [ms] */

int main(void)
{
  const float dt = 0.001f;
  yaw_t y = { 0 };

  /* 1. 명령 회전 속도: 좌 -100 · 우 +100, W 400 -> 0.5 rad/s = 28.648 deg/s(반시계 +). W 모름 = 0 */
  CHECK(NEAR(yaw_cmd_dps(&C, -100.0f, 100.0f), 28.6479f, 1e-3f));
  CHECK(NEAR(yaw_cmd_dps(&C, 100.0f, 100.0f), 0.0f, 1e-6f));
  { yaw_cfg_t z = C; z.w_mm = 0.0f;
    CHECK(NEAR(yaw_cmd_dps(&z, -100.0f, 100.0f), 0.0f, 1e-6f));
    CHECK(NEAR(yaw_step(&y, &z, 10.0f, 0.0f, true, false, dt), 0.0f, 1e-6f)); }

  /* 2. 직진 유지: 명령 0, 차체가 반시계로 +2 deg/s 돈다 -> e = -2 -> Δ < 0 -> 오른쪽을 줄이고 왼쪽을 올려 시계로 되돌린다 */
  yaw_reset(&y);
  { float d = yaw_step(&y, &C, 0.0f, 2.0f, true, false, dt);
    CHECK(d < 0.0f);
    CHECK(NEAR(d, 2.0f * -2.0f + 4.0f * (-2.0f * dt), 1e-4f)); }

  /* 3. 회전 추종: 반시계 명령인데 덜 돈다(회전 미끄러짐) -> Δ > 0 -> 좌우 차이를 키운다 */
  yaw_reset(&y);
  CHECK(yaw_step(&y, &C, 28.6f, 20.0f, true, false, dt) > 0.0f);

  /* 4. 불감대는 P 몫에만: |e| < 0.2 -> P 몫 0, 적분은 그대로 쌓는다(i = -0.1 x dt) */
  yaw_reset(&y);
  { const float d = yaw_step(&y, &C, 0.0f, 0.1f, true, false, dt);   /* NEAR 은 인자를 두 번 계산한다 - 먼저 받아 둔다 */
    CHECK(NEAR(d, C.ki * -0.1f * dt, 1e-6f)); CHECK(NEAR(y.i_deg, -0.1f * dt, 1e-9f)); }

  /* 5. I 는 방향 오차를 기억한다: 걸려서 0.5 s 동안 +10 deg/s 로 틀어졌다가 멈추면 i = -5 deg,
        틀어짐이 끝난 뒤(e = 0)에도 Δ = ki · i 가 남아 되돌리는 쪽으로 민다 */
  yaw_reset(&y);
  for (int k = 0; k < 500; ++k) { (void)yaw_step(&y, &C, 0.0f, 10.0f, true, false, dt); }
  CHECK(NEAR(y.i_deg, -5.0f, 1e-2f));
  { float d = yaw_step(&y, &C, 0.0f, 0.0f, true, false, dt);
    CHECK(NEAR(d, 4.0f * -5.0f, 0.05f));            /* -20 mm/s: 오른쪽 -10 · 왼쪽 +10 -> 시계로 되돌림 */
    CHECK(d < 0.0f); }
  /* 되돌아가는 동안(-10 deg/s) 오차를 갚아 i 가 0 으로 */
  for (int k = 0; k < 500; ++k) { (void)yaw_step(&y, &C, 0.0f, -10.0f, true, false, dt); }
  CHECK(NEAR(y.i_deg, 0.0f, 0.05f));

  /* 6. I 상한: 오래 틀어져도 ±10 deg 에서 멈춘다(Δ 상한 안인 동안) */
  { yaw_cfg_t wide = C; wide.delta_max_mm_s = 1000.0f;
    yaw_reset(&y);
    for (int k = 0; k < 5000; ++k) { (void)yaw_step(&y, &wide, 0.0f, 5.0f, true, false, dt); }
    CHECK(NEAR(y.i_deg, -10.0f, 1e-3f)); }

  /* 7. Δ 상한 + 조건부 적분: 상한에 걸린 채 같은 쪽 오차가 이어지면 적분이 더 자라지 않는다 */
  yaw_reset(&y);
  { float d = yaw_step(&y, &C, 0.0f, 100.0f, true, false, dt);    /* P 만 -200 -> -60 으로 자름 */
    CHECK(NEAR(d, -60.0f, 1e-4f));
    CHECK(y.saturated);
    CHECK(NEAR(y.i_deg, 0.0f, 1e-9f)); }                          /* 포화라 이번 틱 적분을 되돌렸다 */

  /* 8. 적분 동결(슬립 억제 동작 중): P 는 그대로, i 는 그대로 */
  yaw_reset(&y);
  (void)yaw_step(&y, &C, 0.0f, 2.0f, true, false, dt);
  { const float i0 = y.i_deg;
    float d = yaw_step(&y, &C, 0.0f, 2.0f, true, true, dt);
    CHECK(NEAR(y.i_deg, i0, 1e-9f));
    CHECK(y.frozen);
    CHECK(NEAR(d, 2.0f * -2.0f + 4.0f * i0, 1e-4f)); }

  /* 9. 꺼짐: Δ = 0, 적분을 버린다 */
  (void)yaw_step(&y, &C, 0.0f, 2.0f, true, false, dt);
  CHECK(NEAR(yaw_step(&y, &C, 0.0f, 2.0f, false, false, dt), 0.0f, 1e-9f));
  CHECK(NEAR(y.i_deg, 0.0f, 1e-9f));
  CHECK(!y.enabled);

  /* 10. 치우침: 정지 500 ms 뒤부터만 따라간다. 움직이면 셈을 처음부터 */
  { yaw_t b = { 0 };
    for (int k = 0; k < 400; ++k) { yaw_bias_step(&b, &C, 0.3f, true, 1u); }
    CHECK(NEAR(b.bias_dps, 0.0f, 1e-9f));                         /* 아직 정지 판정 전 */
    yaw_bias_step(&b, &C, 0.3f, false, 1u);
    CHECK(b.still_cnt_ms == 0u);
    for (int k = 0; k < 3000; ++k) { yaw_bias_step(&b, &C, 0.3f, true, 1u); }
    CHECK(NEAR(b.bias_dps, 0.3f, 1e-3f));
    /* 치우침을 뺀 뒤에는 명령 0 · 자이로 0.3 이 오차 0 이다 */
    CHECK(NEAR(yaw_step(&b, &C, 0.0f, 0.3f, true, false, dt), 0.0f, 1e-3f)); }

  /* 11. 적용: Δ = 20 -> 왼쪽 -10 · 오른쪽 +10, 평균 그대로. int16 끝에서 자른다 */
  { int16_t l = 200, r = 200;
    yaw_apply(20.0f, &l, &r);
    CHECK(l == 190 && r == 210);
    CHECK((l + r) == 400);
    l = -32760; r = 32760;
    yaw_apply(40.0f, &l, &r);
    CHECK(l == -32768 && r == 32767); }

  /* 12. IMU 끊김: seq 가 50 ms 그대로면 끊김, 바뀌면 다시 살아남. seq 0 = 샘플 없음 */
  { yaw_t m = { 0 };
    CHECK(!yaw_imu_fresh(&m, &C, 0u, 1u));
    CHECK(yaw_imu_fresh(&m, &C, 7u, 1u));
    bool f = true;
    for (int k = 0; k < 49; ++k) { f = yaw_imu_fresh(&m, &C, 7u, 1u); }
    CHECK(f);
    CHECK(!yaw_imu_fresh(&m, &C, 7u, 1u));                        /* 50 ms */
    CHECK(yaw_imu_fresh(&m, &C, 8u, 1u)); }

  /* 13. 부호 대칭: 시계 명령에서 덜 돌면 Δ < 0 */
  yaw_reset(&y);
  CHECK(yaw_step(&y, &C, -28.6f, -20.0f, true, false, dt) < 0.0f);

  /* 14. 불감대보다 느린 틀어짐도 기억한다: 0.16 deg/s 로 10 s 돌면 i = -1.6 deg -> 되돌리는 쪽 Δ < 0
         (적분까지 불감대로 0 으로 만들면 i = 0 으로 남아 끝없이 돈다) */
  yaw_reset(&y);
  for (int k = 0; k < 10000; ++k) { (void)yaw_step(&y, &C, 0.0f, 0.16f, true, false, dt); }
  CHECK(NEAR(y.i_deg, -1.6f, 1e-2f));
  CHECK(y.delta_mm_s < 0.0f);

  printf("PASS yaw %d cases\n", cases);
  return 0;
}

#include <stdio.h>
#include <math.h>
#include "Control/attitude.h"

static int cases = 0;
#define CHECK(c) do { cases++; if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); return 1; } } while (0)
#define NEAR(a, b, t) (fabsf((float)(a) - (float)(b)) < (t))

/* 시험용 고정값이지 권고가 아니다 */
static const att_cfg_t C = { 1.0f, 0.05f, 0.30f, 0.30f, 60.0f, 200u };

/* 자세 (φ, θ) 로 정지한 차체가 받는 비력 [mg] */
static void force_of(float roll_deg, float pitch_deg, float *fx, float *fy, float *fz)
{
  const float r = roll_deg * ATT_DEG2RAD, p = pitch_deg * ATT_DEG2RAD;
  *fx = -1000.0f * sinf(p);
  *fy =  1000.0f * sinf(r) * cosf(p);
  *fz =  1000.0f * cosf(r) * cosf(p);
}

/* 자세 (φ, θ) 를 유지한 채 수직축으로 ψ' [deg/s] 도는 차체의 자이로 */
static void rates_of(float roll_deg, float pitch_deg, float yaw_rate_dps, float *p, float *q, float *r)
{
  const float rr = roll_deg * ATT_DEG2RAD, pp = pitch_deg * ATT_DEG2RAD;
  *p = -yaw_rate_dps * sinf(pp);
  *q =  yaw_rate_dps * sinf(rr) * cosf(pp);
  *r =  yaw_rate_dps * cosf(rr) * cosf(pp);
}

static void run(att_t *a, int n, float roll, float pitch, float yaw_rate, float dfx)
{
  float fx, fy, fz, p, q, r;
  force_of(roll, pitch, &fx, &fy, &fz);
  rates_of(roll, pitch, yaw_rate, &p, &q, &r);
  for (int k = 0; k < n; ++k) { att_step(a, &C, p, q, r, fx + dfx, fy, fz, 1000.0f, 0.005f, 5u); }
}

힌트 T1 — yaw_step() · 고리 한 틱

할 일 — 입력은 상태 y, 설정 c, 이번 틱의 명령 회전 속도 cmd_dps 와 자이로 gyro_dps [deg/s], 켤지(enable), 적분을 멈출지(freeze_i), 틱 길이 dt_s. 출력은 좌우에 나눠 더할 Δ [mm/s]. 부르는 곳은 T13(1 kHz)과 호스트 시험.

완결 코드

/* 완결 코드 T1 - User/Inc/Control/yaw.h */
static inline float yaw_step(yaw_t *y, const yaw_cfg_t *c, float cmd_dps, float gyro_dps,
                             bool enable, bool freeze_i, float dt_s)
{
  y->cmd_dps  = cmd_dps;
  y->rate_dps = gyro_dps - y->bias_dps;
  if (!enable || c->w_mm <= 0.0f) { yaw_reset(y); return 0.0f; }
  y->enabled = true;
  y->frozen  = freeze_i;

  const float e   = cmd_dps - y->rate_dps;                         /* 적분은 이 값을 그대로 쌓는다 */
  const float e_p = (yaw_absf(e) < c->deadband_dps) ? 0.0f : e;     /* 불감대는 P 몫에만 - 적분까지 0 으로 하면 */
                                                                     /* 불감대보다 느린 틀어짐을 기억하지 못한다 */

  const float i_prev = y->i_deg;
  if (!freeze_i) {
    y->i_deg += e * dt_s;
    if (y->i_deg >  c->i_max_deg) { y->i_deg =  c->i_max_deg; }
    if (y->i_deg < -c->i_max_deg) { y->i_deg = -c->i_max_deg; }
  }

  float d = c->kp * e_p + c->ki * y->i_deg;
  y->saturated = false;
  if (d > c->delta_max_mm_s || d < -c->delta_max_mm_s) {
    y->saturated = true;
    const float lim = (d > 0.0f) ? c->delta_max_mm_s : -c->delta_max_mm_s;
    if ((e > 0.0f && d > 0.0f) || (e < 0.0f && d < 0.0f)) { y->i_deg = i_prev; }   /* 같은 쪽으로 더 쌓지 않는다 */
    d = lim;
  }
  y->delta_mm_s = d;
  return d;
}

코드 설명

  • 맨 앞의 두 줄(cmd_dps · rate_dps 남기기)은 꺼져 있어도 한다 — 0x85 로 Pi 가 "명령은 얼마였고 차체는 얼마나 돌았나"를 늘 볼 수 있게 하려는 것이다.
  • 꺼짐 · W 모름 → yaw_reset() 과 0 — 적분을 버린다. 다시 켜질 때 옛 방향 오차를 들고 오지 않는다.
  • e = cmd - rate — 덜 돌면 + 다. Δ 가 + 이면 오른쪽을 올리고 왼쪽을 내려 반시계로 더 돈다(REP-103 의 + 방향). 부호를 거꾸로 쓰면 보정이 틀어짐을 키운다(흔한 실수 첫 줄).
  • 불감대 — 작은 오차를 0 으로 바꾼 값(e_p)은 P 몫에만 쓴다. 적분은 원래 오차 e 를 쌓는다. 적분까지 0 으로 바꾸면, 적분이 남긴 Δ 가 만드는 느린 회전이 불감대 안에 들어가 고리가 그 회전을 보지 못한다 — 바퀴 간격이 넓을수록 같은 Δ 가 느린 회전이 되므로 잘 생긴다.
  • 적분은 e × dt — 단위가 deg 다. 이것이 방향 오차이고, ki 는 "방향 오차 1° 당 좌우 차이 [mm/s]" 다.
  • 상한에 걸렸을 때 오차가 Δ 와 같은 쪽이면 이번 틱의 적분을 되돌린다(조건부 적분). 막힌 쪽으로 적분이 계속 자라면, 막힘이 풀린 순간 쌓인 만큼 크게 튄다(와인드업).
  • delta_mm_s 에 남기는 값은 자른 뒤의 값이다 — 실제로 좌우에 더해지는 양.

쓰는 API — 없다(순수 함수).

힌트 T2 — yaw_bias_step() · 정지 중 치우침

할 일 — 입력은 상태 y, 설정 c, 자이로 gyro_dps, 정지인지(still — 호출자가 판정), 지난 시간 dt_ms. 이 함수는 y->bias_dps 와 정지 시간 셈을 바꾼다. 부르는 곳은 T13(IMU 가 살아 있을 때만)과 호스트 시험.

완결 코드

/* 완결 코드 T2 - User/Inc/Control/yaw.h */
static inline void yaw_bias_step(yaw_t *y, const yaw_cfg_t *c, float gyro_dps, bool still, uint32_t dt_ms)
{
  if (!still) { y->still_cnt_ms = 0u; return; }
  if (y->still_cnt_ms < c->still_ms) { y->still_cnt_ms += dt_ms; return; }
  y->bias_dps += c->bias_alpha * (gyro_dps - y->bias_dps);
}

코드 설명

  • 정지가 아니면 셈을 0 으로 — 한 번이라도 움직이면 처음부터 다시 센다. 움직이는 동안의 자이로 값은 치우침이 아니다.
  • still_ms 가 차기 전에는 더하기만 한다 — 멈춘 직후 차체가 흔들리는 동안을 건너뛴다.
  • 그 뒤로는 저역 통과 — bias += α × (gyro − bias). 정지가 이어지는 한 계속 따라가므로 온도로 치우침이 바뀌어도 다음 정지에서 다시 맞춰진다.

  s_ctrl.yaw_rate_dps   = s_yaw.rate_dps;                       /* 수직축 회전 속도 - 치우침 */
  s_ctrl.yaw_bias_dps   = s_yaw.bias_dps;
  s_ctrl.yaw_delta_mm_s = s_yaw.delta_mm_s;
  s_ctrl.yaw_i_mm_s     = s_yaw_cfg.ki * s_yaw.i_deg;           /* Δ 안의 적분 몫 */

  if (s_yaw.saturated)                { flags = (uint16_t)(flags | CONTROL_CTRL_YAW_SAT); }
  if (s_yaw.enabled && s_yaw.frozen)  { flags = (uint16_t)(flags | CONTROL_CTRL_YAW_FROZEN); }

}

void control_get_ctrl(ctrl_snapshot_t *out)   /* 1 kHz 문맥(통신 모듈) - control_step_1khz() 와 같은 ISR 안이라 찢어지지 않는다 */
{
  if (out == NULL) { return; }
  *out = s_ctrl;
}

  /* T8(fw-20b) 의 3) 과 4) 사이에 - 실습 C 의 traction_step() 호출 다음 */
  /* 3b) 회전 속도 되먹임 (실습 H). 슬립 억제가 이번 틱에 출력을 줄이고 있으면 적분만 멈춘다(슬립 억제가 우선) */

  for (uint8_t i = 0u; i < (uint8_t)NW; i++) { if (trac[i] < 1.0f) { trac_active = true; } }   /* trac = 실습 C 의 계수 배열 이름 */
  yaw_layer_step(meas, (s_wd_stopped != 0u) || !armed || (s_cond_prev != 0u), trac_active, &tl, &tr);

  /* T8(fw-20b) 의 8) 과 9) 사이에 - 출력 직전 */
  /* 8b) 0x85 스냅숏 */

  if (clamped)                      { cflags = (uint16_t)(cflags | CONTROL_CTRL_NO_GO_CLAMP); }   /* 3) 의 else if 가지에서 true 로 */

  • dt 는 1 ms(PID_DT_S) — 자이로 샘플은 5 ms 마다 새로 오지만 고리는 1 kHz 로 돌며 마지막 샘플을 쓴다. 적분은 틱의 시간으로 해야 맞다.
  • 부르는 자리 3b) — 목표 정리(주행 불가 가공 · 버팀) 뒤라서, 주행 불가 중 잘린 회전 성분을 이 층이 다시 만들지 않는다(직진 명령이므로 ω_명령 = 0, 직진 유지만 한다). 슬립 억제 뒤라서 이번 틱의 계수로 적분을 멈출 수 있다.

  • 8b) 스냅숏은 출력 직전 — 실제로 나갈 듀티와 최종 목표를 싣는다. clamped 는 T8(fw-20b) 의 3) 에서 slope_clamp_downhill() 을 부른 가지에 clamped = true; 한 줄을 더해 만든다. trac 는 실습 C 에서 붙인 계수 배열 이름으로 바꾼다.

1. 회전 속도 되먹임에서 P 만 두면 안 되고 I 가 있어야 하는 이유는? I 가 기억하는 것은 무엇인가?

P 는 지금 생기고 있는 회전 속도 오차에만 맞선다. 한 바퀴가 걸려 차체가 틀어지는 동안에는 틀어짐을 줄이지만, 걸림이 끝나 오차가 0 이 되면 보정도 0 이 되어 이미 틀어진 각은 그대로 남는다. I 는 회전 속도 오차를 시간으로 쌓는다. 쌓인 값은 "명령한 방향 변화 − 실제 방향 변화", 곧 방향 오차다. 그래서 걸림이 끝난 뒤에도 그 값만큼 보정이 남아 틀어진 각으로 되돌리고, 되돌아가는 동안 반대 오차가 쌓여 0 으로 돌아온다(§2-11, 호스트 시험 벡터 5).

2. 받침대(바퀴를 띄운 상태)에서 이 층을 켜면 회전 명령에 무슨 일이 생기는가? 그리고 그것을 막는 장치 둘은?

차체가 돌지 않으므로 자이로는 늘 0 이다. 회전 명령이 오면 오차가 줄지 않아 적분이 상한까지 차고 Δ 가 상한에 붙어, 좌우 차이가 명령보다 훨씬 커진다. 막는 장치는 (1) 부팅하면 늘 꺼져 있고 바닥에서 yaw on 으로만 켜는 것, (2) 적분 상한과 Δ 상한이다(§2-11 ②).

3. 롤 20° 로 기운 채 수직축으로 30 °/s 돌 때 z 자이로는 얼마를 읽는가? 그 값을 회전 속도 되먹임에 그대로 쓰면 무슨 일이 생기는가?

r = 30 × cos20° ≈ 28.2 °/s 다. 고리는 차체가 명령보다 덜 돈다고 보고 더 돌리려 한다. 둔덕을 넘는 동안처럼 롤 · 피치가 바뀌는 순간에는 y 축 회전이 섞여 들어와 적분한 방향이 정답에서 벗어나고, I 몫이 그 틀린 오차를 되돌리려다 오히려 더 틀어진다. 그래서 자세 추정으로 φ · θ 를 구해 ψ' = (q·sinφ + r·cosφ)/cosθ 를 쓴다(§2-11 ④).
