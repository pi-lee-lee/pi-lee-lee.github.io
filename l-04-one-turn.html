1. 개요 — 흐름을 바퀴로 자르고, 바퀴를 파일로 남긴다

l-03 까지는 점 하나가 옳은지만 물었다. 점 하나에 담긴 것은 방향과 거리뿐이고, 점 하나만으로는 "내 앞이 어떻게 생겼는가"를 물을 수 없다. 방의 모양은 한 바퀴가 다 모였을 때 비로소 생긴다. 그래서 이 쪽의 일은 둘이다 — 어디서 자를 것인가를 정하는 일, 그리고 자른 것을 다시 읽을 수 있게 적어 두는 일이다.

둘째 일이 첫째보다 덜 중요해 보이지만 그렇지 않다. 실제 센서만 가지고는 두 번 측정하면 두 번 다 다른 숫자가 나와서, 값이 달라졌을 때 내 코드가 바뀐 건지 방이 바뀐 건지 구별할 수 없다(§2-5). 그리고 이 파일 한 장이 있으면 라이다가 없는 날에도 이 파일 하나로 뒤의 다섯 쪽을 진행할 수 있다.

새로 나오는 용어를 먼저 한 줄씩 정해 둔다. 용어를 섞어 쓰면 뒤에서 서로 다른 값을 혼동한다 — 특히 아래 첫 세 줄은 서로 다른 세 가지다.

2. 원리 — 왜 한 바퀴가 경계이고, 왜 이 형식이라야 하는가

2-1. 한 바퀴는 어떻게 알아보는가 — 단서는 둘이고, 쓰는 것은 하나다

센서는 "여기서 한 바퀴가 끝났다"고 따로 알려 주지 않는다. 대신 단서가 둘 있다.

  • 기기가 보내는 단서 — Start Flag. 데이터시트는 이 라이다(Slamtec RPLIDAR A1M8)의 제조사 문서이고, 이 가이드는 rev.2.2 와 v3.0 두 판을 함께 읽는다(두 판의 차이는 l-01). 데이터시트의 점 형식 그림은 점 하나에 담긴 값 넷을 Distance · Heading · Quality · Start Flag 로 적는다.1 Start Flag 의 설명은 "Flag of a new scan" 이다. 바로 다음 그림은 점의 흐름 위에 그 플래그를 하나 그리고 "A new scan" 이라 표시한다.2 우리 도구에서 이 플래그는 l-03 의 NodeStream::feed() 가 붙이는 넷째 칸 start 다.
  • 각도 값에서 얻는 단서 — 각도의 되감김. 각도가 계속 커지다가 갑자기 작아지면 한 바퀴가 넘어간 것이다. 플래그 값을 전혀 쓰지 않아도 판정할 수 있다.

이 쪽은 플래그를 쓰고, 되감김은 검산으로만 쓴다. 이유는 둘이다 — ① 플래그는 기기가 선언한 것이고 되감김은 내가 추론한 것이다. 우리는 이미 l-03 에서 같은 비트로 프레이밍을 검사했다. 프레이밍은 바이트 흐름에서 점 하나가 어디서 시작하는지 정하는 규칙이다. 그래서 플래그를 그대로 받아들여도 새로 검증해야 할 가정이 늘지 않는다. ② 되감김 판정은 문턱이 필요하다("얼마나 작아져야 되감김인가"). 각도 간격이 고르지 않으면(§2-4) 그 문턱이 곧 내가 정해야 할 또 하나의 값이 된다. 플래그를 쓰면 이 문턱을 정하지 않아도 된다.

플래그를 쓰기로 하면 세는 방법이 곧 정해진다. 한 바퀴는 어떤 플래그부터 다음 플래그 직전까지다. 이 정의에서 다음 셋이 따라 나온다.

여기서 정해지는 것 셋 — §3-1 의 골격이 이 셋을 그대로 불변식으로 적는다
  • 플래그 N 개 → 완전한 바퀴 N−1 개. N 개가 아니다. 이 개수를 틀리면 점/회전이 한 개 분량만큼 낮게 나온다.
  • 첫 플래그 이전의 점은 바퀴가 아니다. 포트를 열었을 때 스캔은 이미 어딘가를 돌고 있었으므로, 맨 앞 조각은 바퀴의 일부다. 그 조각을 한 바퀴로 세면 점 수가 아무 값이나 나온다.
  • 마지막 플래그 이후의 점도 바퀴가 아니다. 읽기를 멈춘 순간 진행 중이던 바퀴다. 같은 이유로 버린다.

⚠ 같은 모델에서 다르게 한 예가 있다. 1세대는 이 프로젝트 이전에 같은 부품 일부로 만든 첫 로봇이고, 같은 모델의 라이다를 썼다(같은 개체인지는 확인되지 않았다). 1세대의 자체 도구는 플래그를 만날 때마다 지금까지 모은 점을 한 바퀴로 묶는다.3 그래서 그 도구가 내놓는 첫 "바퀴"는 조각이다. 어느 쪽이 옳다는 이야기가 아니다. 1세대 도구는 3바퀴를 받아 점을 한 덩어리로 쓰는 용도라 조각이 섞여도 결과가 달라지지 않았다. 이 쪽은 바퀴마다 점 수를 세는 것이 목적이라 달라진다. 중요한 것은 "내 도구가 지금 무엇을 세고 있는지 내가 아는가"다. 내 도구가 세는 것을 화면에서 직접 확인하는 실습이 실습 E 다.

2-2. 회전당 점 수는 센서가 정한 값이 아니라 결과다

"이 라이다는 한 바퀴에 점이 몇 개인가"에는 답이 없다. 세 값이 한 식으로 묶여 있고, 그중 둘이 각각 다른 것에 달려 있기 때문이다.

 점/초  =  점/회전  ×  회전수(Hz)          ←  이 셋 중 둘을 재면 나머지가 나온다

 점/초    ← 선이 나를 수 있는 양과 모드가 정한다 (한 점에 몇 바이트를 쓰는가)
 회전수   ← 모터에 걸린 전압과 부하가 정한다     (사양은 범위로만 적혀 있다)
 점/회전  ← 위 둘의 나눗셈. 센서 안에 이런 상수는 없다

데이터시트의 성능 표가 세 행을 각각 다음과 같이 적는다.4

  • Sample Duration typical 0.125 ms
  • Sample Frequency typical ≥8000 Hz(주기 0.125 ms) · max 8010 Hz
  • Scan Rate min 1 · typical 5.5 Hz(주기 약 182 ms) · max 10 Hz

회전수가 하나의 값이 아니라 범위로 적혀 있다는 것이 핵심이다. 같은 센서가 상황에 따라 다른 속도로 돈다는 뜻이고, 그래서 점/회전도 따라 달라진다.

그리고 사양의 샘플 주파수가 곧 내 회선으로 오는 점 수는 아니다. 한 점이 5바이트인 지금 방식(legacy SCAN)에서는 회선 용량의 상한 11 520 B/s(l-01 §2-2)가 샘플 주파수보다 먼저 점 수를 제한한다. 그 상한이 정확히 얼마이고 왜 모드가 여럿인지는 이 쪽이 논증하지 않는다 — l-05 가 산수로 도출한다. 이 쪽이 하는 일은 내 기기에서 실제로 몇 개가 오는지를 세어 두는 것이고, l-05 는 그 숫자를 받아서 "내 도구가 이 센서의 몇 분의 일을 쓰고 있는가"를 판정한다.

그러니 점/회전이 고정값이 아니면(§2-2) 각도 간격도 고정값이 아니다. 데이터시트도 이 사실을 조건과 함께 적어 두었다. 데이터시트 성능 표의 Angular Resolution 행은 typical ≤1 Degree 이고, 같은 행의 Comments 열이 "5.5Hz scan rate" 다.6 바로 아래 Scan Rate 행의 Comments 열은 조건을 더 구체적으로 적는다 — "Typical value is measured when RPLIDAR A1 takes 360 samples per scan". 즉 "≤1°"는 "한 바퀴에 360 점일 때"라는 조건 위의 값이고, 360 ÷ 360 = 1.000° 다. 조건을 빼면 이 숫자는 아무 뜻이 없다.

2-4. 간격이 고른가 — 중앙값과 σ, 그리고 이 숫자가 무엇에 대한 근거인가

§2-3 의 360 ÷ 점/회전 은 평균적인 간격이다. 실제로 이웃한 두 점이 언제나 그만큼 떨어져 있는지는 전혀 다른 질문이고, 그 답은 나눗셈으로 나오지 않는다 — 재야 한다.

재는 방법은 이렇다. 한 바퀴의 점을 각도로 정렬한 다음 이웃끼리 뺀다. 그러면 점 수보다 하나 적은 간격이 나오는데, 한 바퀴는 원이므로 하나가 더 있다 — 마지막 점에서 첫 점으로 돌아오는 간격이다.

2-5. 왜 파일로 남기는가 — 같은 입력에 같은 답을 요구할 수 있어야 도구를 의심할 수 있다

실제 센서만 가지고 도구를 고치면 이런 일이 벌어진다. 코드를 한 줄 고치고 다시 실행했더니 숫자가 달라졌다. 고친 것이 효과가 있었던 걸까, 아니면 그 사이에 누가 지나간 걸까? 알 방법이 없다. 두 번 실행하면 두 번 다 입력이 다르기 때문이다.

파일 한 장을 저장해 두면 그 질문의 답이 확정된다. 같은 파일에 다른 답이 나왔다면 바뀐 것은 내 코드뿐이다. 이것이 뒤의 여덟 쪽이 전부 파일을 입력으로 쓰는 이유다.

자기시험 벡터(§3-1-3)와는 역할이 다르다. 벡터는 내가 만든 다섯 줄이라 내가 상상한 경우만 다룬다. 파일은 내 방을 잰 기록이라 내가 상상하지 못한 것이 들어 있다 — 갑자기 비는 섹터, 이상하게 가까운 점, 한 바퀴만 유난히 점이 적은 구간. 둘 다 필요하다.

그래서 형식에 머리 줄이 하나 붙는다. source 가 없는 파일은 내 기기에 대한 판정 근거로 쓸 수 없다. 내가 직접 기록한 것인지, 남의 기록을 빌린 것인지, /scan 에서 받은 것인지에 따라 그 파일이 증명할 수 있는 것이 전혀 다르기 때문이다.

2-6. 못 잰 방향을 무엇으로 적는가 — LaserScan 이 inf 와 NaN 을 고정한 것과 같은 종류의 결정

기준 형식의 모양은 l-00 §2-3 에 이미 있다. l-00 이 설명하지 않고 남겨 둔 것이 하나 있다 — 못 잰 방향을 0 도 inf 도 아닌 null 로 적는 이유다. 이 쪽이 그 이유를 확정한다. 물음은 표기가 세 가지 있다는 것이 아니라, 왜 이 표기라야 뒤의 쪽들이 오류 없이 틀린 값을 내지 않는가다.

판단 기준을 먼저 정한다. 세 표기 중 어느 것도 더 정확하지 않다 — 셋 다 "못 쟀다"를 적을 수는 있다. 갈리는 축은 하나뿐이다.

2-6-1. 그러면 LaserScan 은 왜 반대로 골랐는가 — 고를 수 있는 것이 달랐다

sensor_msgs/msg/LaserScan 의 ranges 는 고정 폭 실수 배열이다. 배열의 한 칸은 반드시 실수 하나를 담아야 하고, "비어 있음"이라는 칸은 존재할 수 없다. 그러니 그 규약에서 null 은 선택지가 아니었다 — 실수 중에서 골라야 했고, 그래서 inf 와 NaN 을 규약으로 고정했다.

그 선택의 대가는 우리 표의 둘째 행 그대로다. 걸러 내는 코드가 없으면 오류 없이 틀린 값이 나온다. 그래서 받는 쪽 코드가 그 처리를 대신 한다. 07 §1-1 은 이 값들을 "물체가 없다"가 아니라 "측정 실패" 라고 정해 두었다. 07 §3-10 의 C++ 노드는 inf · NaN 을 걸러 내는 줄을 따로 갖고 있다. 규약이 막지 못하는 값을 받는 쪽 코드가 매번 걸러 내는 구조다.

같은 종류의 결정이라는 것

둘 다 "못 쟀다"를 어떻게 적을지 한 번 정해 고정했다. 다른 것은 고를 수 있는 것의 폭이었다 — 고정 폭 실수 배열에는 null 이 없고, 한 줄짜리 JSON 에는 있다. 그래서 답이 갈렸다.

여기서 가져갈 것은 "우리 쪽이 낫다"가 아니다. 메시지 형식이 왜 한 번 정하면 바꾸기 어려운가다. 이 형식에 필드를 하나 더하고 싶으면 C++ 로더(정본, scan_io.hpp)와 파이썬 편의 로더(view/scanfile.py)를 같이 고쳐야 한다 — 읽는 쪽 둘이 이 쪽부터 실제로 있다(§3-4). 읽는 쪽이 둘뿐인데도 그렇다. LaserScan 은 읽는 쪽이 수천 개다.

그래서 이 변환을 어디서 하는가가 중요해진다. mm → m 과 0 → null 은 파일에 쓰는 함수가 아니라 TurnSplitter::push() 안에서 일어난다. 파일에 쓰는 함수의 시험(왕복 시험, §3-4-2)은 받은 값을 그대로 적었는가만 본다 — 단위가 맞는지는 보지 않는다. 그래서 변환을 쓰는 함수에 두고 한 글자를 놓치면 형식은 멀쩡하고 왕복도 맞는데 값이 1000배 틀린 파일이 나온다. 그래도 l-08 부터 l-16 까지 어느 쪽 코드도 오류를 내지 않는다. 변환을 push() 에 두면 test_turn 의 벡터 1이 그 실수를 바로 찾아낸다.

// One point of the revolution being built, already converted: a in degrees, r in metres
// (empty = could not measure), q raw. Kept together so that sorting moves all three.
struct TurnPoint {
  double a;
  std::optional<double> r;
  long q;
};

// Nodes in, revolutions out -- l-03's NodeStream one level up.
// Invariants -- every one of these is graded by a vector in tests/test_turn.cpp:
//   1. A revolution runs from one start flag up to (not including) the next one.
//      N start flags therefore produce N-1 Scans, never N.
//   2. Nodes seen BEFORE the first start flag are a fragment, not a revolution: drop
//      them. Nodes after the last start flag are the revolution still in progress:
//      push() never returns it.
//   3. mm -> m here (divide by 1000), and mm == 0 -> empty r here. NOT at save time:
//      a writer that converts would write a well-formed file that is wrong by a factor
//      of 1000, and every page from l-08 on would read it without complaining.
//   4. Inside a Scan the points come out in ASCENDING angle, with r and q moved along
//      with their own angle. The stream is roughly ascending already, but "roughly" is
//      not the format (2-6), and the gap statistics of 3-2 are only defined on a sorted list.
//   5. A node whose angle is not in [0, 360) is outside the format -- drop it. l-03 2-2
//      showed the field is 15 bits and reaches 511.98 when a shift is wrong.
// The Scan that push() returns has t empty: a pure function has no clock.
class TurnSplitter {
 public:
  // Feed one node. -> the revolution that this node's start flag CLOSES, or nullopt.
  std::optional<Scan> push(const Node& p) {
    // TODO(you) [T1]: close the revolution on a start flag, then keep the node - hint card T1
    //   1) if p.start: when a start was seen before (started_), sort pts_ by angle with ONE
    //      std::stable_sort on the TurnPoint vector (r and q move with their angle), copy
    //      it into a Scan and keep that Scan to return. Then started_ = true, clear pts_.
    //      The flag comes BEFORE the point: the node with start == true belongs to the NEW
    //      revolution, not to the one it just closed.
    //   2) no start flag seen yet -> return (the fragment of invariant 2)
    //   3) angle outside [0, 360) -> return without keeping the node (invariant 5)
    //   4) keep TurnPoint{deg, r, quality}: r = mm / 1000.0, left empty when mm == 0 (invariant 3)
    //   5) return the Scan of step 1, or nullopt
    //   Delete the placeholder lines below when you start.
    (void)p;
    return std::nullopt;
  }

  bool started() const { return started_; }  // has a start flag been seen yet

 private:
  bool started_ = false;
  std::vector<TurnPoint> pts_;
};

// All nodes at once -> every COMPLETE revolution. Given in full: it only runs push().
// The tests call this; the recorder calls push() itself, so that it can read the clock
// the moment a revolution comes out.
inline std::vector<Scan> split_turns(const std::vector<Node>& pts) {
  TurnSplitter splitter;
  std::vector<Scan> out;
  for (const Node& p : pts) {
    if (std::optional<Scan> s = splitter.push(p)) out.push_back(std::move(*s));
  }
  return out;

// [(a, r, q), ...] -- r prints "none" for an empty optional.
std::string shape(const std::vector<Scan>& scans) {
  std::string s = "[";
  for (std::size_t i = 0; i < scans.size(); ++i) {

}

/* 완결 코드 T1 - scripts/lidar_lab/include/lidar_lab/turn.hpp (TurnSplitter::push) */
std::optional<Scan> push(const Node& p) {
  std::optional<Scan> done;
  if (p.start) {
    if (started_) {
      std::stable_sort(pts_.begin(), pts_.end(),
                       [](const TurnPoint& x, const TurnPoint& y) { return x.a < y.a; });
      Scan s;
      for (const TurnPoint& tp : pts_) {
        s.a.push_back(tp.a);
        s.r.push_back(tp.r);
        s.q.push_back(tp.q);
      }
      done = std::move(s);
    }
    started_ = true;
    pts_.clear();
  }
  if (!started_) return done;                        // fragment before the first flag
  if (!(p.deg >= 0.0 && p.deg < 360.0)) return done;  // outside the format
  std::optional<double> r;
  if (p.mm != 0.0) r = p.mm / 1000.0;                // 0 mm = could not measure
  pts_.push_back(TurnPoint{p.deg, r, static_cast<long>(p.quality)});
  return done;
}

코드 설명

  • std::optional<Scan> done; — 돌려줄 값을 빈 채로 먼저 만든다. 플래그를 처리한 뒤에도 이 점을 담는 일이 남아 있으므로, 바퀴를 닫자마자 return 하지 않는다.
  • if (p.start) { … } — 플래그를 점보다 먼저 본다. 플래그가 붙은 점은 새 바퀴의 첫 점이므로, 앞 바퀴를 닫은 뒤에 담아야 한다(불변식 1).
  • if (started_) { … } — 첫 플래그에는 닫을 바퀴가 없다. 그 전의 점은 아래 if (!started_) return done; 이 이미 버렸다.

  • std::stable_sort(pts_.begin(), pts_.end(), …); — 셋째 인자는 람다다. 람다는 그 자리에서 만든 이름 없는 함수다. 여기서는 [](const TurnPoint& x, const TurnPoint& y) { return x.a < y.a; } 가 "앞에 올 것"을 정하는 비교 규칙이다.

    원소가 TurnPoint 하나이므로 a 로 정렬하면 r · q 가 따라 움직인다(불변식 4). stable_sort 는 각도가 같은 점들의 도착 순서를 바꾸지 않는다.

  • Scan s; for (…) { s.a.push_back(tp.a); … } — 정렬된 점을 Scan 의 세 벡터로 옮긴다. 세 벡터의 길이가 같아진다.
  • done = std::move(s); — std::move 는 내용을 복사하지 않고 옮긴다. 벡터 셋을 한 번 더 복사하지 않는다.
  • started_ = true; pts_.clear(); — 새 바퀴를 빈 목록으로 시작한다.
  • if (!started_) return done; — 첫 플래그 전의 점은 앞 조각이다. 담지 않는다(불변식 2). 이때 done 은 늘 비어 있다.
  • if (!(p.deg >= 0.0 && p.deg < 360.0)) return done; — 형식 밖의 각도는 버린다(불변식 5). 버려도 이 점이 닫은 바퀴(done)는 그대로 돌려준다. !(… && …) 꼴은 NaN 도 버린다 — NaN 과의 비교는 모두 거짓이다.
  • std::optional<double> r; if (p.mm != 0.0) r = p.mm / 1000.0; — 빈 optional 에서 시작해 잰 값만 넣는다. 0 mm 는 "못 쟀다"이므로 비운 채 둔다(불변식 3).
  • pts_.push_back(TurnPoint{p.deg, r, static_cast<long>(p.quality)}); — Node::quality 는 int, Scan::q 는 long 이라 형을 밝혀 바꾼다.

namespace lidar_lab {

namespace detail {

// s as a JSON string literal: quotes, backslash and control characters escaped.
// Everything else -- UTF-8 included -- is written as it is. The loader below refuses
// \uXXXX escapes, so this writer never produces one.
inline std::string json_str(const std::string& s) {
  std::string out = "\"";
  for (char c : s) {
    switch (c) {
      case '"': out += "\\\""; break;
      case '\\': out += "\\\\"; break;
      case '\n': out += "\\n"; break;
      case '\r': out += "\\r"; break;
      case '\t': out += "\\t"; break;
      case '\b': out += "\\b"; break;
      case '\f': out += "\\f"; break;
      default:
        if (static_cast<unsigned char>(c) < 0x20) {
          out += ' ';  // other control characters: the loader has no escape for them
        } else {
          out += c;
        }
    }
  }
  return out + "\"";
}

}  // namespace detail

// The head line {"meta": {...}} of l-00 2-3. Keys in the order of l-00 2-3 first
// (model, firmware, mode, source, date, unit, note), then any other key alphabetically.
inline std::string meta_line(const Meta& meta) {
  static const char* const kOrder[] = {"model", "firmware", "mode", "source", "date", "unit", "note"};
  std::string out = "{\"meta\": {";
  bool first = true;
  auto add = [&](const std::string& k, const std::string& v) {
    out += (first ? "" : ", ") + detail::json_str(k) + ": " + detail::json_str(v);
    first = false;
  };
  for (const char* k : kOrder) {
    auto it = meta.find(k);
    if (it != meta.end()) add(it->first, it->second);
  }
  for (const auto& kv : meta) {
    bool listed = false;
    for (const char* k : kOrder) listed = listed || kv.first == k;
    if (!listed) add(kv.first, kv.second);
  }
  return out + "}}";
}

std::string stamps(const std::vector<Scan>& v) {

    s += (i ? ", " : "") + std::string(b);

}

  std::string s;
  for (std::size_t i = 0; i < v.size(); ++i) s += (i ? " | " : "") + v[i];
  return s.empty() ? "(nothing)" : s;
}

/* 완결 코드 T2 - scripts/lidar_lab/include/lidar_lab/turn_port.hpp */
inline std::vector<Scan> record(int fd, double seconds) {
  using clock = std::chrono::steady_clock;
  NodeStream ns;
  TurnSplitter splitter;
  std::vector<Scan> scans;
  std::optional<clock::time_point> t0;
  stream(fd, seconds, ns, [&](const Node& p) {
    std::optional<Scan> s = splitter.push(p);
    if (s) {
      const clock::time_point now = clock::now();  // the revolution ENDED now
      if (!t0) t0 = now;
      s->t = std::chrono::duration<double>(now - *t0).count();
      print_turn(static_cast<int>(scans.size()) + 1, *s);
      scans.push_back(std::move(*s));
    }
    return true;  // keep reading; stream() stops on the time limit and on Ctrl-C
  });
  std::printf("accepted %zu nodes, rejected %zu boundaries\n", ns.accepted(), ns.rejected());
  return scans;
}

코드 설명

  • using clock = std::chrono::steady_clock; — 시스템 시각을 고쳐도 거꾸로 가지 않는 시계다(l-01 의 count_bytes() 와 같다). 간격을 잴 때는 이 시계를 쓴다.
  • NodeStream ns; TurnSplitter splitter; — 바이트 → 점(l-03 T2) → 바퀴(T1) 의 두 단이다.
  • std::optional<clock::time_point> t0; — 빈 값 = 아직 바퀴가 없다. 첫 바퀴가 나온 시각을 기준으로 삼는다.
  • stream(fd, seconds, ns, [&](const Node& p) { … }); — l-03 의 전량 함수가 읽기 고리를 실행한다. [&] 는 람다가 바깥 변수(splitter · scans · t0)를 참조로 쓰게 한다.
  • const clock::time_point now = clock::now(); — push() 가 값을 돌려준 그 순간이 바퀴가 끝난 순간이다. 시계를 여기서 읽어야 그 순간이 적힌다.
  • if (!t0) t0 = now; — 첫 바퀴의 시각을 기준으로 정한다. 이 줄이 없으면 다음 줄의 *t0 가 빈 값을 꺼낸다(흔한 실수).
  • s->t = std::chrono::duration<double>(now - *t0).count(); — 두 시각의 차를 초 단위 double 로 바꾼다. s->t 는 (*s).t 와 같다.
  • print_turn(static_cast<int>(scans.size()) + 1, *s); · scans.push_back(std::move(*s)); — 번호는 1 부터 센다. 찍은 뒤에 옮긴다 — 옮긴 뒤의 *s 는 비어 있다.
  • return true; — 계속 읽는다. stream() 은 시간이 다 되거나 Ctrl-C 를 받으면 자동으로 돌아온다(l-03).
  • std::printf("accepted %zu nodes, rejected %zu boundaries\n", …) — §3-1-4 표 첫 행의 판정 재료다. %zu 는 std::size_t 를 찍는 서식이다.
  • 골격의 자리표시 세 줄은 지웠다.

  • 다르게 써도 되는 곳 — 시간 대신 바퀴 수로 멈추기다. 람다에서 scans.size() 가 원하는 수에 닿으면 false 를 돌려준다. 그 수가 넷보다 크면 시험도 통과한다(return scans.size() < 10; 로 확인했다).

    기준을 stream() 을 부르기 직전 시각으로 잡는 방법은 다르게 쓴 것이 아니라 틀린 것이다. 형식은 "첫 바퀴가 0.0"(l-00 §2-3)이고, 시험의 3번이 첫 t 를 본다(흔한 실수).

쓰는 API — stream(fd, seconds, ns, on_node)(point_port.hpp, l-03)는 세 경우에 돌아온다. seconds 가 지났을 때 · 정지 신호를 받았을 때 · on_node 가 false 를 돌려줬을 때다. on_node 의 타입은 std::function<bool(const Node&)> 이므로 람다는 bool 을 돌려줘야 한다. clock::now() · std::chrono::duration<double>(d).count()(<chrono>).

3-2-3. 직접 채우기

  1. 간격을 먼저 모은다. 한 바퀴 안에서 이웃끼리 빼고, 마지막 하나(랩 간격)를 잊지 않는다(§2-4). 바퀴가 여럿이면 전부 한 벡터에 모은다 — 바퀴마다 따로 중앙값을 내는 것이 아니다.
  2. 중앙값과 σ 를 직접 쓴다. 정의는 §2-4 의 표에 있다. 통계 라이브러리를 쓰지 않는다 — 중앙값은 std::sort 뒤 가운데를 고르고, σ 는 합 → 평균 → 편차 제곱의 합 → N 으로 나누기 → std::sqrt 차례로 쓴다. σ 를 N 으로 나눌지 N−1 로 나눌지는 직접 써 봐야 의식하게 된다. 벡터는 N 으로 계산돼 있다.
  3. 점이 하나뿐인 바퀴를 어떻게 다룰지 정한다. 간격이 하나도 안 나오는 바퀴다. 0으로 나누지 않고 그냥 건너뛰면 된다 — 벡터 10이 이 경우만 검사한다.

  4. gap_max 를 어떻게 할지 내가 정한다. 큰 간격을 버리면 "센서가 제대로 잰 구간에서 얼마나 고른가"를 재는 것이고, 안 버리면 "한 바퀴 전체가 얼마나 고른가"를 재는 것이다. 둘은 다른 질문이고 답도 다르다.

    이 가이드는 값을 정해 주지 않는다. 문턱을 ____ 로 두고 왜 그 값인지 한 줄을 노트에 적는다. 같은 모델을 쓴 1세대 도구는 0 < 간격 < 5° 만 남겼다.14 그 5° 는 그 기기·그 모드에서 고른 값이지 내 값이 아니다. 방법은 빌리고 숫자는 내가 정한다. 정한 값은 src/turn.cpp 의 kGapMax 에 적는다(지금은 std::nullopt = 아무것도 버리지 않는다).

완결 코드

/* 완결 코드 T3 - scripts/lidar_lab/include/lidar_lab/turn.hpp */
inline TurnStats turn_stats(const std::vector<Scan>& scans, std::optional<double> gap_max = std::nullopt) {
  auto median = [](std::vector<double> v) -> std::optional<double> {
    if (v.empty()) return std::nullopt;
    std::sort(v.begin(), v.end());
    const std::size_t m = v.size() / 2;
    return v.size() % 2 ? v[m] : (v[m - 1] + v[m]) / 2.0;
  };
  TurnStats st;
  st.turns = static_cast<int>(scans.size());
  std::vector<double> counts, gaps;
  for (const Scan& s : scans) {
    st.points.push_back(static_cast<int>(s.size()));
    counts.push_back(static_cast<double>(s.size()));
    if (s.size() < 2) continue;                           // no gap at all
    for (std::size_t i = 1; i < s.size(); ++i) gaps.push_back(s.a[i] - s.a[i - 1]);
    gaps.push_back(s.a.front() + 360.0 - s.a.back());     // the wrap gap
  }
  if (gap_max) {
    gaps.erase(std::remove_if(gaps.begin(), gaps.end(), [&](double g) { return g > *gap_max; }),
               gaps.end());
  }
  st.points_median = median(counts);
  st.gap_median = median(gaps);
  if (!gaps.empty()) {
    double sum = 0.0, sq = 0.0;
    for (double g : gaps) sum += g;
    const double mean = sum / static_cast<double>(gaps.size());
    for (double g : gaps) sq += (g - mean) * (g - mean);
    st.gap_sigma = std::sqrt(sq / static_cast<double>(gaps.size()));
  }
  return st;
}

코드 설명

  • auto median = [](std::vector<double> v) -> std::optional<double> { … }; — 함수 안의 작은 함수(람다)다. 인자를 값으로 받으므로 정렬해도 바깥의 벡터는 그대로다. -> std::optional<double> 는 돌려주는 타입을 밝힌다. 람다 안의 return 이 둘(std::nullopt 와 double 값을 고르는 식)이라, 밝히지 않으면 컴파일러가 타입을 하나로 정하지 못한다.
  • v.size() % 2 ? v[m] : (v[m - 1] + v[m]) / 2.0 — 개수가 홀수면 한가운데, 짝수면 가운데 둘의 평균(§2-4 의 정의). m = v.size() / 2 는 정수 나눗셈이다.
  • st.points.push_back(static_cast<int>(s.size())); — 바퀴마다 점 수. counts 는 같은 값을 double 로 모아 중앙값에 넣는다.
  • if (s.size() < 2) continue; — 점이 하나인 바퀴는 간격이 없다(벡터 10). 이 줄이 없으면 아래의 랩 간격이 a[0] + 360 - a[0] = 360 하나를 만든다(흔한 실수).
  • gaps.push_back(s.a[i] - s.a[i - 1]); · gaps.push_back(s.a.front() + 360.0 - s.a.back()); — 이웃 간격, 그리고 원을 한 바퀴 돌아오는 랩 간격. 정렬은 T1 이 이미 했다.
  • gaps.erase(std::remove_if(…), gaps.end()); — remove_if 는 조건에 맞는 원소를 뒤로 밀고 새 끝을 돌려준다. erase 가 그 뒤를 실제로 지운다. 두 단계가 한 관용구다. [&] 로 gap_max 를 참조한다.
  • if (!gaps.empty()) { … } — 간격이 없으면 σ 를 계산하지 않는다. 0 으로 나누지 않고, gap_sigma 는 빈 값으로 남는다.
  • sum / N → 평균, (g - mean) * (g - mean) 의 합 / N → 분산, std::sqrt → σ. N 으로 나눈다(모집단 σ).
  • 골격의 자리표시 세 줄은 지웠다.
  • 다르게 써도 되는 곳 — 중앙값을 std::nth_element 로 고르면 전체 정렬보다 빠르다. 짝수 개일 때 가운데 둘을 모두 찾아야 하므로 코드가 조금 길어진다. 바퀴 하나에 수백 개라 이 쪽에서는 차이가 없다.

쓰는 API — std::sort(first, last) · std::remove_if(first, last, pred)(<algorithm>), std::sqrt(<cmath>). 셋 다 turn.hpp 머리에서 이미 include 했다.

3-4-2. 골격 — 쓰는 쪽은 골격, 읽는 쪽은 전량

쓰는 쪽과 읽는 쪽을 다르게 제공하는 데는 이유가 있다. 쓰기가 틀리면 파일 하나가 틀리고, 읽기가 틀리면 뒤의 모든 쪽이 오류 없이 틀린 값을 낸다. 그래서 읽는 쪽은 아래에 전량으로 주고, 대신 검사하게 만들었다 — 이 로더를 통과한 파일은 §2-6 이 고정한 성질을 지킨다는 것이 보장된다.

쓰는 쪽의 골격은 §3-1-4 에서 이미 붙였다 — scan_io.hpp 의 save_jsonl()(T4)이다. 시각은 그보다 앞에서 record()(T2)가 찍는다. push() 는 순수해서 시각을 찍을 수 없기 때문이다(§3-1-2). 그래서 순수한 두 헤더는 시계 없이 시험되고, 바퀴의 시각(t)을 찍는 곳은 turn_port.hpp 의 record() 하나다.

왜 로더가 이렇게 긴가

C++ 표준 라이브러리에는 JSON 을 읽는 기능이 없다. 이 프로젝트는 이 한 가지를 위해 외부 라이브러리를 늘리지 않는다 — 늘리면 Pi 호스트와 컨테이너(l-06 의 기록 노드) 양쪽에 같은 라이브러리를 설치하고 판을 맞춰야 한다.

그래서 첫 블록은 한 줄짜리 JSON 만 처리하는 작은 읽개다. 일반 JSON 라이브러리가 아니다 — 지원하지 않는 입력이 나오면 추측하지 않고 예외를 던진다. 예외를 던지는 것이 읽개를 짧게 유지하는 방법이다.

\u 이스케이프도 거부한다. note 에 한글을 적어도 된다 — save_jsonl() 은 UTF-8 글자를 그대로 쓴다. 다만 한글을 \uXXXX 로 적은 파일(파이썬 json.dump 의 기본 꼴)은 읽지 않는다. 오류 없이 통과시키면 깨진 글자로 읽히기 때문이다.

아래 로더 블록 둘은 전량 제공이고, 길어서 접어 두었다. 형식이 §2-6 으로 고정돼 있기 때문에 전량으로 줄 수 있다(형식을 학습자가 정하는데 로더를 전량으로 주면 그 둘은 동시에 성립하지 않는다). 집필자가 정상 파일을 읽는 것부터, §3-4-4 의 여섯 가지 고장 파일이 각각 어느 줄에서 거부되는지까지 확인했다.15

namespace lidar_lab {

namespace detail {

// A tiny JSON reader for ONE line. It is deliberately not a general library: it knows
// null / true / false / number / string / array / object and nothing else, and it
// THROWS on anything it does not understand rather than guessing.
struct Json {
  enum Kind { Null, Bool, Num, Str, Arr, Obj } kind = Null;
  double num = 0.0;
  bool bol = false;
  std::string str;                               // Str, and the raw text of a Num
  std::vector<Json> arr;                         // Arr
  std::vector<std::pair<std::string, Json>> obj; // Obj, in file order

  const Json* find(const std::string& key) const {
    for (const auto& kv : obj) { if (kv.first == key) return &kv.second; }
    return nullptr;
  }
};

class Reader {
public:
  explicit Reader(const std::string& text) : s_(text) {}

  Json parse_line() {
    Json v = value();
    ws();
    if (i_ != s_.size()) { fail("trailing text after the JSON value"); }
    return v;
  }

private:
  const std::string& s_;
  std::size_t i_ = 0;

  [[noreturn]] void fail(const std::string& why) const {
    throw std::runtime_error("column " + std::to_string(i_ + 1) + ": " + why);
  }
  void ws() { while (i_ < s_.size() && (s_[i_] == ' ' || s_[i_] == '\t' || s_[i_] == '\r')) { ++i_; } }
  char peek() const { return i_ < s_.size() ? s_[i_] : '\0'; }
  bool eat(char c) { ws(); if (peek() == c) { ++i_; return true; } return false; }
  void expect(char c) { if (!eat(c)) { fail(std::string("expected '") + c + "'"); } }

  bool literal(const char* word) {
    std::size_t n = 0; while (word[n]) { ++n; }
    if (s_.compare(i_, n, word) != 0) { return false; }
    i_ += n; return true;
  }

  Json value() {
    ws();
    char c = peek();
    if (c == '{') { return object(); }
    if (c == '[') { return array(); }
    if (c == '"') { Json v; v.kind = Json::Str; v.str = string(); return v; }
    if (literal("null")) { return Json(); }
    if (literal("true")) { Json v; v.kind = Json::Bool; v.bol = true; return v; }
    if (literal("false")) { Json v; v.kind = Json::Bool; v.bol = false; return v; }
    return number();
  }

  Json object() {
    Json v; v.kind = Json::Obj;
    expect('{');
    if (eat('}')) { return v; }
    for (;;) {
      ws();
      if (peek() != '"') { fail("object key must be a string"); }
      std::string key = string();
      expect(':');
      v.obj.emplace_back(key, value());
      if (eat(',')) { continue; }
      expect('}');
      return v;
    }
  }

  Json array() {
    Json v; v.kind = Json::Arr;
    expect('[');
    if (eat(']')) { return v; }
    for (;;) {
      v.arr.push_back(value());
      if (eat(',')) { continue; }
      expect(']');
      return v;
    }
  }

  std::string string() {
    expect('"');
    std::string out;
    while (i_ < s_.size()) {
      char c = s_[i_++];
      if (c == '"') { return out; }
      if (c != '\\') { out.push_back(c); continue; }
      if (i_ >= s_.size()) { break; }
      char e = s_[i_++];
      switch (e) {
        case '"': out.push_back('"'); break;
        case '\\': out.push_back('\\'); break;
        case '/': out.push_back('/'); break;
        case 'b': out.push_back('\b'); break;
        case 'f': out.push_back('\f'); break;
        case 'n': out.push_back('\n'); break;
        case 'r': out.push_back('\r'); break;
        case 't': out.push_back('\t'); break;
        default: fail("unsupported escape in a string");   // \uXXXX included: we refuse
      }
    }
    fail("string is not closed");
  }

  Json number() {
    std::size_t start = i_;
    const char* begin = s_.c_str() + i_;
    char* end = nullptr;
    double d = std::strtod(begin, &end);
    if (end == begin) { fail("not a JSON value"); }
    i_ += static_cast<std::size_t>(end - begin);
    Json v; v.kind = Json::Num; v.num = d; v.str = s_.substr(start, i_ - start);
    return v;
  }
};

}  // namespace detail

}  // namespace lidar_lab

fail() 이 열 번호를 같이 적는다는 것에 주목한다. 한 줄이 4 000자를 넘는 파일에서 "JSON 이 아니다"만 나오면 어디를 볼지 알 수 없다. value() 의 마지막 줄이 number() 인 것은 남은 것이 수뿐이라는 뜻이고, 수가 아니면 number() 안에서 예외를 던진다. std::strtod 를 쓰므로 1e-3 도 -0.0 도 그대로 읽힌다.

namespace lidar_lab {

// Read a .scan.jsonl file -> the revolutions it holds. When meta_out is not null the
// head line is copied into it. Throws std::runtime_error naming the LINE on any file
// that breaks the format -- six refusals, because a quietly wrong file makes every page
// after it quietly wrong. The numbers (1)..(6) are the rows of the table in 3-4-2.
inline std::vector<Scan> load_jsonl(const std::string& path, Meta* meta_out = nullptr) {
  std::ifstream in(path);
  if (!in) { throw std::runtime_error(path + ": cannot open"); }

  std::vector<Scan> scans;
  bool have_meta = false;
  std::string line;
  for (std::size_t ln = 1; std::getline(in, line); ++ln) {
    const std::string where = "line " + std::to_string(ln) + ": ";
    while (!line.empty() && (line.back() == '\r' || line.back() == ' ')) { line.pop_back(); }
    if (line.empty()) { continue; }

    detail::Json row;
    try {
      row = detail::Reader(line).parse_line();
    } catch (const std::exception& e) {
      throw std::runtime_error(where + "not JSON (" + e.what() + ")");
    }
    if (row.kind != detail::Json::Obj) { throw std::runtime_error(where + "not a JSON object"); }

    // (1) the head line is not optional: a file with no source cannot be used later
    //     as evidence about MY device.
    if (!have_meta) {
      const detail::Json* m = row.find("meta");
      if (m == nullptr || m->kind != detail::Json::Obj) {
        throw std::runtime_error("line 1 must be the head line: {\"meta\": {...}}");
      }
      Meta meta;
      for (const auto& kv : m->obj) {
        const detail::Json& v = kv.second;
        if (v.kind == detail::Json::Bool) { meta[kv.first] = v.bol ? "true" : "false"; }
        else if (v.kind == detail::Json::Null) { meta[kv.first] = "null"; }
        else { meta[kv.first] = v.str; }   // Str: the text; Num: the text as written
      }
      for (const char* k : {"source", "unit", "date"}) {
        if (meta.find(k) == meta.end()) {
          throw std::runtime_error(std::string("line 1: meta is missing \"") + k + "\"");
        }
      }
      // (2) the unit is fixed by the format. "mm" here would divide every later page by 1000.
      if (meta["unit"] != "m") {
        throw std::runtime_error("line 1: unit is \"" + meta["unit"] + "\", the format fixes \"m\"");
      }
      if (meta_out != nullptr) { *meta_out = meta; }
      have_meta = true;
      continue;
    }

    const detail::Json* ja = row.find("a");
    const detail::Json* jr = row.find("r");
    if (ja == nullptr || jr == nullptr ||
        ja->kind != detail::Json::Arr || jr->kind != detail::Json::Arr) {
      throw std::runtime_error(where + "a and r must both be lists");
    }
    // (3) a and r are index-paired. Different lengths means some point wears another
    //     point's angle, and nothing downstream can notice.
    if (ja->arr.size() != jr->arr.size()) {
      throw std::runtime_error(where + "len(a)=" + std::to_string(ja->arr.size()) +
                               " but len(r)=" + std::to_string(jr->arr.size()));
    }
    const detail::Json* jn = row.find("n");
    // The sign test comes BEFORE the cast: converting a negative double to an unsigned
    // integer is undefined behaviour, and || evaluates left to right.
    if (jn == nullptr || jn->kind != detail::Json::Num || !(jn->num >= 0.0) ||
        static_cast<std::size_t>(jn->num) != ja->arr.size()) {
      throw std::runtime_error(where + "n disagrees with len(a)=" + std::to_string(ja->arr.size()));
    }
    // (6) t is a number. The recorder stamps it; split_turns() is pure and cannot.
    const detail::Json* jt = row.find("t");
    if (jt == nullptr || jt->kind != detail::Json::Num) {
      throw std::runtime_error(where + "t is not a number -- the recorder did not stamp it");
    }

    Scan sc;
    sc.t = jt->num;
    sc.a.reserve(ja->arr.size());
    double prev = -1.0;
    for (std::size_t i = 0; i < ja->arr.size(); ++i) {
      const detail::Json& e = ja->arr[i];
      // (5) angles live in [0, 360). 360.0 is outside the format on purpose.
      if (e.kind != detail::Json::Num || !(e.num >= 0.0) || !(e.num < 360.0)) {
        throw std::runtime_error(where + "a[" + std::to_string(i) + "] is outside [0, 360)");
      }
      // (4) and they ascend.
      if (e.num < prev) {
        throw std::runtime_error(where + "a[" + std::to_string(i) + "] breaks ascending order");
      }
      prev = e.num;
      sc.a.push_back(e.num);
    }

    sc.r.reserve(jr->arr.size());
    for (std::size_t i = 0; i < jr->arr.size(); ++i) {
      const detail::Json& e = jr->arr[i];
      // A range is a number or null. null -> empty optional: "could not measure".
      if (e.kind == detail::Json::Null) { sc.r.push_back(std::nullopt); continue; }
      if (e.kind != detail::Json::Num) {
        throw std::runtime_error(where + "r[" + std::to_string(i) + "] is neither a number nor null");
      }
      sc.r.push_back(e.num);
    }
    const detail::Json* jq = row.find("q");
    if (jq != nullptr && jq->kind == detail::Json::Arr) {
      if (jq->arr.size() != ja->arr.size()) {
        throw std::runtime_error(where + "q has " + std::to_string(jq->arr.size()) +
                                 " entries, a has " + std::to_string(ja->arr.size()));
      }
      for (const detail::Json& e : jq->arr) { sc.q.push_back(static_cast<long>(e.num)); }
    }
    scans.push_back(std::move(sc));
  }
  if (!have_meta) { throw std::runtime_error(path + " is empty: there is no head line"); }
  return scans;
}

}  // namespace lidar_lab

주석의 (1) ~ (6) 이 §3-4-4 의 거부 표와 같은 번호다. 머리 줄은 첫 줄이라야 하고, continue 로 다음 줄로 넘어가므로 바퀴로 세지 않는다. a[] 를 읽는 고리 안에 (5) 범위와 (4) 오름차순이 따로 있다 — 둘을 한 줄로 합치면 어느 조건을 어겼는지 메시지로 구분할 수 없다.

// scripts/lidar_lab/src/scancheck.cpp -- run the loader on one file and print its verdict.
// (l-04, given in full)
//   pi$ scripts/lidar_lab/build/lab_scancheck scripts/lidar_lab/scans/<name>.scan.jsonl
//   ok <n> revolutions          exit 0
//   error: <the loader's text>  exit 1
// No port, no clock: it only reads the file, so it runs with the lidar unplugged.
#include <cstdio>
#include <exception>
#include <vector>

#include "lidar_lab/scan_io.hpp"

int main(int argc, char** argv) {
  if (argc != 2) {
    std::printf("usage: lab_scancheck <file.scan.jsonl>\n");
    return 2;
  }
  try {
    const std::vector<lidar_lab::Scan> scans = lidar_lab::load_jsonl(argv[1]);
    std::printf("ok %zu revolutions\n", scans.size());
    return 0;
  } catch (const std::exception& e) {
    std::printf("error: %s\n", e.what());
    return 1;
  }
}

std::string write_tmp(const char* name, const std::string& body) {
  const std::string path = g_dir + "/" + name;
  std::ofstream out(path);
  out << body;
  return path;
}

// The message load_jsonl() threw, or "" when it did not throw at all.
std::string refusal(const char* name, const std::string& body) {
  const std::string path = write_tmp(name, body);
  std::string msg;
  try {
    load_jsonl(path);
  } catch (const std::exception& e) {
    msg = e.what();
  }
  std::remove(path.c_str());
  return msg;
}

void refuses(const std::string& name, const std::string& msg, const char* needle) {
  const bool ok = !msg.empty() && msg.find(needle) != std::string::npos;
  check(name, ok, msg.empty() ? std::string("(no refusal)") : msg, std::string("... ") + needle + " ...");
}

// Read through the size, so a broken writer reports FAIL instead of walking off the end.
std::optional<double> r_at(const std::vector<Scan>& v, std::size_t k, std::size_t i) {
  if (k >= v.size() || i >= v[k].r.size()) return std::nullopt;
  return v[k].r[i];
}
double a_at(const std::vector<Scan>& v, std::size_t k, std::size_t i) {
  return k < v.size() && i < v[k].a.size() ? v[k].a[i] : -99.0;
}

힌트 T4 — save_jsonl() · 머리 줄 하나, 그다음 바퀴마다 한 줄

할 일 — 파일 path 에 머리 줄 meta_line(meta) 를 쓰고, 바퀴마다 {"t": …, "n": …, "a": […], "r": […], "q": […]} 한 줄을 쓴다. 파일을 열 수 없거나 쓰기가 실패하면 std::runtime_error 를 던진다.

끝났을 때 참이어야 하는 것: 이 파일을 load_jsonl() 로 다시 읽으면 같은 값이 나온다. 채점은 test_scan_io.cpp 의 3군(3a ~ 3f)이 한다.

완결 코드

/* 완결 코드 T4 - scripts/lidar_lab/include/lidar_lab/scan_io.hpp */
inline void save_jsonl(const std::string& path, const std::vector<Scan>& scans, const Meta& meta) {
  std::ofstream out(path);
  if (!out) throw std::runtime_error(path + ": cannot open for writing");
  out << meta_line(meta) << "\n";
  for (const Scan& s : scans) {
    out << "{\"t\": " << (s.t ? repr_double(*s.t) : "null");
    out << ", \"n\": " << s.a.size();  // from the list itself, never from a counter
    out << ", \"a\": [";
    for (std::size_t i = 0; i < s.a.size(); ++i) out << (i ? ", " : "") << repr_double(s.a[i]);
    out << "], \"r\": [";
    for (std::size_t i = 0; i < s.r.size(); ++i) {
      out << (i ? ", " : "") << (s.r[i] ? repr_double(*s.r[i]) : "null");
    }
    out << "]";
    if (!s.q.empty()) {
      out << ", \"q\": [";
      for (std::size_t i = 0; i < s.q.size(); ++i) out << (i ? ", " : "") << s.q[i];
      out << "]";
    }
    out << "}\n";
  }
  if (!out) throw std::runtime_error(path + ": write failed");
}

코드 설명

  • std::ofstream out(path); · if (!out) throw …; — 파일을 한 번 연다. 열리지 않으면(폴더가 없다 · 권한이 없다) 예외로 알린다. lab_turn 의 main() 이 그 예외를 잡아 error: … 를 찍고, 그 뒤에도 모터를 끈다(try 블록).
  • out << meta_line(meta) << "\n"; — 머리 줄은 빼먹을 수 없다(§2-5). 빼먹으면 meta 인자를 쓰지 않게 되어 빌드가 unused parameter 'meta' 경고를 낸다.
  • (s.t ? repr_double(*s.t) : "null") — t 가 비어 있으면 null 을 쓴다. 그 줄은 로더가 거부한다 — 기록 껍질이 시각을 찍지 않았다는 뜻이기 때문이다. 조건 연산자 a ? b : c 의 두 갈래(std::string · 문자열 상수)는 std::string 으로 맞춰진다.
  • out << ", \"n\": " << s.a.size(); — n 은 벡터 길이에서 바로 쓴다. 다른 수를 쓰면 로더가 n disagrees with len(a) 로 그 줄을 거부한다.
  • repr_double(s.a[i]) — l-02 의 전량 함수. 다시 읽었을 때 같은 double 이 되는 가장 짧은 글자를 쓴다(0.30000000000000004). std::to_string 은 소수점 아래 여섯 자리에서, out << x 는 유효숫자 여섯 자리에서 잘라 값이 바뀐다(흔한 실수).
  • (s.r[i] ? repr_double(*s.r[i]) : "null") — 값이 있는지 먼저 보고 꺼낸다. 비어 있으면 null 이다(§2-6). push() 가 이미 0 mm 를 빈 값으로 바꿔 두었으므로 여기서 바꿀 것은 없다.
  • if (!s.q.empty()) { … } — 품질을 남기지 않기로 했으면(q 가 빈 벡터) "q" 칸을 아예 쓰지 않는다. 빈 [] 를 쓰면 길이가 a 와 달라 로더가 거부한다.
  • out << "}\n"; · if (!out) throw …; — 줄마다 줄바꿈으로 끝낸다. 쓰기 도중의 실패(디스크가 가득 찼다)는 마지막에 한 번 확인한다.
  • 골격의 자리표시 한 줄((void)path; (void)scans; (void)meta;)은 지웠다.
  • 다르게 써도 되는 곳 — 한 줄을 std::string 에 먼저 모아 한 번에 쓰는 방법. 결과 파일은 같다. 공백 배치(", " · ": ")는 로더가 신경 쓰지 않는다 — 이 코드는 l-00 §2-3 의 보기와 같은 꼴로 쓴다.

쓰는 API — std::ofstream(<fstream>): 만들 때 파일을 연다. !out 이 참이면 열기나 쓰기가 실패한 것이다. repr_double()(repr.hpp, l-02) · meta_line()(§3-1-4 의 쓰기 블록, 전량).

# scripts/lidar_lab/view/scanfile.py -- read a .scan.jsonl for the viewing tools.  (l-04, given in full)
# CONVENIENCE READER: it does NOT make the six refusals of the C++ loader (scan_io.hpp).
# A file this reads without complaint can still be malformed -- if a file looks wrong,
# scripts/lidar_lab/build/lab_scancheck <file> is the reference.
# Standard library only, so it runs on the Pi host and on the Mac with no install.
import json


def load(path):
    """-> (meta: dict, scans: list of dict with keys a, r, q, t).

    r holds None where the file has null (could not measure). q is None when the line
    has no "q". A first line without "meta" gives meta = {} and is read as a revolution.
    """
    meta, scans = None, []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            row = json.loads(line)
            if meta is None:
                meta = {}
                if isinstance(row, dict) and isinstance(row.get("meta"), dict):
                    meta = row["meta"]
                    continue
            scans.append({"a": row.get("a", []), "r": row.get("r", []),
                          "q": row.get("q"), "t": row.get("t")})
    return meta or {}, scans

# is a SECOND reader: a mistake in save_jsonl() cannot hide behind the same mistake here.

3-5. 실습 E — 회전 경계를 일부러 틀리게 한다

// at what comes out.  (l-04 3-5, given in full)
//   pi$ scripts/lidar_lab/build/lab_turn_break --mode none            control: push() as you wrote it
//   pi$ scripts/lidar_lab/build/lab_turn_break --mode every-other     only every other start flag closes
//   pi$ scripts/lidar_lab/build/lab_turn_break --mode keep-fragment   the nodes before the first flag stay
//   options  --dev <tty>    default /dev/lidar
//            --seconds <s>  how long to read, 0.5 .. 60 (default 3)
//            --show <k>     whose first 20 angles to print, 1 .. 1000 (default 2)
// turn.hpp is not changed. The tool edits the Node BEFORE push() sees it:
//   every-other    clears the start flag of the 2nd, 4th, 6th ... flag, so push() does not close there
//   keep-fragment  sets the start flag of the very first node, so the fragment becomes revolution 1
// It writes no file (nothing of this goes into scans/) and stamps no t.
// It spins the head (motor(fd, true)). Every way out passes the stop(fd) and motor(fd, false)

enum class Mode { None, EveryOther, KeepFragment };

// stop -> drain -> SCAN -> descriptor. -> true if a descriptor came back. (as in src/turn.cpp)
bool begin_scan(int fd) {
  stop(fd);
  drain(fd);
  send(fd, CMD_SCAN);
  u8 raw[kDescriptorLen];
  const std::size_t got = read_exact(fd, raw, kDescriptorLen, kReadTimeoutMs);
  return parse_descriptor(raw, got).has_value();
}

std::string num(const std::optional<double>& v) {
  if (!v) return "none";
  char buf[32];
  std::snprintf(buf, sizeof buf, "%.3f", *v);
  return buf;
}

// Read for `seconds`, change the start flags as the mode says, cut with your push().
// Prints the same rev lines as lab_turn, then the counters, the 3-2 numbers and the angles.
void run(int fd, Mode mode, double seconds, int show) {
  NodeStream ns;
  TurnSplitter splitter;
  std::vector<Scan> scans;
  int flags = 0;            // start flags as received
  bool first = true;
  bool first_was_flag = false;
  stream(fd, seconds, ns, [&](const Node& p) {
    Node q = p;
    if (first) first_was_flag = p.start;
    if (p.start) ++flags;
    if (mode == Mode::EveryOther && p.start && flags % 2 == 0) q.start = false;
    if (mode == Mode::KeepFragment && first) q.start = true;
    first = false;
    if (std::optional<Scan> s = splitter.push(q)) {
      print_turn(static_cast<int>(scans.size()) + 1, *s);
      scans.push_back(std::move(*s));
    }
    return true;  // stream() stops on the time limit and on Ctrl-C
  });
  std::printf("accepted %zu nodes, rejected %zu boundaries\n", ns.accepted(), ns.rejected());
  std::printf("flags      = %d received", flags);
  if (mode == Mode::KeepFragment) {
    std::printf("   (first node start=%s%s)", first_was_flag ? "true" : "false",
                first_was_flag ? " -- no fragment this time" : "");
  }
  std::printf("\n");
  const TurnStats st = turn_stats(scans);  // no gap_max: the three runs are compared as they are
  std::printf("turns      = %d\n", st.turns);
  std::printf("points/rev = %s\n", num(st.points_median).c_str());
  std::printf("gap median = %s deg   sigma = %s deg\n", num(st.gap_median).c_str(),
              num(st.gap_sigma).c_str());
  if (show > static_cast<int>(scans.size())) {
    std::printf("rev %d: none (%zu revolutions)\n", show, scans.size());
    return;
  }
  const Scan& s = scans[static_cast<std::size_t>(show - 1)];
  std::printf("rev %d first 20 angles:", show);
  for (std::size_t i = 0; i < s.size() && i < 20; ++i) {
    if (i % 10 == 0) std::printf("\n ");
    std::printf(" %6.2f", s.a[i]);
  }
  std::printf("\n");
}

int usage() {
  std::printf("usage: lab_turn_break --mode none|every-other|keep-fragment [--dev <tty>]"
              " [--seconds <0.5..60>] [--show <1..1000>]\n");
  return 2;

}  // namespace

int main(int argc, char** argv) {
  const char* dev = kDev;
  std::optional<Mode> mode;
  const char* mode_name = "";
  double seconds = 3.0;
  int show = 2;
  for (int i = 1; i < argc; i += 2) {
    if (i + 1 >= argc) return usage();
    const char* v = argv[i + 1];
    char* end = nullptr;
    if (std::strcmp(argv[i], "--mode") == 0) {
      if (std::strcmp(v, "none") == 0) mode = Mode::None;
      else if (std::strcmp(v, "every-other") == 0) mode = Mode::EveryOther;
      else if (std::strcmp(v, "keep-fragment") == 0) mode = Mode::KeepFragment;
      else return usage();
      mode_name = v;
    } else if (std::strcmp(argv[i], "--dev") == 0) {
      dev = v;
    } else if (std::strcmp(argv[i], "--seconds") == 0) {
      seconds = std::strtod(v, &end);
      if (*end != '\0' || !(seconds >= 0.5 && seconds <= 60.0)) return usage();
    } else if (std::strcmp(argv[i], "--show") == 0) {
      const long k = std::strtol(v, &end, 10);
      if (*end != '\0' || k < 1 || k > 1000) return usage();
      show = static_cast<int>(k);
    } else {
      return usage();
    }
  }
  if (!mode) return usage();

  install_stop_handler();
  const int fd = open_port(dev);
  if (fd < 0) return 1;
  std::printf("mode       %s   %.1f s\n", mode_name, seconds);
  motor(fd, true);
  for (int i = 0; i < 40 && !stop_requested(); ++i)  // spin-up 2 s as in lab_turn
    std::this_thread::sleep_for(std::chrono::milliseconds(50));
  int rc = 0;
  if (!begin_scan(fd)) {
    std::printf("no descriptor -- not reading points\n");
    rc = 1;
  } else {
    run(fd, *mode, seconds, show);
  }
  stop(fd);          // stop scanning
  motor(fd, false);  // motor off (L2)
  std::printf("stopped    STOP sent, motor off\n");
  ::close(fd);
  return rc;
}

5. 못 잰 방향을 null 로 적는데 LaserScan 은 inf 와 NaN 을 쓴다. 둘은 같은 종류의 결정인가, 다른 종류의 결정인가

같은 종류다. 둘 다 "못 쟀다"를 어떻게 적을지 규약이 한 번 정해 고정했다. 다른 것은 고를 수 있는 것의 폭이었다 — LaserScan 의 ranges 는 고정 폭 실수 배열이라 "비어 있는 칸"이 존재할 수 없고, 그래서 실수 중에서 골라야 했다. 한 줄짜리 JSON 에는 null 이 있다.

고르는 축은 "어느 쪽이 정확한가"가 아니다 — 셋 다 "못 쟀다"를 적을 수는 있다. 축은 이 값을 처리하는 것을 깜빡한 코드가 오류를 내는가 그럴듯한 숫자를 내는가 하나다. 0 은 "코앞에 벽"이 되고, inf 는 "멀리 있다"가 되어 격자에서는 그 방향의 칸을 전부 비어 있음으로 칠한다. 둘 다 오류가 나지 않는다. null 은 수가 아니다. C++ 로더는 빈 std::optional 로 읽고, 확인하지 않고 *r 로 꺼내면 이 가이드의 g++ 빌드는 그 자리에서 중단한다(Pi 의 판은 확인 과제, §2-6-2). 단 value_or(0.0) 으로 꺼내면 멈추지 않고 0 m 의 측정값이 된다 — 그래서 꺼내는 방법까지 규칙으로 정한다(§2-6-2).

LaserScan 쪽에서 그 처리를 어디서 하는지도 저장소에서 보인다. 07 §1-1 은 이 값들을 "물체가 없다"가 아니라 "측정 실패" 라고 정해 두었다. 07 §3-10 의 C++ 노드는 inf · NaN 을 걸러 내는 줄을 따로 갖는다. 규약이 막지 못하는 값을 받는 쪽 코드가 매번 걸러 낸다.

한 "바퀴"가 두 바퀴를 담으므로 점 수가 대략 두 배가 되고, 각도로 정렬하고 나면 간격 중앙값이 대략 절반으로 떨어진다. 그리고 첫 20개 각도를 보면 거의 같은 각도가 둘씩 짝지어 나타난다 — 두 바퀴가 같은 방향을 각각 한 번씩 쟀기 때문이다.

점 수만 보면 이 결과와 "센서가 갑자기 점을 두 배로 많이 재는 것"이 구별되지 않는다. 둘 다 점이 두 배다. 구별해 주는 것은 각도의 모양이다 — 진짜로 점이 두 배면 각도가 고르게 촘촘해지고, 두 바퀴가 겹친 것이면 짝을 지어 몰린다. 개수는 증상이고 각도가 증거다. l-03 의 재동기 실습에서 "개수가 아니라 각도의 이어짐을 보라"고 한 것과 같은 교훈이다.

7. (안전) 이 쪽은 머리를 30초 넘게 계속 돌린다. 그동안 지키는 것 둘과 그 이유
