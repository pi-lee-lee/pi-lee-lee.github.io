자기소개서

성장과정 및 성격

기록하는 습관을 오래 유지해 왔습니다. 대학 2학년 때 팀 과제에서 같은 오류를 세 번 반복해 고친 일이 계기가 되어, 그때부터 해결한 문제와 원인을 정리해 두는 저장소를 따로 운영하고 있습니다. 덕분에 교육과정에서는 팀원들이 막힌 부분을 물어보는 일이 잦았고, 정리한 내용을 공유하며 함께 진도를 맞출 수 있었습니다. 맡은 일의 진행 상황을 먼저 알리는 편이라 협업 과정에서 일정이 어긋나는 일이 적었습니다.

지원동기

사용자에게 직접 닿는 서비스의 뒷단을 만드는 일에 관심을 두고 백엔드 개발을 준비했습니다. 학부 전공에서 자료구조와 데이터베이스의 기초를 쌓고, 졸업 후 960시간 교육과정에서 Spring Boot 기반의 API 서버를 세 차례 처음부터 구축하며 설계와 구현의 간격을 좁혀 왔습니다. 안정적인 서비스 운영을 중요하게 여기는 귀사에서 기초가 탄탄한 개발자로 성장하고자 지원하게 되었습니다.

입사 후 포부

입사 후 첫 1년은 담당 서비스의 코드와 데이터 구조를 정확히 파악하는 데 집중하겠습니다. 작은 기능이라도 요구사항의 의도를 확인한 뒤 구현하고, 맡은 부분에 대해서는 테스트 코드까지 책임지는 습관을 들이겠습니다. 이후에는 프로젝트에서 경험한 성능 개선을 더 깊이 다뤄, 문제가 생겼을 때 원인을 데이터로 설명할 수 있는 개발자가 되겠습니다.

위의 모든 기재 사항은 사실과 다름없습니다.
