C8 · Hailo 추론 노드

Hailo 추론 노드 — 같은 /detections 를 Hailo-8 로

C6 와 같은 토픽 · 같은 메시지 · 같은 파라미터 이름으로 발행하는 검출기를 하나 더 만든다. 다른 것은 추론을 Hailo-8 이 한다는 것뿐이다. 그리기 노드도, 뒤의 소비자도 바뀌지 않는다. 끝나면 /detections 가 카메라 속도로 나오고 CPU 사용률은 절반 아래가 된다.

이 쪽이 끝나면 보이는 것
  • 패키지 rpi5_hailo_detect 가 find_package(HailoRT 4.23.0 EXACT) 로 빌드된다.
  • hailo_detect 가 /detections 를 카메라 fps 근처로 발행하고, C6 의 그리기 노드가 수정 없이 박스를 그린다.
  • 추론 중 노드의 CPU 사용률이 50 % 아래다.
  • 런치 파일 하나로 카메라 + 검출기(Hailo 또는 CPU) + 그리기 노드가 뜬다.
  • 모델 이름 · 입력 해상도 · 실측 fps 를 INVENTORY 5절에 적었다.

필요한 것 — C7 을 통과한 컨테이너, C5 의 coco.names 와 test.jpg, C6 의 그리기 노드.

환경컨테이너 C++ 벤치
선행C7(버전 · 모델 확인), C6(그리기 노드 · 메시지 구조)
만드는 것패키지 ros2_ws/src/rpi5_hailo_detect, rpi5_vision/launch/perception.launch.py, rpi5_vision/config/detector.yaml
적는 곳INVENTORY 5절 — 사용할 모델 · 입력 해상도 · 실측 추론 fps

1. 개요

                         C6                                                C8
/stereo/left/image_raw ──► yolo_detector (OpenCV DNN · CPU) ──┐   /stereo/left/image_raw ──► hailo_detect (HailoRT · /dev/hailo0) ──┐
                                                              ▼                                                                     ▼
                                                      /detections  (vision_msgs/Detection2DArray)  ← 같은 토픽 · 같은 메시지 · 같은 파라미터 이름
                                                              │
                                               detection_overlay (C6) · 뒤의 소비자 — 어느 쪽이 발행하는지 모른다

노드는 두 층이다. ROS 배선(구독 · 발행 · 프레임 버리기 · header 복사)은 C6 와 같고, 백엔드(프레임 → 박스 목록)만 HailoRT 호출로 바뀐다. 백엔드가 지키는 계약은 하나다 — 원본 프레임의 픽셀 좌표로 박스 목록을 돌려준다.

2. 원리

2-1. HailoRT 호출 순서 — 다섯 단계

단계호출뜻
① 장치 열기VDevice::create()/dev/hailo0 을 여는 핸들. 노드 수명 동안 하나
② 모델 읽기vdevice->create_infer_model(hef_path).hef 파일을 읽어 입력 · 출력의 이름 · 모양 · 형식을 안다
③ 형식 지정input().set_format_type(UINT8), output().set_format_type(FLOAT32)내가 넣고 받을 형식. 입력은 8비트 RGB, 출력은 32비트 실수
④ 구성과 버퍼configure() → create_bindings() → set_buffer()모델을 칩에 올리고, 입력 · 출력 버퍼의 메모리를 등록한다. 버퍼 크기는 get_frame_size() 가 알려 준다
⑤ 실행run(bindings, 1000 ms)입력 버퍼를 보내고 출력 버퍼가 채워질 때까지 기다린다. 매 프레임 반복

①~④ 는 생성자에서 한 번, ⑤ 는 콜백마다다. 모든 호출은 성공 여부를 돌려준다. 실패를 무시하면 "박스가 안 나온다" 로만 보이므로, 실패마다 예외로 바꿔 로그에 이유를 남긴다.

2-2. 출력 버퍼의 배치 — 클래스별 박스 목록

출력 버퍼 (160 320 바이트) = 클래스 0 묶음 | 클래스 1 묶음 | ... | 클래스 79 묶음

클래스 c 의 묶음 = count (float32, 박스 개수)  |  박스 0  |  박스 1  | ... |  박스 count-1
박스 하나 (20 바이트)  = y_min, x_min, y_max, x_max, score   (전부 float32, 좌표는 0 ~ 1 — 640 × 640 입력 기준)

최대 크기 = 80 × (4 + 100 × 20) = 160 320        count 가 0 인 클래스는 4 바이트만 차지한다

좌표 순서가 y 가 먼저이고 0 ~ 1 로 정규화되어 있다. 640 을 곱해 레터박스 입력의 픽셀로 만든 뒤, C6 과 같은 식으로 원본 좌표로 되돌린다. 이 두 가지(순서 · 정규화)를 틀리면 박스가 한쪽으로 몰리거나 화면 밖으로 나간다.

2-3. 입력 — 같은 레터박스, RGB 8비트

모델 입력은 640 × 640 × 3, 8비트 RGB 다. 카메라는 bgr8 로 보내므로 cv_bridge 에 rgb8 을 요청해 변환시킨다(복사 한 번). 레터박스는 C6 의 식 그대로이고, 결과를 입력 버퍼에 직접 그려 복사를 줄인다. 버퍼는 페이지 경계(4096 바이트)에 맞춰 할당한다 — 칩이 메모리를 직접 읽는 장치라 정렬된 버퍼가 빠르다.

2-4. 임계값은 두 곳에 있다

.hef 안의 NMS 가 점수 임계값과 겹침 임계값을 갖고 있고, 노드의 conf_threshold 가 그 위에서 한 번 더 거른다. 코드는 set_nms_score_threshold() 로 .hef 쪽 점수 임계값도 conf_threshold 로 맞춘다. 그래서 C6 와 검출 개수가 다르면 그 원인은 임계값이 아니라 모델(yolov8n 대 yolov8s)이다.

// One detection in original-frame pixel coordinates (the backend contract).
struct Box
{
  cv::Rect2f rect;
  float score;
  int class_id;
};

// Throw with the HailoRT status text instead of silently continuing.
void check(hailo_status status, const char * what)
{
  if (status != HAILO_SUCCESS) {
    throw std::runtime_error(std::string(what) + " failed: " + hailo_get_status_message(status));
  }
}

// Page-aligned buffer: the chip reads memory directly, aligned buffers avoid an extra copy.
class AlignedBuffer
{
public:
  explicit AlignedBuffer(size_t size)
  : size_(size)
  {
    const size_t page = static_cast<size_t>(sysconf(_SC_PAGESIZE));
    const size_t rounded = ((size + page - 1) / page) * page;
    if (posix_memalign(&ptr_, page, rounded) != 0) {
      throw std::bad_alloc();
    }
    std::memset(ptr_, 0, rounded);
  }
  ~AlignedBuffer() { std::free(ptr_); }
  AlignedBuffer(const AlignedBuffer &) = delete;
  AlignedBuffer & operator=(const AlignedBuffer &) = delete;
  uint8_t * data() { return static_cast<uint8_t *>(ptr_); }
  size_t size() const { return size_; }

private:
  void * ptr_{nullptr};
  size_t size_;
};

// --- pure logic begin ---
struct Letterbox
{
  float scale;
  int pad_x;
  int pad_y;
};

// Resize keeping the aspect ratio into dst (already allocated, size x size, 3 channels) and pad with gray.
// Same formula as C6; here the result is written straight into the model's input buffer.
Letterbox letterbox_into(const cv::Mat & src, cv::Mat & dst)
{
  Letterbox lb;
  lb.scale = std::min(static_cast<float>(dst.cols) / src.cols, static_cast<float>(dst.rows) / src.rows);
  const int new_w = static_cast<int>(std::round(src.cols * lb.scale));
  const int new_h = static_cast<int>(std::round(src.rows * lb.scale));
  lb.pad_x = (dst.cols - new_w) / 2;
  lb.pad_y = (dst.rows - new_h) / 2;
  dst.setTo(cv::Scalar(114, 114, 114));
  cv::Mat roi = dst(cv::Rect(lb.pad_x, lb.pad_y, new_w, new_h));
  cv::resize(src, roi, roi.size(), 0, 0, cv::INTER_LINEAR);     // same size and type -> writes into dst
  return lb;
}

// Parse the "NMS by class" output (C8 section 2-2):
//   for each class: float32 count, then count x { y_min, x_min, y_max, x_max, score } (float32, 0..1).
// Coordinates are relative to the letterboxed model input; map them back to the original frame.
std::vector<Box> parse_nms_by_class(const uint8_t * buf, size_t buf_size, uint32_t num_classes,
                                    int input_w, int input_h, const Letterbox & lb, int orig_w, int orig_h)
{
  std::vector<Box> boxes;
  const uint8_t * p = buf;
  const uint8_t * end = buf + buf_size;
  const cv::Rect2f frame(0.f, 0.f, static_cast<float>(orig_w), static_cast<float>(orig_h));
  for (uint32_t c = 0; c < num_classes; ++c) {
    if (p + sizeof(float) > end) {
      break;
    }
    float count_f = 0.f;
    std::memcpy(&count_f, p, sizeof(float));
    p += sizeof(float);
    const uint32_t count = static_cast<uint32_t>(count_f);
    for (uint32_t i = 0; i < count; ++i) {
      if (p + sizeof(hailo_bbox_float32_t) > end) {
        return boxes;
      }
      hailo_bbox_float32_t bb;
      std::memcpy(&bb, p, sizeof(bb));
      p += sizeof(bb);
      const float x1 = (bb.x_min * input_w - lb.pad_x) / lb.scale;
      const float y1 = (bb.y_min * input_h - lb.pad_y) / lb.scale;
      const float x2 = (bb.x_max * input_w - lb.pad_x) / lb.scale;
      const float y2 = (bb.y_max * input_h - lb.pad_y) / lb.scale;
      Box b;
      b.rect = cv::Rect2f(x1, y1, x2 - x1, y2 - y1) & frame;    // clip to the frame
      b.score = bb.score;
      b.class_id = static_cast<int>(c);
      if (b.rect.width > 0.f && b.rect.height > 0.f) {
        boxes.push_back(b);
      }
    }
  }
  return boxes;
}
// --- pure logic end ---

// HailoRT backend: steps 1-4 of section 2-1 in the constructor, step 5 in infer().
class HailoBackend
{
public:
  HailoBackend(const std::string & hef_path, float score_threshold)
  {
    using hailort::VDevice;
    using hailort::MemoryView;

    // 1. device
    vdevice_ = VDevice::create().expect(
      "VDevice::create -- is /dev/hailo0 visible in the container and the HailoRT version equal to the host?");
    // 2. model
    model_ = vdevice_->create_infer_model(hef_path).expect("create_infer_model -- check model_path");

    // 3. formats (before configure)
    auto input = model_->input().expect("the model must have exactly one input");
    auto output = model_->output().expect("the model must have exactly one output");
    input.set_format_type(HAILO_FORMAT_TYPE_UINT8);        // we feed 8-bit RGB
    if (!output.is_nms()) {
      throw std::runtime_error("this HEF has no NMS output -- this guide expects a yolov8 HEF with NMS (C7 section 2-1)");
    }
    output.set_format_type(HAILO_FORMAT_TYPE_FLOAT32);
    output.set_nms_score_threshold(score_threshold);       // the HEF-side score filter follows conf_threshold

    const hailo_3d_image_shape_t shape = input.shape();    // height, width, features
    input_h_ = static_cast<int>(shape.height);
    input_w_ = static_cast<int>(shape.width);
    if (shape.features != 3) {
      throw std::runtime_error("model input is not 3-channel");
    }
    const hailo_format_order_t order = output.format().order;
    if (order != HAILO_FORMAT_ORDER_HAILO_NMS_BY_CLASS && order != HAILO_FORMAT_ORDER_HAILO_NMS) {
      throw std::runtime_error("output is not 'NMS by class' -- this guide parses only that layout (check parse-hef)");
    }
    num_classes_ = output.get_nms_shape().expect("get_nms_shape").number_of_classes;

    // 4. configure and bind page-aligned buffers (sizes depend on the format types set above)
    input_buf_ = std::make_unique<AlignedBuffer>(input.get_frame_size());
    output_buf_ = std::make_unique<AlignedBuffer>(output.get_frame_size());
    configured_ = model_->configure().expect("configure");
    bindings_ = configured_.create_bindings().expect("create_bindings");
    check(bindings_.input()->set_buffer(MemoryView(input_buf_->data(), input_buf_->size())), "set input buffer");
    check(bindings_.output()->set_buffer(MemoryView(output_buf_->data(), output_buf_->size())), "set output buffer");

    // the model input, viewed as an OpenCV image: letterbox draws directly into the input buffer
    input_mat_ = cv::Mat(input_h_, input_w_, CV_8UC3, input_buf_->data());
  }

  int input_width() const { return input_w_; }
  int input_height() const { return input_h_; }
  uint32_t num_classes() const { return num_classes_; }

  // 5. one frame (RGB, 8-bit) -> boxes in original pixel coordinates
  std::vector<Box> infer(const cv::Mat & rgb)
  {
    const Letterbox lb = letterbox_into(rgb, input_mat_);
    check(configured_.run(bindings_, std::chrono::milliseconds(1000)), "run");
    return parse_nms_by_class(output_buf_->data(), output_buf_->size(), num_classes_,
                              input_w_, input_h_, lb, rgb.cols, rgb.rows);
  }

private:
  std::unique_ptr<hailort::VDevice> vdevice_;
  std::shared_ptr<hailort::InferModel> model_;
  std::unique_ptr<AlignedBuffer> input_buf_;
  std::unique_ptr<AlignedBuffer> output_buf_;
  hailort::ConfiguredInferModel configured_;
  hailort::ConfiguredInferModel::Bindings bindings_;
  cv::Mat input_mat_;
  int input_w_{0};
  int input_h_{0};
  uint32_t num_classes_{0};
};

struct BusyGuard
{
  explicit BusyGuard(std::atomic<bool> & flag) : flag_(flag) {}
  ~BusyGuard() { flag_ = false; }
  std::atomic<bool> & flag_;
};

}  // namespace

class HailoDetect : public rclcpp::Node
{
public:
  HailoDetect()
  : Node("hailo_detect")
  {
    // Same parameter names as yolo_detector (C6). input_size and nms_threshold are accepted for
    // compatibility: the input size comes from the HEF and NMS already ran inside the HEF.
    this->declare_parameter<std::string>("model_path", "");
    this->declare_parameter<std::string>("names_path", "");
    this->declare_parameter<double>("conf_threshold", 0.4);
    this->declare_parameter<double>("nms_threshold", 0.5);
    this->declare_parameter<int>("input_size", 640);
    this->declare_parameter<std::vector<std::string>>("class_filter", std::vector<std::string>{});
    this->declare_parameter<std::string>("test_image", "");

    const auto model_path = this->get_parameter("model_path").as_string();
    conf_thr_ = static_cast<float>(this->get_parameter("conf_threshold").as_double());
    class_filter_ = this->get_parameter("class_filter").as_string_array();
    class_filter_.erase(std::remove(class_filter_.begin(), class_filter_.end(), std::string{}),
                        class_filter_.end());
    load_names(this->get_parameter("names_path").as_string());

    backend_ = std::make_unique<HailoBackend>(model_path, conf_thr_);    // steps 1-4, once
    RCLCPP_INFO(this->get_logger(), "model loaded: %s  input %dx%d  classes %u",
                model_path.c_str(), backend_->input_width(), backend_->input_height(), backend_->num_classes());
    if (backend_->num_classes() != names_.size()) {
      RCLCPP_WARN(this->get_logger(), "names file has %zu lines but the model has %u classes",
                  names_.size(), backend_->num_classes());
    }

    const auto test_image = this->get_parameter("test_image").as_string();
    if (!test_image.empty()) {
      run_test_image(test_image);
      return;
    }

    pub_ = this->create_publisher<vision_msgs::msg::Detection2DArray>(
      "/detections", rclcpp::QoS(1).best_effort());
    auto qos = rmw_qos_profile_sensor_data;
    qos.depth = 1;                                   // newest frame only
    sub_ = image_transport::create_subscription(
      this, "/stereo/left/image_raw",
      [this](const sensor_msgs::msg::Image::ConstSharedPtr & msg) { on_image(msg); }, "raw", qos);
  }

  bool test_mode() const { return test_mode_; }

private:
  void load_names(const std::string & path)
  {
    std::ifstream f(path);
    for (std::string line; std::getline(f, line);) {
      if (!line.empty()) {
        names_.push_back(line);
      }
    }
    if (names_.empty()) {
      RCLCPP_FATAL(this->get_logger(), "cannot read names_path '%s'", path.c_str());
      throw std::runtime_error("names file");
    }
  }

  std::string class_name(int id) const
  {
    return (id >= 0 && static_cast<size_t>(id) < names_.size()) ? names_[id] : std::to_string(id);
  }

  bool passes_filter(const std::string & name) const
  {
    return class_filter_.empty() ||
           std::find(class_filter_.begin(), class_filter_.end(), name) != class_filter_.end();
  }

  void on_image(const sensor_msgs::msg::Image::ConstSharedPtr & msg)
  {
    bool expected = false;
    if (!busy_.compare_exchange_strong(expected, true)) {
      dropped_++;
      return;
    }
    BusyGuard guard(busy_);

    cv_bridge::CvImageConstPtr cv_ptr;
    try {
      cv_ptr = cv_bridge::toCvShare(msg, "rgb8");    // camera sends bgr8; the model wants RGB -> converted copy
    } catch (const cv_bridge::Exception & e) {
      RCLCPP_ERROR_THROTTLE(this->get_logger(), *this->get_clock(), 2000, "cv_bridge: %s", e.what());
      return;
    }

    const auto t0 = std::chrono::steady_clock::now();
    std::vector<Box> boxes;
    try {
      boxes = backend_->infer(cv_ptr->image);
    } catch (const std::exception & e) {
      RCLCPP_ERROR_THROTTLE(this->get_logger(), *this->get_clock(), 2000, "inference: %s", e.what());
      return;
    }
    const double ms =
      std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - t0).count();

    vision_msgs::msg::Detection2DArray arr;
    arr.header = msg->header;        // capture time and frame id -- not the inference time
    for (const Box & b : boxes) {
      if (b.score < conf_thr_) {
        continue;
      }
      const std::string name = class_name(b.class_id);
      if (!passes_filter(name)) {
        continue;
      }
      vision_msgs::msg::Detection2D det;
      det.header = msg->header;
      det.bbox.center.position.x = b.rect.x + b.rect.width / 2.0;
      det.bbox.center.position.y = b.rect.y + b.rect.height / 2.0;
      det.bbox.size_x = b.rect.width;
      det.bbox.size_y = b.rect.height;
      vision_msgs::msg::ObjectHypothesisWithPose hyp;
      hyp.hypothesis.class_id = name;
      hyp.hypothesis.score = b.score;
      det.results.push_back(hyp);
      arr.detections.push_back(det);
    }
    pub_->publish(arr);

    RCLCPP_INFO_THROTTLE(this->get_logger(), *this->get_clock(), 2000,
      "%zu det  %.1f ms  dropped=%zu", arr.detections.size(), ms, dropped_.load());
  }

  void run_test_image(const std::string & path)
  {
    test_mode_ = true;
    cv::Mat bgr = cv::imread(path);
    if (bgr.empty()) {
      RCLCPP_FATAL(this->get_logger(), "cannot read test_image '%s'", path.c_str());
      throw std::runtime_error("test image");
    }
    cv::Mat rgb;
    cv::cvtColor(bgr, rgb, cv::COLOR_BGR2RGB);
    const auto boxes = backend_->infer(rgb);
    RCLCPP_INFO(this->get_logger(), "test_image %s: %zu det", path.c_str(), boxes.size());
    for (const Box & b : boxes) {
      if (b.score < conf_thr_) {
        continue;
      }
      RCLCPP_INFO(this->get_logger(), "  %-12s %.2f  x=%.0f y=%.0f w=%.0f h=%.0f",
                  class_name(b.class_id).c_str(), b.score, b.rect.x, b.rect.y, b.rect.width, b.rect.height);
    }
  }

  std::unique_ptr<HailoBackend> backend_;
  std::vector<std::string> names_;
  std::vector<std::string> class_filter_;
  float conf_thr_{0.4f};
  bool test_mode_{false};
  std::atomic<bool> busy_{false};
  std::atomic<size_t> dropped_{0};

  image_transport::Subscriber sub_;
  rclcpp::Publisher<vision_msgs::msg::Detection2DArray>::SharedPtr pub_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<HailoDetect>();
  if (!node->test_mode()) {
    rclcpp::spin(node);
  }
  rclcpp::shutdown();
  return 0;
}

"""Camera + detector + overlay (camera guide C8).

    ros2 launch rpi5_vision perception.launch.py                    # Hailo-8 detector (default)
    ros2 launch rpi5_vision perception.launch.py detector:=yolo     # CPU detector (C6)
    ros2 launch rpi5_vision perception.launch.py overlay:=false     # no drawing node (saves CPU)
    ros2 launch rpi5_vision perception.launch.py hef:=/usr/share/hailo-models/other_h8.hef
"""
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.conditions import IfCondition
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution, PythonExpression
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare


def generate_launch_description():
    share = FindPackageShare('rpi5_vision')
    camera_params = PathJoinSubstitution([share, 'config', 'camera.yaml'])
    detector_params = PathJoinSubstitution([share, 'config', 'detector.yaml'])
    names_path = PathJoinSubstitution([share, 'models', 'coco.names'])
    onnx_path = PathJoinSubstitution([share, 'models', 'yolov8n.onnx'])
    detector = LaunchConfiguration('detector')

    return LaunchDescription([
        DeclareLaunchArgument('detector', default_value='hailo', description='hailo | yolo'),
        DeclareLaunchArgument('hef', default_value='/usr/share/hailo-models/yolov8s_h8.hef'),
        DeclareLaunchArgument('overlay', default_value='true'),

        Node(package='camera_ros', executable='camera_node', namespace='stereo', name='left',
             output='screen', parameters=[camera_params]),

        Node(package='rpi5_vision', executable='yolo_detector', name='detector', output='screen',
             parameters=[detector_params, {'model_path': onnx_path, 'names_path': names_path}],
             condition=IfCondition(PythonExpression(["'", detector, "' == 'yolo'"]))),

        Node(package='rpi5_hailo_detect', executable='hailo_detect', name='detector', output='screen',
             parameters=[detector_params, {'model_path': LaunchConfiguration('hef'), 'names_path': names_path}],
             condition=IfCondition(PythonExpression(["'", detector, "' == 'hailo'"]))),

        Node(package='rpi5_vision', executable='detection_overlay', name='detection_overlay', output='screen',
             condition=IfCondition(LaunchConfiguration('overlay'))),
    ])

🤔 이해 확인

이 쪽에서 설명한 내용만으로 답할 수 있다. 답을 펼치기 전에 먼저 말로 답해 본다.

1. 출력 버퍼의 최대 크기 160 320 바이트는 어떻게 나오는 숫자인가.

클래스 80 개 × (박스 개수 4 바이트 + 클래스당 최대 100 개 × 박스 20 바이트) = 80 × 2004 = 160 320 이다. 박스 하나는 float32 다섯 개(y_min, x_min, y_max, x_max, score)다. 실제로 채워지는 양은 검출 수에 따라 다르고, 코드는 클래스마다 count 를 읽어 그만큼만 읽는다.

2. Hailo 를 쓰는 목표가 fps 가 아니라 CPU 사용률인 이유는 무엇인가.

자율주행은 인지 · 지도 작성 · 경로 계획 · 제어가 동시에 실행되어야 한다. CPU 로 추론하면 4 코어가 포화되어 나머지가 CPU 시간을 얻지 못하고 전체가 멈춘다. 추론을 전용 칩으로 옮겨 CPU 를 나머지 일에 쓰는 것이 목표이고, fps 는 그 결과다.

3. 이 쪽에서 그리기 노드를 한 줄도 고치지 않은 것이 왜 중요한가.

토픽 이름 · 메시지 형식 · 파라미터 이름이 계약이고 검출기는 그 구현이기 때문이다. 소비자가 구현에 의존하지 않으므로 CPU 와 Hailo 를 런치 인자 하나로 바꿀 수 있고, 다른 가속기로 옮겨도 소비자는 그대로다.

4. C6 와 C8 의 검출 개수가 다르다. 임계값은 같게 맞췄다. 남는 원인은 무엇인가.

모델이 다르다 — C6 는 yolov8n(가장 작은 판), C8 은 yolov8s(더 큰 판)다. 더 큰 모델이 작은 물체를 더 찾는다. 같은 모델로 비교하려면 Mac 에서 yolov8s ONNX 를 내보내 C6 에 쓰거나, Hailo 용 yolov8n 모델 파일을 구해 C8 에 쓴다.

  • 카메라 영상이 토픽이 되고(C2), 보정값이 실리고(C3), OpenCV 로 가공되고(C4), YOLO 가 물체를 찾고(C6), 그 계산이 Hailo-8 로 옮겨졌다(C8). perception.launch.py 한 줄이 전부를 띄운다.
  • 이어지는 것은 학습 단계 08d — /detections 에 번호를 붙여 따라가고(추적), 라이다와 합쳐 거리를 잰다. 08d 에서 C3 의 camera_info 가 쓰인다.
  • 모델을 바꾸려면: CPU 쪽은 C5 를 다른 모델로 다시, Hailo 쪽은 Hailo-8 용 .hef 를 /usr/share/hailo-models/ 에 두고 hef:= 인자로 준다. 출력이 "NMS by class" 인 yolov8 계열이면 코드는 그대로다.
