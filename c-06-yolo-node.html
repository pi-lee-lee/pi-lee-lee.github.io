C6 · YOLO 추론 노드 (CPU)

YOLO 추론 노드 (CPU) — /detections 를 만들고 느림을 잰다

C5 의 모델 파일을 Pi 의 C++ 노드가 OpenCV DNN 모듈로 실행해 /detections 를 발행한다. 검출 결과를 영상 위에 그리는 노드도 함께 만든다. Pi 5 의 CPU 라 초당 1 ~ 3 장이다. 주행용으로는 부족하지만 전처리 · 후처리 · 메시지 · 그리기가 전부 맞는지 확인하기에는 충분하고, 이 느림이 C8 의 이유가 된다.

이 쪽이 끝나면 보이는 것
  • yolo_detector 가 /detections(vision_msgs/Detection2DArray)를 발행한다. 첫 로그의 출력 모양이 C5 에서 본 것과 같다.
  • detection_overlay 가 박스와 이름을 그린 /stereo/left/annotated 를 발행하고 Foxglove 에 보인다.
  • 시험 사진 한 장의 검출 결과가 C5 의 정답과 몇 픽셀 안에서 같다.
  • 추론 시간 · fps · CPU 사용률을 표에 적었다.

필요한 것 — C5 의 yolov8n.onnx · coco.names · test.jpg, C4 의 패키지.

환경컨테이너 C++ 벤치
선행C4(패키지 · 빌드), C5(모델 파일 · 정답)

적는 곳노트 — §3-8 의 측정 표

1. 개요

/stereo/left/image_raw ──► yolo_detector ──► /detections ──► detection_overlay ──► /stereo/left/annotated ──► Foxglove
                           레터박스 → blob → 추론 → 전치 → 점수 필터 → NMS → 좌표 복원 → 메시지

검출 메시지는 표준 형식 vision_msgs/msg/Detection2DArray 다. 박스 하나가 Detection2D 하나이고, 좌표는 픽셀이다. 그리기 노드가 읽는 필드 경로가 아래와 같다.

Detection2DArray
├── header                              촬영 시각 · stereo_left_optical_link (입력 영상의 header 를 복사)
└── detections[]  Detection2D
    ├── bbox.center.position.x / .y     박스 중심 (픽셀)
    ├── bbox.size_x / size_y            폭 / 높이 (픽셀)
    └── results[0].hypothesis.class_id  "person"       results[0].hypothesis.score  0.87

그리기를 검출기 안에 넣지 않고 노드로 나눈 이유는 셋이다. C8 에서 검출기를 바꿔도 그리기 노드는 그대로다. 운용 중에는 그리기 노드를 실행하지 않아 CPU 를 아낀다. /detections 만 필요한 소비자는 영상 없이 구독한다.

2. 원리

2-1. 프레임을 버린다 — 큐 1 과 처리 중 표시

카메라는 초당 30 장, 추론은 300 ms 다. 들어오는 프레임을 전부 처리하려 하면 초당 27 장이 밀리고, 1 분 뒤에는 30 초 전 영상을 보고 판단한다. 두 가지로 막는다.

  • 구독 큐 깊이 1 — 밀린 프레임은 전송 계층에서 버려지고 최신 것만 남는다.
  • 처리 중 표시(busy_) — 처리 중에 콜백이 또 들어오면 즉시 돌아간다. 기본 실행기는 단일 스레드라 지금은 겹치지 않지만, 나중에 다중 스레드 실행기로 바꿔도 안전하도록 둔다.

2-2. 검출 메시지의 시각은 촬영 시각이다

추론이 끝난 시각이 아니라 입력 영상의 header 를 그대로 복사한다. 좌표 변환은 "그 시각의 로봇 자세"를 조회한다. 300 ms 걸린 추론의 완료 시각을 넣으면 0.3 m/s 로 달리던 로봇은 사람의 위치를 9 cm 어긋난 곳으로 계산한다. 코드로는 arr.header = msg->header 한 줄이다.

2-3. OpenCV 4.5.4 가 모델을 읽지 못할 때

C5 의 내보내기 옵션(opset=12)이면 대개 읽힌다. 실패하면 오류 문구로 판단한다 — 먼저 로드해 보고 판단하지, 미리 OpenCV 를 새로 빌드하지 않는다.

오류 문구뜻조치
Can't open file, No such file경로ls $MODELS. CMake 의 install(DIRECTORY models …) 가 있고 다시 빌드했는가
Unsupported … opset, Can't create layer … Split연산자 미지원Mac 에서 opset=12, simplify=True, dynamic=False 로 다시 내보낸다(C5 §3-4)
위를 해도 같은 종류의 오류OpenCV 4.5.4 의 한계C7 · C8 로 먼저 넘어간다 — Hailo 는 ONNX 를 쓰지 않는다. CPU 검출기를 꼭 살리려면 ONNX Runtime C++ 로 바꾼다
로드는 되는데 모양이 [1 x 84 x 8400] 이 아니다모델 세대 · 입력 크기 차이C5 §2-2. [1 x N x 6] 이면 nms=True 로 내보낸 것

3. 실습

3-1. 검출 노드 소스 C++

rpi5_vision/src/yolo_detector.cpp. 구조는 C4 의 노드와 같다 — 받는다 → cv::Mat → (전처리 → 추론 → 후처리) → 메시지 → 발행. 새로운 것은 가운데 괄호뿐이다. 파라미터 이름(model_path · names_path · conf_threshold · nms_threshold · input_size · class_filter)은 C8 의 Hailo 노드와 같다.

// yolo_detector -- /stereo/left/image_raw -> YOLOv8 (ONNX, OpenCV DNN, CPU) -> /detections   (camera guide C6)
//
// Same topic, message and parameter names as hailo_detect (C8): the overlay node and
// later consumers do not need to know which backend is running.
#include <algorithm>
#include <atomic>
#include <chrono>
#include <cmath>
#include <fstream>
#include <memory>
#include <stdexcept>
#include <string>
#include <vector>

#include "rclcpp/rclcpp.hpp"
#include "sensor_msgs/msg/image.hpp"
#include "vision_msgs/msg/detection2_d_array.hpp"
#include "cv_bridge/cv_bridge.h"
#include "image_transport/image_transport.hpp"
#include "opencv2/dnn.hpp"
#include "opencv2/imgcodecs.hpp"
#include "opencv2/imgproc.hpp"

namespace
{

// One detection in original-frame pixel coordinates.
struct Box
{
  cv::Rect rect;
  float score;
  int class_id;
};

// Resize keeping the aspect ratio into a size x size square and pad the rest with gray (114).
// scale / pad_x / pad_y are needed to map the boxes back to the original frame (C5 section 2-1).
cv::Mat letterbox(const cv::Mat & src, int size, float & scale, int & pad_x, int & pad_y)
{
  scale = std::min(static_cast<float>(size) / src.cols, static_cast<float>(size) / src.rows);
  const int new_w = static_cast<int>(std::round(src.cols * scale));
  const int new_h = static_cast<int>(std::round(src.rows * scale));
  pad_x = (size - new_w) / 2;
  pad_y = (size - new_h) / 2;
  cv::Mat resized;
  cv::resize(src, resized, cv::Size(new_w, new_h), 0, 0, cv::INTER_LINEAR);
  cv::Mat canvas(size, size, src.type(), cv::Scalar(114, 114, 114));
  resized.copyTo(canvas(cv::Rect(pad_x, pad_y, new_w, new_h)));   // the ROI is a view into canvas
  return canvas;
}

// Clears the busy flag when the scope ends, whatever the return path.
struct BusyGuard
{
  explicit BusyGuard(std::atomic<bool> & flag) : flag_(flag) {}
  ~BusyGuard() { flag_ = false; }
  std::atomic<bool> & flag_;
};

}  // namespace

class YoloDetector : public rclcpp::Node
{
public:
  YoloDetector()
  : Node("yolo_detector")
  {
    this->declare_parameter<std::string>("model_path", "");
    this->declare_parameter<std::string>("names_path", "");
    this->declare_parameter<int>("input_size", 640);
    this->declare_parameter<double>("conf_threshold", 0.25);
    this->declare_parameter<double>("nms_threshold", 0.45);
    this->declare_parameter<std::vector<std::string>>("class_filter", std::vector<std::string>{});
    this->declare_parameter<std::string>("test_image", "");   // if set: detect once on this file, print, exit

    const auto model_path = this->get_parameter("model_path").as_string();
    input_size_ = this->get_parameter("input_size").as_int();
    conf_thr_ = static_cast<float>(this->get_parameter("conf_threshold").as_double());
    nms_thr_ = static_cast<float>(this->get_parameter("nms_threshold").as_double());
    class_filter_ = this->get_parameter("class_filter").as_string_array();
    class_filter_.erase(std::remove(class_filter_.begin(), class_filter_.end(), std::string{}),
                        class_filter_.end());                   // YAML "class_filter: ['']" means no filter

    load_names(this->get_parameter("names_path").as_string());

    // Load the network once. Loading per frame would cost hundreds of ms every time.
    try {
      net_ = cv::dnn::readNetFromONNX(model_path);
    } catch (const cv::Exception & e) {
      RCLCPP_FATAL(this->get_logger(),
        "ONNX load failed: %s\n  check: (1) model_path  (2) exported with opset=12, simplify=True, dynamic=False"
        "\n  (3) otherwise OpenCV %s does not support an operator in this model (C6 section 2-3)",
        e.what(), CV_VERSION);
      throw;
    }
    net_.setPreferableBackend(cv::dnn::DNN_BACKEND_OPENCV);
    net_.setPreferableTarget(cv::dnn::DNN_TARGET_CPU);
    RCLCPP_INFO(this->get_logger(), "model loaded: %s (%zu classes, input %d, OpenCV %s)",
                model_path.c_str(), names_.size(), input_size_, CV_VERSION);

    const auto test_image = this->get_parameter("test_image").as_string();
    if (!test_image.empty()) {
      run_test_image(test_image);
      return;                            // main() sees test_mode() and exits without spinning
    }

    pub_ = this->create_publisher<vision_msgs::msg::Detection2DArray>(
      "/detections", rclcpp::QoS(1).best_effort());
    auto qos = rmw_qos_profile_sensor_data;   // BEST_EFFORT, VOLATILE ...
    qos.depth = 1;                            // ... and a queue of one: unprocessed frames are dropped
    sub_ = image_transport::create_subscription(
      this, "/stereo/left/image_raw",
      [this](const sensor_msgs::msg::Image::ConstSharedPtr & msg) { on_image(msg); }, "raw", qos);
  }

  bool test_mode() const { return test_mode_; }

private:
  void load_names(const std::string & path)
  {
    std::ifstream f(path);
    for (std::string line; std::getline(f, line);) {
      if (!line.empty()) {
        names_.push_back(line);
      }
    }
    if (names_.empty()) {
      RCLCPP_FATAL(this->get_logger(), "cannot read names_path '%s'", path.c_str());
      throw std::runtime_error("names file");
    }
  }

  // Frame -> boxes in original pixel coordinates. No ROS inside, so the callback and the
  // test path share it.
  std::vector<Box> detect(const cv::Mat & bgr)
  {
    float scale = 1.f;
    int pad_x = 0, pad_y = 0;
    const cv::Mat lb = letterbox(bgr, input_size_, scale, pad_x, pad_y);
    // 1/255 scaling, BGR -> RGB (swapRB = true), HWC -> NCHW [1, 3, S, S]
    cv::Mat blob = cv::dnn::blobFromImage(lb, 1.0 / 255.0, cv::Size(input_size_, input_size_),
                                          cv::Scalar(), true, false);
    net_.setInput(blob);
    std::vector<cv::Mat> outs;
    net_.forward(outs, net_.getUnconnectedOutLayersNames());
    cv::Mat out = outs[0];

    if (!shape_logged_) {   // first frame: must match what onnxruntime showed on the Mac (C5 section 3-4)
      RCLCPP_INFO(this->get_logger(), "output dims=%d shape=[%d x %d x %d]",
                  out.dims, out.size[0], out.size[1], out.size[2]);
      shape_logged_ = true;
    }

    const int num_classes = static_cast<int>(names_.size());
    cv::Mat rows;
    bool has_objectness = false;
    if (out.dims == 3 && out.size[1] == 4 + num_classes) {
      rows = out.reshape(1, out.size[1]).t();     // [84 x 8400] -> transpose -> [8400 x 84]   (YOLOv8 / v11)
    } else if (out.dims == 3 && out.size[2] == 5 + num_classes) {
      rows = out.reshape(1, out.size[1]);         // [25200 x 85]: already one row per candidate (YOLOv5)
      has_objectness = true;
    } else {
      throw std::runtime_error("unexpected output shape -- does names_path match the model's class count?");
    }
    const int cls_offset = has_objectness ? 5 : 4;

    std::vector<cv::Rect> boxes;
    std::vector<float> confs;
    std::vector<int> class_ids;
    for (int i = 0; i < rows.rows; ++i) {
      const float * r = rows.ptr<float>(i);
      // wrap the class-score section of this row without copying
      cv::Mat scores(1, num_classes, CV_32F, const_cast<float *>(r + cls_offset));
      cv::Point cls_pt;
      double max_score = 0.0;
      cv::minMaxLoc(scores, nullptr, &max_score, nullptr, &cls_pt);
      if (has_objectness) {
        max_score *= r[4];
      }
      if (max_score < conf_thr_) {
        continue;                                 // most of the 8400 candidates stop here
      }
      // (cx, cy, w, h) in letterbox coordinates -> original frame (C5 section 2-1)
      const float cx = (r[0] - pad_x) / scale;
      const float cy = (r[1] - pad_y) / scale;
      const float w = r[2] / scale;
      const float h = r[3] / scale;
      boxes.emplace_back(static_cast<int>(cx - w / 2), static_cast<int>(cy - h / 2),
                         static_cast<int>(w), static_cast<int>(h));
      confs.push_back(static_cast<float>(max_score));
      class_ids.push_back(cls_pt.x);
    }
    candidates_before_nms_ = boxes.size();

    std::vector<int> keep;
    cv::dnn::NMSBoxes(boxes, confs, conf_thr_, nms_thr_, keep);

    std::vector<Box> result;
    for (int idx : keep) {
      result.push_back(Box{boxes[idx], confs[idx], class_ids[idx]});
    }
    return result;
  }

  bool passes_filter(const std::string & name) const
  {
    return class_filter_.empty() ||
           std::find(class_filter_.begin(), class_filter_.end(), name) != class_filter_.end();
  }

  void on_image(const sensor_msgs::msg::Image::ConstSharedPtr & msg)
  {
    // Drop this frame if the previous one is still being processed (section 2-1).
    bool expected = false;
    if (!busy_.compare_exchange_strong(expected, true)) {
      dropped_++;
      return;
    }
    BusyGuard guard(busy_);
    const auto t0 = std::chrono::steady_clock::now();

    cv_bridge::CvImageConstPtr cv_ptr;
    try {
      cv_ptr = cv_bridge::toCvShare(msg, "bgr8");   // camera sends bgr8 -> shared, no copy
    } catch (const cv_bridge::Exception & e) {
      RCLCPP_ERROR_THROTTLE(this->get_logger(), *this->get_clock(), 2000, "cv_bridge: %s", e.what());
      return;
    }

    std::vector<Box> boxes;
    try {
      boxes = detect(cv_ptr->image);
    } catch (const std::exception & e) {
      RCLCPP_ERROR_THROTTLE(this->get_logger(), *this->get_clock(), 2000, "detect: %s", e.what());
      return;
    }

    vision_msgs::msg::Detection2DArray arr;
    arr.header = msg->header;   // capture time and frame id, not the inference time (section 2-2)
    for (const Box & b : boxes) {
      const std::string & name = names_[b.class_id];
      if (!passes_filter(name)) {
        continue;
      }
      vision_msgs::msg::Detection2D det;
      det.header = msg->header;
      det.bbox.center.position.x = b.rect.x + b.rect.width / 2.0;
      det.bbox.center.position.y = b.rect.y + b.rect.height / 2.0;
      det.bbox.size_x = b.rect.width;
      det.bbox.size_y = b.rect.height;
      vision_msgs::msg::ObjectHypothesisWithPose hyp;
      hyp.hypothesis.class_id = name;
      hyp.hypothesis.score = b.score;
      det.results.push_back(hyp);
      arr.detections.push_back(det);
    }
    pub_->publish(arr);

    const double ms =
      std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - t0).count();
    RCLCPP_INFO_THROTTLE(this->get_logger(), *this->get_clock(), 2000,
      "%zu det (%zu before NMS)  %.0f ms  dropped=%zu",
      arr.detections.size(), candidates_before_nms_, ms, dropped_.load());
  }

  // test_image parameter: run the same pipeline on one file and print the boxes (compare with C5).
  void run_test_image(const std::string & path)
  {
    test_mode_ = true;
    const cv::Mat img = cv::imread(path);
    if (img.empty()) {
      RCLCPP_FATAL(this->get_logger(), "cannot read test_image '%s'", path.c_str());
      throw std::runtime_error("test image");
    }
    const auto boxes = detect(img);
    RCLCPP_INFO(this->get_logger(), "test_image %s: %zu det (%zu before NMS)",
                path.c_str(), boxes.size(), candidates_before_nms_);
    for (const Box & b : boxes) {
      RCLCPP_INFO(this->get_logger(), "  %-12s %.2f  x=%d y=%d w=%d h=%d",
                  names_[b.class_id].c_str(), b.score, b.rect.x, b.rect.y, b.rect.width, b.rect.height);
    }
  }

  cv::dnn::Net net_;
  std::vector<std::string> names_;
  std::vector<std::string> class_filter_;
  int input_size_{640};
  float conf_thr_{0.25f};
  float nms_thr_{0.45f};
  bool shape_logged_{false};
  bool test_mode_{false};
  size_t candidates_before_nms_{0};
  std::atomic<bool> busy_{false};
  std::atomic<size_t> dropped_{0};

  image_transport::Subscriber sub_;
  rclcpp::Publisher<vision_msgs::msg::Detection2DArray>::SharedPtr pub_;
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<YoloDetector>();
  if (!node->test_mode()) {
    rclcpp::spin(node);
  }
  rclcpp::shutdown();
  return 0;
}

3-2. 그리기 노드 소스 C++

rpi5_vision/src/detection_overlay.cpp. 마지막 검출 결과를 현재 프레임 위에 그린다. 영상은 30 fps 로 오고 검출은 수백 ms 마다 오므로 박스가 물체보다 늦게 따라온다. 화면 왼쪽 위의 lag 가 그 지연(이 프레임의 촬영 시각 − 검출 결과의 촬영 시각)이다. C8 에서 이 숫자가 얼마나 줄어드는지 비교한다.

// detection_overlay -- draw /detections on /stereo/left/image_raw -> /stereo/left/annotated   (camera guide C6)
#include <algorithm>
#include <cstdio>
#include <memory>
#include <string>

#include "rclcpp/rclcpp.hpp"
#include "sensor_msgs/msg/image.hpp"
#include "vision_msgs/msg/detection2_d_array.hpp"   // Detection2DArray -> detection2_d_array.hpp
#include "cv_bridge/cv_bridge.h"
#include "image_transport/image_transport.hpp"
#include "opencv2/imgproc.hpp"

class DetectionOverlay : public rclcpp::Node
{
public:
  DetectionOverlay()
  : Node("detection_overlay")
  {
    pub_ = image_transport::create_publisher(this, "/stereo/left/annotated", rmw_qos_profile_sensor_data);

    // Only the newest detection result matters: depth 1, BEST_EFFORT (the detector publishes the same way).
    det_sub_ = this->create_subscription<vision_msgs::msg::Detection2DArray>(
      "/detections", rclcpp::QoS(1).best_effort(),
      [this](const vision_msgs::msg::Detection2DArray & msg) {
        last_det_ = msg;             // cache only; drawing happens in the image callback
        has_det_ = true;
      });

    sub_ = image_transport::create_subscription(
      this, "/stereo/left/image_raw",
      [this](const sensor_msgs::msg::Image::ConstSharedPtr & msg) { on_image(msg); },
      "raw", rmw_qos_profile_sensor_data);
  }

private:
  void on_image(const sensor_msgs::msg::Image::ConstSharedPtr & msg)
  {
    cv_bridge::CvImagePtr cv_ptr;
    try {
      cv_ptr = cv_bridge::toCvCopy(msg, "bgr8");   // we draw on it, so we need a copy (toCvShare is read-only)
    } catch (const cv_bridge::Exception & e) {
      RCLCPP_ERROR_THROTTLE(this->get_logger(), *this->get_clock(), 2000, "cv_bridge: %s", e.what());
      return;
    }
    cv::Mat & img = cv_ptr->image;

    if (has_det_) {
      for (const auto & det : last_det_.detections) {
        const auto & b = det.bbox;
        const int x1 = static_cast<int>(b.center.position.x - b.size_x / 2.0);
        const int y1 = static_cast<int>(b.center.position.y - b.size_y / 2.0);
        const int x2 = static_cast<int>(b.center.position.x + b.size_x / 2.0);
        const int y2 = static_cast<int>(b.center.position.y + b.size_y / 2.0);
        cv::rectangle(img, cv::Point(x1, y1), cv::Point(x2, y2), cv::Scalar(0, 255, 0), 2);

        std::string label = "?";
        if (!det.results.empty()) {
          char buf[64];
          std::snprintf(buf, sizeof(buf), "%s %.2f",
                        det.results[0].hypothesis.class_id.c_str(), det.results[0].hypothesis.score);
          label = buf;
        }
        cv::putText(img, label, cv::Point(x1, std::max(y1 - 6, 12)),
                    cv::FONT_HERSHEY_SIMPLEX, 0.6, cv::Scalar(0, 255, 0), 2);
      }

      // this frame's capture time - the detection's capture time = how old the boxes are
      const double lag_ms =
        (rclcpp::Time(msg->header.stamp) - rclcpp::Time(last_det_.header.stamp)).seconds() * 1000.0;
      char info[96];
      std::snprintf(info, sizeof(info), "det: %zu  lag: %.0f ms", last_det_.detections.size(), lag_ms);
      cv::putText(img, info, cv::Point(8, 22), cv::FONT_HERSHEY_SIMPLEX, 0.6, cv::Scalar(0, 255, 255), 2);
    }

    pub_.publish(cv_ptr->toImageMsg());   // header was copied by toCvCopy
  }

  // No mutex around last_det_: the default executor is single-threaded, so the two callbacks never overlap.
  image_transport::Subscriber sub_;
  image_transport::Publisher pub_;
  rclcpp::Subscription<vision_msgs::msg::Detection2DArray>::SharedPtr det_sub_;
  vision_msgs::msg::Detection2DArray last_det_;
  bool has_det_{false};
};

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<DetectionOverlay>());
  rclcpp::shutdown();
  return 0;
}

🤔 이해 확인

이 쪽에서 설명한 내용만으로 답할 수 있다. 답을 펼치기 전에 먼저 말로 답해 본다.

1. 검출 메시지의 header.stamp 에 추론 완료 시각을 넣으면 무엇이 잘못되는가.

좌표 변환은 그 시각의 로봇 자세를 조회한다. 추론에 300 ms 걸렸다면 로봇은 그만큼 움직였고, 물체의 위치를 300 ms 뒤의 자세 기준으로 계산해 수 cm ~ 수십 cm 어긋난다. 입력 영상의 header 를 그대로 복사한다.

2. 큐 깊이 1 과 처리 중 표시(busy_)는 각각 무엇을 막는가.

큐 1 은 전송 계층에서 밀린 프레임을 버려 옛 프레임을 차례로 처리하는 지연 누적을 막는다. busy_ 는 처리 중에 콜백이 또 실행되는 것(다중 스레드 실행기에서 가능)을 막아 추론 두 개가 겹치지 않게 한다.

3. conf_threshold 를 0.05 로 내리면 추론 시간은 그대로인데 왜 전체 처리 시간이 늘어나는가.

신경망 추론 시간은 입력 크기로만 정해진다. 그러나 점수 필터를 통과하는 후보가 수십 배 늘어 NMS 의 입력이 커지고, NMS 의 계산량은 후보 수의 대략 제곱으로 는다. 로그의 before NMS 개수와 ms 를 함께 보면 확인된다.

4. 그리기를 검출기 안에 넣지 않고 별도 노드로 둔 이유는 무엇인가.

검출기의 일은 /detections 를 발행하는 것뿐이어야 한다. 그리기를 나누면 C8 에서 검출기를 바꿔도 그리기 노드는 그대로 동작하고, 운용 중에는 그리기 노드를 끄고, /detections 만 필요한 소비자는 영상 없이 구독한다.
