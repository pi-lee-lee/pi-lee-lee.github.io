l-01 은 읽기만 했다. 포트를 열면 바이트가 흘러나오고, 초당 몇 개인지 셌다. 그 관찰로는 "선 반대편에 무언가가 있다"까지만 안다. 이 쪽은 처음으로 쓴다. 두 바이트를 보내고, 돌아오는 바이트가 내가 예상한 모양인지 본다. 모양이 맞으면 그 응답은 단순히 "값을 얻었다"는 뜻이 아니다. 내가 이 기기의 프로토콜을 옳게 이해했다는 것이 기기의 응답으로 확인된 것이다. 이 가이드에서 프로토콜을 다루는 모든 쪽이 이 확인 장치를 전제한다.

안전 — 이 쪽 내내 머리가 돈다고 간주한다 (L1 · L2)

제목의 L1 · L2 는 l-01 이 정한 안전 규칙이다(L1 = 보이지 않는 레이저, L2 = 도는 머리). A1M8 은 이 프로젝트의 라이다 모델(Slamtec RPLIDAR)이다. 데이터시트는 그 제조사 문서이고, 이 가이드는 rev.2.2 와 v3.0 두 판을 함께 읽는다.

레이저는 눈에 보이지 않는다. A1M8 의 광원은 785 nm(775~795 nm) 적외선이다.1 Class I 은 "정상 사용에서 안전"으로 분류된 등급이지만,2 보이지 않기 때문에 "지금 켜져 있다"는 감각이 생기지 않는다. 이 감각이 없다는 것이 조심하는 습관이 저절로 생기지 않는 실제 이유다. 스캔 창을 렌즈 높이에서 정면으로 들여다보지 않는다.

머리는 이 쪽의 실습 내내 돈다고 간주한다. 실습 C 의 lab_cmd_break 는 머리를 돌리고, 실습 A 의 lab_cmd 는 모터를 건드리지 않는다 — 포트를 열 때 머리가 어떻게 되는지는 l-01 §2-4 ② 의 확인 과제다. 이 쪽의 STOP 은 데이터 출력을 멈추고 모터는 끄지 않는다(§2-3). 레이저도 꺼진다는 것은 1세대 기록에만 있고, 데이터시트에는 없다. 등급은 NOMINAL(gen1-record) — 출처는 있지만 이 프로젝트에서 잰 값은 아닌 임시값이다(l-00 의 "값의 세 상태"). 이 장비에서는 §2-3 의 확인 과제로 남아 있다. 그래서 STOP 뒤에도 레이저가 켜져 있다고 간주한다. 바이트가 더 오지 않는다고 해서 머리가 멈춘 것은 아니다. 손 · 머리카락 · 천 · 케이블을 도는 머리에 가까이 두지 않고, 센서를 들어 올리거나 옮길 때는 모터가 멈춘 것을 확인한 뒤 든다. 머리가 계속 돌면 허브 쪽에서 라이다의 USB 케이블을 뽑는다(l-01 §1 의 L2).

2. 원리 — 왜 이 두 바이트이고, 왜 앞을 비워야 하는가

2-1. 명령에는 두 가지 꼴이 있다 — 그리고 어느 꼴인지는 명령 바이트 값이 정한다

이 기기에 보내는 요청은 두 가지 모양뿐이다.

 짧은 꼴 (페이로드 없음)      A5 | cmd
 긴   꼴 (페이로드 있음)      A5 | cmd | len | payload(len 바이트) | checksum

   A5        고정 머리 바이트 (SL_LIDAR_CMD_SYNC_BYTE)
   cmd       무엇을 요청하는가
   len       payload 의 바이트 수. 1바이트이므로 0~255
   checksum  앞의 "모든" 바이트를 XOR 한 값 — A5 부터 payload 마지막까지 전부

여기서 학습자가 가장 먼저 묻게 되는 것은 "어느 명령이 어느 꼴인가"다. 답은 규칙 하나다. SDK(Slamtec 이 공개한 라이다 통신 소스 코드 — 판은 아래 등급 상자와 그 각주)의 인코더는 명령 바이트의 비트 7을 보고 두 꼴을 가른다. 해당 조건문은 if (message->cmd & RPLIDAR_CMDFLAG_HAS_PAYLOAD) 이다.3 그 플래그 값은 0x80 이다.4 그래서 GET_INFO = 0x50 은 짧은 꼴이고 GET_LIDAR_CONF = 0x84 는 긴 꼴이다. 이 구분은 SDK 인코더가 그렇게 구현했다는 사실이고, 프로토콜 문서가 그렇게 규정했다는 주장이 아니다. 1차 문서가 없기 때문이다(§2-5).

체크섬이 앞의 모든 바이트를 XOR 한 값이라는 것은 같은 인코더 소스에서 읽을 수 있다. 인코더는 checksum = 0 으로 시작해 내보내는 바이트마다 checksum ^= currentTxByte 를 하고, 마지막 자리에 그 값을 쓴다.5 A5 도 cmd 도 len 도 XOR 에 들어간다. 이 셋 중 하나를 빼먹는 것이 이 쪽에서 가장 흔한 실수이고, 자기시험 벡터가 정확히 이 실수를 검출한다(§3-1-3).

손으로 한 번 계산해 보면 규칙을 기억하기 쉽다. GET_LIDAR_CONF 로 "모드가 몇 개인가"(0x70)를 묻는 요청은 아래처럼 만들어진다. 페이로드는 u32(부호 없는 32비트 정수) 리틀엔디안(LE — 낮은 자리 바이트가 먼저 오는 순서)이라 70 00 00 00 이다.

  A5 ^ 84 = 21        (머리 ^ 명령)
  21 ^ 04 = 25        (^ len)
  25 ^ 70 = 55        (^ payload[0])
  55 ^ 00 ^ 00 ^ 00 = 55
  -> A5 84 04 70 00 00 00 55
등급 — 확정(1차 소스) · 이 규칙은 두 출처가 서로를 확인한다

위 규칙은 Slamtec 의 SDK 소스(Slamtec/rplidar_sdk, master 브랜치)에서 직접 읽은 것이다.6 그리고 같은 규칙을 독립적으로 확인할 수 있다. 같은 모델을 쓴 1세대 기록에 긴 명령 한 줄 A5 82 05 00 00 00 00 00 22 가 남아 있다. 이 1세대 기록의 등급은 NOMINAL(gen1-record) 이다.7 이 명령의 마지막 바이트 22 를 위 규칙으로 다시 계산하면 그대로 나온다. 출처가 다른 둘이 같은 답을 내는 것이 지금 이 값에 줄 수 있는 가장 강한 근거다.

⚠ 이 값들은 ROS 2 라이다 드라이버 rplidar_ros(설치한 판 2.1.4)가 무엇을 하는가의 출처가 아니다. 기기가 쓰는 프로토콜의 출처다. 드라이버의 거동은 l-06 · l-07 에서 따로 본다.

2-2. 응답은 먼저 "얼마나 올 것인지"를 말한다 — 7바이트 기술자

응답이 있는 명령에 대해 기기는 본문을 바로 보내지 않는다. 먼저 기술자 7바이트가 온다. 구조는 SDK 헤더에 그대로 있다.8

  A5   5A   | ss ss ss ss |  tt
  --------    -----------    --
  머리 2B     u32 리틀엔디안  종류 1B      -> 1 + 1 + 4 + 1 = 7바이트

  u32 의 하위 30비트 = 뒤이어 올 본문의 바이트 수   (ANS_HEADER_SIZE_MASK 0x3FFFFFFF)
  상위  2비트        = subtype 플래그              (ANS_HEADER_SUBTYPE_SHIFT 30)

이 구조에서 세 가지를 알 수 있다.

  1. A5 5A 는 자기검증 장치다. 이 두 바이트가 오면, 내가 명령을 옳은 모양으로 만들었고 스트림의 정렬이 맞았다는 것을 기기가 확인해 준 것이다. 1차 문서가 없는 이 프로토콜에서 학습자가 가진 가장 확실한 근거가 이 두 바이트다.
  2. 본문 길이를 먼저 알려 준다. 그래서 "얼마나 읽을까"를 추측하지 않아도 된다. 타임아웃이 날 때까지 읽는 방식과 이 점이 다르다.
  3. 마스크는 선택이 아니다. 상위 2비트가 플래그라서, 마스크 없이 u32 를 그대로 읽으면 크기가 10억이 넘는 수로 나온다. 스캔처럼 끝없이 이어지는 응답에서 그 비트가 1 이기 때문이다. SDK 는 이 비트를 loop 플래그(응답이 끝없이 이어진다는 표시)로 읽는다.9 자기시험 벡터가 이 경우를 따로 채점한다.

GET_INFO 의 응답은 종류 0x04(SL_LIDAR_ANS_TYPE_DEVINFO)이고 본문은 20바이트다.10 왜 20인지는 구조체 정의로 계산할 수 있다.11 u8 model + u16 firmware_version + u8 hardware_version + u8 serialnum[16] = 1 + 2 + 1 + 16 = 20. 기술자에 적힌 크기와 구조체로 계산한 크기가 같은 것도 확인 항목 하나다.

읽는 쪽에도 같은 확인이 필요하다. 리눅스의 read(fd, buf, 7)(fd = 파일 기술자, open() 이 돌려준 번호)은 "7바이트를 읽어라"가 아니라 "지금 와 있는 것을 7바이트까지 달라"다. 바이트가 두 번에 나뉘어 도착하면 첫 read() 는 7보다 적게 돌려준다. 그래서 이 쪽의 read_exact()(전량)는 정한 시간 안에서 읽기를 되풀이해 n 바이트를 모으고, 모은 수를 돌려준다. 모자라면 parse_descriptor() 가 그 수를 보고 "기술자가 아니다"로 판정한다 — 시험 벡터 short read (6 B) 가 이 경우다. 20바이트 본문도 같은 함수로 읽는다.12

2-3. STOP 은 데이터를 멈추지 모터를 끄지 않는다

명령을 보내기 전에 기기의 데이터 출력을 멈춰야 한다. 이때 쓰는 명령이 STOP(A5 25)이다.13 그런데 이 이름은 오해하기 쉽다. 멈추는 것은 데이터이지 회전이 아니다. 아래 표의 DTR 은 시리얼 포트의 모뎀 제어선이다. 이 라이다의 USB 어댑터에서는 모터를 켜고 끄는 선으로 쓰인다고 알려져 있다(근거는 l-01 §2-4).

무엇이STOP 뒤에내가 어떻게 아는가

2-4. 왜 명령 앞마다 비워야 하는가 — tcflush() 로는 부족하다

기기는 응답을 요청과 짝지어 보내 주지 않는다. 선으로 바이트를 내보낼 뿐이다. 그래서 명령을 쓰기 전에 바이트가 계속 들어오고 있으면, 앞서 들어오던 바이트가 내 기술자 자리에서 읽힌다. 오류는 나지 않고, A5 5A 가 아닌 엉뚱한 두 바이트가 보인다. 이것이 이 쪽의 발동 확인 실습(§3-3)이 일부러 일으키는 고장이다.

tcflush(fd, TCIFLUSH) 는 커널이 받아 두고 아직 읽지 않은 입력 바이트를 버리는 함수다. 비우는 일을 이 한 줄로 끝낼 수 없는 이유는 버퍼가 한 군데가 아니기 때문이다. 아래 그림의 CP2102 는 라이다 USB 어댑터 안의 USB–시리얼 변환 칩(Silicon Labs)이다. FIFO 는 그 칩 안의 대기열이고, 먼저 들어온 바이트가 먼저 나간다.

  기기 --(선 위를 날고 있는 바이트)--> CP2102 칩의 FIFO --> USB --> 커널/OS 버퍼 --> 내 프로그램

  tcflush(TCIFLUSH) 가 비우는 곳               :  맨 오른쪽 하나
  비운 직후에도 계속 도착하는 것               :  왼쪽 셋에 남아 있던 것
  그것이 읽히는 자리                           :  "다음" 명령의 기술자 7바이트

그래서 drain() 은 한 번 비우는 함수가 아니라 새 바이트가 더 오지 않을 때까지 기다리며 읽어 버리는 함수다. "일정 시간 동안 새 바이트가 없었다"를 종료 조건으로 쓴다. 그 시간을 얼마로 둘지, 전체 대기 상한을 얼마로 둘지는 내가 정한다. §3-1-2 의 골격에 기본값이 인자로 있다. 헤더의 값은 고치지 않는다. §3-3-3 의 실험 도구에 --quiet · --stop-wait-ms 인자로 다른 값을 주고, 무엇이 달라지는지 적는다.

inline constexpr int kStopWaitMs = 50;   // after STOP, before drain. gen-1 rplidar_ctl.py:64.
inline constexpr int kDrainPollMs = 20;  // one wait inside drain(). gen-1 rplidar_ctl.py:57.

// Write one request. -> the bytes framed (for the log); empty if it could not be framed.
inline Bytes send(int fd, u8 cmd, const Bytes& payload = {}) {
  Bytes pkt = frame(cmd, payload);
  if (pkt.empty()) {
    std::printf("send: payload of %zu bytes cannot be framed\n", payload.size());
    return pkt;
  }
  std::size_t done = 0;
  while (done < pkt.size()) {            // write() may take fewer bytes than asked
    ssize_t w = ::write(fd, pkt.data() + done, pkt.size() - done);
    if (w < 0) {
      if (errno == EINTR) continue;
      std::printf("write: %s\n", std::strerror(errno));
      return pkt;
    }
    done += static_cast<std::size_t>(w);
  }
  tcdrain(fd);                           // wait until the bytes have left the UART
  return pkt;
}

// Read exactly n bytes, or fewer if timeout_ms (the whole budget) runs out or a stop
// signal arrives. read() returns what is there, not what you asked for -- this loops.
// -> bytes actually read.
inline std::size_t read_exact(int fd, u8* buf, std::size_t n, int timeout_ms) {
  using clock = std::chrono::steady_clock;
  const auto deadline = clock::now() + std::chrono::milliseconds(timeout_ms);
  std::size_t got = 0;
  while (got < n && !stop_requested()) {
    auto left = std::chrono::duration_cast<std::chrono::milliseconds>(deadline - clock::now());
    if (left.count() <= 0) break;
    got += read_some(fd, buf + got, n - got, static_cast<int>(left.count()));
  }
  return got;
}

// Read the 7-byte response descriptor. -> Descriptor, or nullopt on timeout / garbage.
inline std::optional<Descriptor> descriptor(int fd) {
  u8 b[kDescriptorLen];
  std::size_t got = read_exact(fd, b, kDescriptorLen, kReadTimeoutMs);
  return parse_descriptor(b, got);
}

// scripts/lidar_lab/include/lidar_lab/repr.hpp -- print a double the way Python's repr()
// does.  (l-02, given in full)
// Shortest digits that read back to the same double (std::to_chars), placed by Python's
// rule: exponent < -4 or >= 16 -> "1e-05" / "1e+16" form, otherwise plain digits, and a
// whole number keeps ".0". So a value quoted on a page (360.00000000000006,
// -2.4492935982947064e-16, 5.999999999999999 ...) prints with the same characters here.
#pragma once

#include <charconv>
#include <cmath>
#include <cstdlib>
#include <string>
#include <system_error>

namespace lidar_lab {

inline std::string repr_double(double v) {
  if (std::isnan(v)) return "nan";
  if (std::isinf(v)) return v < 0 ? "-inf" : "inf";

  char buf[64];
  auto res = std::to_chars(buf, buf + sizeof buf, v, std::chars_format::scientific);
  if (res.ec != std::errc()) return "?";
  std::string s(buf, res.ptr);  // e.g. "-1.2345e+02", "1e+16", "0e+00"

  std::string sign;
  if (!s.empty() && s[0] == '-') {
    sign = "-";
    s.erase(0, 1);
  }
  const std::size_t e = s.find('e');
  std::string digits = s.substr(0, e);
  if (digits.size() > 1) digits.erase(1, 1);  // drop the '.' after the first digit
  const int exp = std::atoi(s.c_str() + e + 1);
  const int nd = static_cast<int>(digits.size());

  if (exp < -4 || exp >= 16) {  // exponent form: d[.ddd]e+XX, at least two exponent digits
    std::string out = sign + digits.substr(0, 1);
    if (nd > 1) out += "." + digits.substr(1);
    const int a = exp < 0 ? -exp : exp;
    out += exp < 0 ? "e-" : "e+";
    if (a < 10) out += "0";
    out += std::to_string(a);
    return out;
  }
  if (exp < 0) {  // 0.000ddd
    return sign + "0." + std::string(static_cast<std::size_t>(-exp - 1), '0') + digits;
  }
  if (nd <= exp + 1) {  // whole number: pad with zeros, keep ".0"
    return sign + digits + std::string(static_cast<std::size_t>(exp + 1 - nd), '0') + ".0";
  }
  return sign + digits.substr(0, static_cast<std::size_t>(exp + 1)) + "." +
         digits.substr(static_cast<std::size_t>(exp + 1));
}

// Bytes as upper-case hex with no separator ("A525"), and back. from_hex skips spaces and
// returns a vector whose allocation is EXACTLY its size, so a read one past the end leaves
// the allocation and the _ub build reports it (push_back alone leaves spare capacity).
inline std::string hex(const std::vector<std::uint8_t>& b) {
  static const char* d = "0123456789ABCDEF";
  std::string s;
  for (std::uint8_t x : b) {
    s += d[x >> 4];
    s += d[x & 0x0F];
  }
  return s;
}
inline std::vector<std::uint8_t> from_hex(const std::string& h) {
  auto nib = [](char c) -> int {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'a' && c <= 'f') return c - 'a' + 10;
    if (c >= 'A' && c <= 'F') return c - 'A' + 10;
    return -1;
  };
  std::vector<std::uint8_t> out;
  int hi = -1;
  for (char c : h) {
    int v = nib(c);
    if (v < 0) continue;
    if (hi < 0) {
      hi = v;
    } else {
      out.push_back(static_cast<std::uint8_t>(hi << 4 | v));
      hi = -1;
    }
  }
  return std::vector<std::uint8_t>(out.begin(), out.end());
}

}

/* 완결 코드 T1 - scripts/lidar_lab/include/lidar_lab/cmd.hpp (frame) */
inline Bytes frame(u8 cmd, const Bytes& payload = {}) {
  if (payload.empty()) return Bytes{kSync, cmd};
  if (payload.size() > kMaxPayload) return {};
  Bytes out{kSync, cmd, static_cast<u8>(payload.size())};
  out.insert(out.end(), payload.begin(), payload.end());
  u8 sum = 0;
  for (u8 b : out) sum = static_cast<u8>(sum ^ b);
  out.push_back(sum);
  return out;
}

코드 설명

  • if (payload.empty()) return Bytes{kSync, cmd}; — 짧은 꼴. Bytes{…} 는 중괄호 안의 값으로 벡터를 만든다. 길이도 체크섬도 붙이지 않는다.
  • if (payload.size() > kMaxPayload) return {}; — len 은 한 바이트라 255 를 넘는 길이는 적을 수 없다. 빈 줄을 받은 send() 는 send: payload of … bytes cannot be framed 를 찍고 아무것도 쓰지 않는다.
  • Bytes out{kSync, cmd, static_cast<u8>(payload.size())}; — 머리 셋. payload.size() 는 std::size_t 라 중괄호 안에서는 u8 로 밝혀 바꿔야 한다(흔한 실수 마지막 행).
  • out.insert(out.end(), payload.begin(), payload.end()); — 페이로드를 머리 뒤에 이어 붙인다.
  • u8 sum = 0; for (u8 b : out) sum = static_cast<u8>(sum ^ b); — 지금까지 만든 모든 바이트(머리 A5 포함)를 XOR 한다(§2-1). sum ^ b 의 결과는 int 라 u8 로 밝혀 되돌린다.
  • out.push_back(sum); — 체크섬은 맨 끝에 한 번 붙는다.
  • 골격의 자리표시 세 줄((void)cmd; · (void)payload; · return {};)은 지웠다.

  • 다르게 써도 되는 곳 — XOR 줄은 sum ^= b; 로 써도 된다. 경고가 없고 시험도 통과한다.21

쓰는 API — std::vector 의 empty() · size() · push_back(x)(끝에 하나를 더한다) · insert(위치, 처음, 끝)([처음, 끝) 의 원소를 위치 앞에 넣는다).

흔한 실수 — 마지막 행만 컴파일러가 알린다. 나머지는 시험만 검출한다.21

inline std::optional<Descriptor> parse_descriptor(const u8* b, std::size_t n) {
  if (n != kDescriptorLen) return std::nullopt;
  if (b[0] != kAnsSync1 || b[1] != kAnsSync2) return std::nullopt;
  std::uint32_t u = static_cast<std::uint32_t>(b[2]) |
                    static_cast<std::uint32_t>(b[3]) << 8 |
                    static_cast<std::uint32_t>(b[4]) << 16 |

코드 설명

  • if (n != kDescriptorLen) return std::nullopt; — 길이를 가장 먼저 본다. 이 검사보다 앞에서 b[i] 를 읽으면 짧은 줄의 끝 너머를 읽는다(흔한 실수 첫 행).
  • if (b[0] != kAnsSync1 || b[1] != kAnsSync2) return std::nullopt; — 두 바이트를 다 본다. || 는 둘 중 하나라도 다르면 참이다.

  • std::uint32_t u = static_cast<std::uint32_t>(b[2]) | … << 24; — 리틀엔디안은 낮은 자리 바이트가 먼저 온다. b[2] 가 가장 낮은 8비트, b[5] 가 가장 높은 8비트다. << 8 은 한 바이트만큼 위 자리로 올린다.

    먼저 std::uint32_t 로 바꾸므로 미는 계산이 부호 없는 32비트 안에서 일어난다.

  • return Descriptor{u & kSizeMask, b[6]}; — 하위 30비트만 크기다. Descriptor{…} 는 칸 차례대로 값을 넣어 만든다. 반환형이 std::optional<Descriptor> 이므로 값이 든 optional 이 된다.
  • 골격의 자리표시 세 줄((void)b; · (void)n; · return std::nullopt;)은 지웠다.

  • 다르게 써도 되는 곳 — 둘이다.21

    ① std::memcpy(&u, b + 2, 4); 로 네 바이트를 복사해도 시험을 통과한다. 다만 이 방법은 기계가 리틀엔디안일 때만 같은 값을 낸다(Pi 와 Mac 은 둘 다 리틀엔디안이다). 시프트 조립은 기계의 바이트 순서와 상관없다.

    ② 캐스트를 빼고 b[2] | b[3] << 8 | … 로 써도 시험을 통과한다. 이때 계산은 int 로 된다. 이 가이드는 계산하는 타입을 밝혀 쓴다.

기기 자리에는 fork() 로 만든 자식 프로세스가 있다. 자식은 스캔처럼 바이트를 흘려 보내고, stop() 이 보낸 바이트를 받아 적는다. tcflush() · tcdrain() 은 tty 가 아닌 fd 에서 실패한다. 두 함수의 반환값은 쓰지 않으므로 동작은 같다. 그래서 이 시험이 채점하는 것은 읽는 반복(T3)과 세 걸음의 차례(T4)다. 커널 버퍼를 비우는 일과 실제 기기가 반응하는 시간은 §3-1-4 의 왕복과 §3-3 의 실습 C 에서 본다.

벡터는 아홉이다. 시각은 주로 아래쪽 한계로 본다 — 너무 일찍 돌아오는 것이 틀린 판의 모습이다. 위쪽 한계는 넉넉하게 두어 느린 진단 빌드도 통과한다. 시험을 빨리 끝내려고 drain() 에는 기본값보다 짧은 quiet_s = 0.15 를 넘긴다. stop() 은 기본값 그대로 부른다.

// scripts/lidar_lab/tests/test_cmd_port.cpp -- grading vectors for drain() and stop().
// Feeds a pipe / a socket pair instead of the tty: no lidar, no port, no motor.
//   pi$ scripts/lidar_lab/build/test_cmd_port && scripts/lidar_lab/build/test_cmd_port_ub
//
// How a vector works
//   - a child process (fork) plays the device on the other end. It writes 64 B every 10 ms
//     (a scan running, about 6.4 kB/s) and, for stop(), reads what we send it.
//   - tcflush() and tcdrain() fail on a pipe or a socket (not a tty). drain() and stop() ignore
//     their return value, so the run is the same; only the reading loop is graded here.
//   - "bytes left" = what is still waiting 0.1 s after the function returned: the bytes the
//     next descriptor() would read first.
//   - times are checked mostly from below (a function that returns too early is the mistake).
//     The upper bounds are wide, so a slow build (_ub) still passes.
//   - a timer (setitimer -> SIGALRM) runs on_stop_signal from serial.hpp. In the "Ctrl-C" vector
//     it is the stop. In the others it is a watchdog: a loop that never ends is stopped there.

#include <string>

using clock_type = std::chrono::steady_clock;

double since(clock_type::time_point t0) {
  return std::chrono::duration<double>(clock_type::now() - t0).count();
}

std::string secs(double s) {
  char b[32];
  std::snprintf(b, sizeof b, "%.3f s", s);
  return b;
}

// Run the timer once after `s` seconds (0 = cancel). SIGALRM -> on_stop_signal (sets g_stop).
void alarm_after(double s) {
  itimerval t{};
  t.it_value.tv_sec = static_cast<long>(s);
  t.it_value.tv_usec = static_cast<long>((s - static_cast<long>(s)) * 1e6);
  setitimer(ITIMER_REAL, &t, nullptr);
}

int waiting(int fd) {
  int n = 0;
  if (ioctl(fd, FIONREAD, &n) != 0) return -1;
  return n;
}

void sleep_s(double s) { std::this_thread::sleep_for(std::chrono::duration<double>(s)); }

// ---- the child: a device on the other end. Only system calls, ends with _exit ----

// Write 64 B every 10 ms for stream_s, then after gap_s write `late` bytes once, then sit
// silent (holding the write end open) until killed.
pid_t spawn_writer(int wfd, double stream_s, double gap_s, int late) {
  pid_t pid = fork();
  if (pid != 0) return pid;
  signal(SIGPIPE, SIG_IGN);
  u8 chunk[64];
  for (u8& c : chunk) c = 0x3E;  // looks like scan points, never A5 5A
  const auto t0 = clock_type::now();
  while (since(t0) < stream_s) {
    if (::write(wfd, chunk, sizeof chunk) < 0) _exit(1);
    usleep(10000);
  }
  if (late > 0) {
    usleep(static_cast<useconds_t>(gap_s * 1e6));
    if (::write(wfd, chunk, static_cast<std::size_t>(late)) < 0) _exit(1);
  }
  for (;;) pause();
}

// A device on a socket. stream = true: 64 B every 10 ms until it has read 2 bytes (STOP),
// then silence, then 115 B (23 points) 30 ms after the STOP. stream = false: silent.
// Everything it reads goes to `report` when the other side closes (or after 6 s).
// ours = our end of the socket, and the read end of `report`: the child closes its copies,
// or our close() would never reach it.
pid_t spawn_device(int sfd, int report, int ours, int ours_report, bool stream) {
  pid_t pid = fork();
  if (pid != 0) return pid;
  close(ours);
  close(ours_report);
  signal(SIGPIPE, SIG_IGN);
  fcntl(sfd, F_SETFL, fcntl(sfd, F_GETFL) | O_NONBLOCK);
  u8 chunk[115];
  for (u8& c : chunk) c = 0x3E;
  u8 got[64];
  std::size_t n = 0;
  bool burst_due = false;
  clock_type::time_point t_stop{};
  const auto t0 = clock_type::now();
  while (since(t0) < 6.0) {
    pollfd p{};
    p.fd = sfd;
    p.events = POLLIN;
    if (::poll(&p, 1, 10) > 0) {
      ssize_t r = ::read(sfd, got + n, sizeof got - n);
      if (r == 0) break;  // the other side closed: report
      if (r > 0) {
        n += static_cast<std::size_t>(r);
        if (stream && !burst_due && n >= 2) {
          burst_due = true;
          t_stop = clock_type::now();
        }
      }
      if (n == sizeof got) break;
    }
    if (stream && !burst_due && ::write(sfd, chunk, 64) < 0) {
      // the socket is full or closed: the next round tries again or sees the close
    }
    if (burst_due && since(t_stop) >= 0.030) {
      if (::write(sfd, chunk, sizeof chunk) < 0) _exit(1);
      burst_due = false;
      stream = false;
    }
  }
  if (::write(report, got, n) < 0) _exit(1);
  _exit(0);
}

void end_child(pid_t pid) {
  kill(pid, SIGKILL);
  waitpid(pid, nullptr, 0);
}

// What the device read, as hex. Waits up to 2 s for the report, then gives up.
std::string read_report(int report) {
  pollfd p{};
  p.fd = report;
  p.events = POLLIN;
  if (::poll(&p, 1, 2000) <= 0) return "(no report)";
  u8 b[64];
  ssize_t r = ::read(report, b, sizeof b);
  if (r <= 0) return "";
  return hex(Bytes(b, b + r));
}

struct DrainRun {
  int left;
  double elapsed;
};

// One drain() on a fresh pipe. The writer streams for stream_s, then `late` bytes after gap_s.
// The timer fires at alarm_s. left = -1 when it is not measured.
DrainRun drain_run(double stream_s, double gap_s, int late, double quiet_s, double limit_s,
                   double alarm_s, bool measure_left) {
  int p[2];
  if (pipe(p) != 0) {
    std::printf("pipe failed\n");
    return {-1, -1.0};
  }
  pid_t pid = spawn_writer(p[1], stream_s, gap_s, late);
  g_stop = 0;
  alarm_after(alarm_s);
  const auto t0 = clock_type::now();
  drain(p[0], quiet_s, limit_s);
  const double el = since(t0);
  alarm_after(0.0);
  g_stop = 0;
  int left = -1;
  if (measure_left) {  // wait until the writer has written all it will, + 0.1 s
    const double done = stream_s + gap_s + 0.1;
    if (el < done) sleep_s(done - el);
    left = waiting(p[0]);
  }
  end_child(pid);
  close(p[0]);
  close(p[1]);
  return {left, el};
}

struct StopRun {
  std::string sent;
  int left;
  double elapsed;
};

// One stop() on a fresh socket pair, the device streaming (or silent) for 0.2 s before it.
StopRun stop_run(bool stream) {
  int s[2];
  int r[2];
  if (socketpair(AF_UNIX, SOCK_STREAM, 0, s) != 0 || pipe(r) != 0) {
    std::printf("socketpair / pipe failed\n");
    return {"", -1, -1.0};
  }
  pid_t pid = spawn_device(s[1], r[1], s[0], r[0], stream);
  close(s[1]);
  close(r[1]);
  sleep_s(0.2);
  g_stop = 0;
  alarm_after(4.5);  // watchdog: stop() with the default limit_s 3.0 must be back before this
  const auto t0 = clock_type::now();
  stop(s[0]);
  const double el = since(t0);
  alarm_after(0.0);
  g_stop = 0;
  sleep_s(0.1);
  const int left = waiting(s[0]);
  close(s[0]);  // the device reports what it read when it sees this
  std::string sent = read_report(r[0]);
  end_child(pid);
  close(r[0]);
  return {sent, left, el};
}

할 일 — 커널 버퍼를 비운 뒤, 포트가 quiet_s 동안 조용해질 때까지 들어오는 바이트를 읽어 버린다. 전체 시간은 limit_s 를 넘지 않는다. Ctrl-C 를 받으면(stop_requested()) 곧 돌아온다.

완결 코드

/* 완결 코드 T3 - scripts/lidar_lab/include/lidar_lab/cmd_port.hpp (drain) */
inline void drain(int fd, double quiet_s = 0.25, double limit_s = 3.0) {
  using clock = std::chrono::steady_clock;
  using sec = std::chrono::duration<double>;
  tcflush(fd, TCIFLUSH);
  const auto t0 = clock::now();
  auto last = t0;
  u8 junk[256];
  while (!stop_requested() && sec(clock::now() - t0).count() < limit_s) {
    if (read_some(fd, junk, sizeof junk, kDrainPollMs) > 0) {
      last = clock::now();
    } else if (sec(clock::now() - last).count() >= quiet_s) {
      return;
    }
  }
}

코드 설명

  • using clock = …; using sec = std::chrono::duration<double>; — 짧은 이름 둘. sec(a - b).count() 는 두 시각의 차이를 초 단위 double 로 낸다.
  • tcflush(fd, TCIFLUSH); — 커널에 쌓인 것만 버린다(§2-4). 이것으로 끝나지 않는 이유가 아래의 반복이다.
  • const auto t0 = clock::now(); auto last = t0; — 시작 시각과 "마지막으로 바이트가 온 시각". last 는 처음에 시작 시각으로 둔다.
  • u8 junk[256]; — 버릴 바이트를 받는 자리.
  • while (!stop_requested() && sec(clock::now() - t0).count() < limit_s) — 정지 신호를 받았거나 상한이 지나면 끝난다. 스캔이 흐르는 중이면 포트가 조용해지지 않으므로, 이 상한이 없으면 함수가 돌아오지 않는다.
  • if (read_some(fd, junk, sizeof junk, kDrainPollMs) > 0) { last = clock::now(); } — 최대 20 ms 기다려 온 것을 읽는다. 무언가 왔으면 시각을 고친다. 기다림은 poll() 이 하므로 CPU 를 쓰지 않는다(l-01).
  • else if (sec(clock::now() - last).count() >= quiet_s) { return; } — 이번에 아무것도 오지 않았고, 마지막 바이트 뒤로 quiet_s 가 지났으면 끝난다.
  • 골격의 자리표시 세 줄((void)fd; · (void)quiet_s; · (void)limit_s;)은 지웠다.

  • 다르게 써도 되는 곳 — 읽기 전에 ioctl(fd, FIONREAD, &n) 로 쌓인 수를 먼저 물어도 된다(l-01 의 count_bytes()). 다만 기다리는 일은 poll() 에 맡긴다 — 빈 반복으로 기다리면 CPU 를 쓴다.

쓰는 API — tcflush(fd, TCIFLUSH)(<termios.h>) · std::chrono::steady_clock::now(). read_some() · stop_requested() 는 l-01 의 serial.hpp 에 있다.

  • ② 이미 스캔이 흐르고 있었다. 그렇다면 l-01 에서 센 바이트 수가 설명된다.

③ 은 frame() 이 벡터를 통과했다면 거의 제외된다. 무엇이 일어났는지를 적는 것이 이 걸음의 과제이고, 답이 어느 쪽이든 다음 쪽으로 갈 수 있다.

/* 완결 코드 T5 - scripts/lidar_lab/src/cmd.cpp (main) */
int main(int argc, char** argv) {
  install_stop_handler();
  const int fd = open_port(argc > 1 ? argv[1] : kDev);
  if (fd < 0) return 1;

  stop(fd);
  send(fd, CMD_GET_INFO);
  u8 raw[kDescriptorLen];
  const std::size_t got = read_exact(fd, raw, kDescriptorLen, kReadTimeoutMs);
  std::printf("descriptor");
  for (std::size_t i = 0; i < got; ++i) std::printf(" %02X", raw[i]);
  const auto d = parse_descriptor(raw, got);
  if (!d) {  // do NOT read a body after a bad descriptor
    std::printf("   -> not a descriptor (%zu bytes)\n", got);
    ::close(fd);
    return 1;
  }
  std::printf("   size=%u type=0x%02X\n", static_cast<unsigned>(d->size), d->ans_type);

  // u8 model | u16 firmware (little endian: minor, major) | u8 hardware | u8 serial[16]
  constexpr std::size_t kInfoLen = 20;  // sl_lidar_cmd.h:334-340
  if (d->size != kInfoLen) {
    std::printf("unexpected size %u, want %zu -- not reading the body\n",
                static_cast<unsigned>(d->size), kInfoLen);
    ::close(fd);
    return 1;
  }
  u8 body[kInfoLen];
  const std::size_t nb = read_exact(fd, body, kInfoLen, kReadTimeoutMs);
  if (nb != kInfoLen) {
    std::printf("short body: %zu of %zu bytes\n", nb, kInfoLen);
    ::close(fd);
    return 1;
  }
  std::printf("model      0x%02X\n", body[0]);
  std::printf("firmware   %u.%02u\n", static_cast<unsigned>(body[2]), static_cast<unsigned>(body[1]));
  std::printf("hardware   %u\n", static_cast<unsigned>(body[3]));
  std::printf("serial     ");
  for (std::size_t i = 4; i < kInfoLen; ++i) std::printf("%02X", body[i]);
  std::printf("  byte order: as-received\n");
  ::close(fd);
  return 0;
}

  • install_stop_handler(); … if (fd < 0) return 1; — 골격과 같은 머리 세 줄이다(전량).
  • stop(fd); send(fd, CMD_GET_INFO); — 앞을 비우고 묻는다(§2-4).
  • u8 raw[kDescriptorLen]; const std::size_t got = read_exact(…); — 원본을 내가 읽는다. got 은 실제로 받은 수다(0 ~ 7).
  • std::printf(" %02X", raw[i]); — 받은 만큼만 찍는다. %02X 는 두 자리 대문자 16진이다.
  • const auto d = parse_descriptor(raw, got); if (!d) { … return 1; } — 빈 optional 이면 본문을 읽지 않는다. 읽으면 흐르던 점을 본문으로 착각한다. auto 는 오른쪽 식의 타입(std::optional<Descriptor>)을 컴파일러가 정하게 한다.
  • d->size · d->ans_type — optional 안의 Descriptor 칸을 꺼낸다. 값이 있는 것을 확인한 뒤에만 쓴다.
  • constexpr std::size_t kInfoLen = 20; if (d->size != kInfoLen) { … } — 구조체로 계산한 크기(§2-2)와 다르면 다른 응답이다. SCAN 의 기술자라면 5 가 온다(§3-3-1).
  • read_exact(fd, body, kInfoLen, kReadTimeoutMs) · if (nb != kInfoLen) — 본문도 나뉘어 올 수 있다(§2-2 끝 문단).
  • std::printf("firmware %u.%02u\n", body[2], body[1]) 꼴 — u16 리틀엔디안이라 body[1] 이 하위(minor), body[2] 가 상위(major)다. minor 는 두 자리로 찍는다(§3-1-1 표의 "firmware 를 읽는 법").
  • for (std::size_t i = 4; i < kInfoLen; ++i) std::printf("%02X", body[i]); — serial 16바이트를 받은 순서 그대로 찍는다. 그래서 줄 끝에 byte order: as-received 를 붙인다.
  • ::close(fd); return 0; — 성공. 실패 경로도 모두 ::close(fd) 뒤에 1 을 돌려준다.
  • 골격의 자리표시 세 줄(안내 printf · ::close(fd); · return 1;)은 위의 경로들로 바뀌었다.

  • 다르게 써도 되는 곳 — serial 을 뒤에서부터 찍어도 된다. 그때는 줄 끝의 방향 표시를 바꾼다(위의 "serial 은 값 + 읽은 방향" 상자).

쓰는 API — std::printf 의 형식: %02X(두 자리 16진) · %u(부호 없는 정수) · %zu(std::size_t). ::close(fd)(<unistd.h>).

3-3. 실습 C — drain 을 빼고 일부러 깨뜨린다

3-3-1. 확인

깨뜨리려면 먼저 바이트가 계속 들어오는 상태를 만들어야 한다. 그 상태는 SCAN(A5 20)을 보내면 만들어진다. 기기가 측정값을 끝없이 보내기 시작한다.

⚠ SCAN 도 먼저 기술자로 답한다 — 이 점을 모르면 실습에서 엉뚱한 기술자를 읽는다

SCAN 을 보내면 점이 곧바로 오는 것이 아니라 기술자 7바이트가 먼저 오고 그 뒤부터 점이 흐른다. 그 기술자는 종류가 0x81(SL_LIDAR_ANS_TYPE_MEASUREMENT)이고 크기는 점 하나의 길이인 5 다.27 끝없이 이어지는 응답이라 상위 플래그 비트가 1 이 된다.28 즉 A5 5A 05 00 00 40 81 같은 모양이다. §3-1-3 의 시험 파일에서 [synthetic] 이라고 표시한 그 벡터가 여기서 실제로 보일 수 있는 바이트다. 같은 모델을 쓴 1세대 스크립트도 SCAN 뒤에 7바이트를 읽어 A5 5A 인지 확인하고 버린다. 이 1세대 스크립트 기록의 등급은 NOMINAL(gen1-record) 이다.29

그래서 SCAN 을 보낸 직후에 GET_INFO 를 보내고 7바이트를 읽으면, 돌아오는 것은 깨진 바이트가 아니라 SCAN 자신의 정상 기술자다. 그 기술자는 이 실습이 보려는 것이 아니다. GET_INFO 는 점이 실제로 흐르기 시작한 뒤에 보내야 한다. 이 실습의 도구는 그 7바이트를 먼저 읽어 scan 줄에 찍고, 점이 흐르게 둔 뒤에 GET_INFO 를 보낸다.

이 실습의 도구는 lab_cmd_break(§3-3-3)다. SCAN 앞에 motor(fd, true) 로 머리를 돌리고, 끝에 stop(fd) 와 motor(fd, false) 를 부른다 — l-03 의 진입점과 같은 순서다. 확인할 것은 두 가지이고, 도구가 둘 다 한 줄씩 찍는다. 첫째, 바이트가 실제로 흐르고 있는가. waiting 줄의 수가 0 이 아니면 흐른다. 그 수는 ioctl(fd, FIONREAD, &n) 의 n 이다 — l-01 의 count_bytes() 가 쓴 요청이다. 둘째, 내가 그 흐름을 멈출 수 있는가. drain 으로 실행했을 때 drained 줄이 0 이면 stop() 뒤 흐름이 멎은 것이다. 멈출 수 없으면 이 실습을 시작하지 않는다. 포트에 바이트가 계속 들어오는 상태로 두고 끝내면 다음 쪽이 같은 증상으로 시작한다.

안전 (L1 · L2)

이 실습 동안 기기는 측정을 한다. 레이저가 켜지고 머리는 계속 돈다. 손을 스캔 면에 넣지 않고, 실습이 끝나면 도구가 마지막에 stopped 줄을 찍었는지 본 뒤 자리를 뜬다.

lab_cmd_break 는 정상으로 끝나든, 기술자가 깨져 1 로 끝나든, Ctrl-C 로 끊든 main() 끝의 stop(fd) · motor(fd, false) 를 지난다. 중단(abort)되거나 신호로 비정상 종료되면 그 두 줄을 지나지 않는다. 끝난 뒤에도 머리가 돌면 코드로는 멈출 수 없다. 허브 쪽에서 라이다의 USB 케이블을 뽑는다(l-01 §1 의 L2).

3-3-3. 실험 도구 놓기 — 전량

이 실습의 코드는 전량 제공이다. 새 파일 src/cmd_break.cpp 가 실행 파일 lab_cmd_break 가 된다. 채울 자리는 없다. 도구가 부르는 frame() · parse_descriptor() · drain() · stop() 은 내가 T1 ~ T4 에서 쓴 것이다. 그래서 test_cmd · test_cmd_port 가 통과한 뒤에 빌드한다.

실험의 조건은 실행 인자로 바꾼다. 소스 파일은 고치지 않는다.

끝내는 길은 하나다. 실험 함수 run() 이 어디서 돌아오든 main() 끝의 stop(fd) · motor(fd, false) 를 지난다. 종료 코드는 0(GET_INFO 의 기술자가 왔다) · 1(오지 않았다 — 이것이 관찰값이다) · 2(인자가 틀렸다)다.

// scripts/lidar_lab/src/cmd_break.cpp -- break the descriptor on purpose: ask GET_INFO while
// a scan is flowing, with or without the drain in front.  (l-02 3-3, given in full)
//   pi$ scripts/lidar_lab/build/lab_cmd_break /dev/lidar drain      control: stop() first
//   pi$ scripts/lidar_lab/build/lab_cmd_break /dev/lidar nodrain    no stop(), no drain()
//   options  --wait-ms <n>       how long the points flow before GET_INFO (default 1000)
//            --stop-wait-ms <n>  drain only: the wait after STOP (default kStopWaitMs)
//            --quiet <s>         drain only: drain(fd, <s>) (default: drain()'s own quiet_s)
//   With either drain option the tool does stop()'s three steps itself -- cmd_port.hpp stays as is.
// It spins the head (motor(fd, true)). Every way out of run() passes the stop(fd) and
// motor(fd, false) at the end of main() (L2). It calls your T1 .. T4 -- fill them first.
// Exit code: 0 = a GET_INFO descriptor came back, 1 = it did not (the observation), 2 = usage.
#include <chrono>
#include <cstddef>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <thread>

#include <sys/ioctl.h>
#include <unistd.h>

#include "lidar_lab/cmd.hpp"
#include "lidar_lab/cmd_port.hpp"
#include "lidar_lab/serial.hpp"

using namespace lidar_lab;

namespace {

int bytes_waiting(int fd) {  // the same request as l-01 count_bytes()
  int n = 0;
  if (ioctl(fd, FIONREAD, &n) != 0) return -1;
  return n;
}

void print_hex(const char* label, const u8* b, std::size_t n) {
  std::printf("%-10s", label);
  for (std::size_t i = 0; i < n; ++i) std::printf(" %02X", b[i]);
}

// One experiment. Starts the scan, lets it flow, then asks GET_INFO. -> exit code (see top).
int run(int fd, bool use_drain, int wait_ms, int stop_wait_ms, double quiet_s) {
  stop(fd);  // start from a quiet port
  motor(fd, true);
  send(fd, CMD_SCAN);
  u8 scan[kDescriptorLen];  // SCAN answers with its own descriptor first (3-3-1 box)
  const std::size_t sg = read_exact(fd, scan, kDescriptorLen, kReadTimeoutMs);
  print_hex("scan", scan, sg);
  if (sg != kDescriptorLen) std::printf("   -> %zu of %zu bytes", sg, kDescriptorLen);
  std::printf("\n");
  std::this_thread::sleep_for(std::chrono::milliseconds(wait_ms));  // let the points flow
  if (stop_requested()) return 1;
  std::printf("waiting    %d bytes before GET_INFO\n", bytes_waiting(fd));
  if (use_drain) {
    if (stop_wait_ms < 0 && quiet_s < 0) {
      stop(fd);
    } else {  // stop()'s steps with other waits
      send(fd, CMD_STOP);
      std::this_thread::sleep_for(
          std::chrono::milliseconds(stop_wait_ms < 0 ? kStopWaitMs : stop_wait_ms));
      if (quiet_s < 0) drain(fd);
      else drain(fd, quiet_s);
    }
    std::printf("drained    %d bytes waiting after STOP + drain\n", bytes_waiting(fd));
  }
  send(fd, CMD_GET_INFO);
  u8 raw[kDescriptorLen];
  const std::size_t got = read_exact(fd, raw, kDescriptorLen, kReadTimeoutMs);
  print_hex("descriptor", raw, got);
  const auto d = parse_descriptor(raw, got);
  if (!d) {
    std::printf("   -> not a descriptor (%zu bytes)\n", got);
    return 1;
  }
  std::printf("   size=%u type=0x%02X\n", static_cast<unsigned>(d->size), d->ans_type);
  if (d->size != 20) {  // GET_INFO answers 20 (sl_lidar_cmd.h:334-340)
    std::printf("unexpected size %u, want 20 -- not reading the body\n",
                static_cast<unsigned>(d->size));
    return 1;
  }
  return 0;  // the body is left on the port; the stop(fd) in main() drains it
}

int usage() {
  std::printf("usage: lab_cmd_break <dev> drain|nodrain [--wait-ms <0..10000>]"
              " [--stop-wait-ms <0..1000>] [--quiet <s>]\n");
  return 2;
}

}  // namespace

int main(int argc, char** argv) {
  if (argc < 3) return usage();
  const char* dev = argv[1];
  const bool use_drain = std::strcmp(argv[2], "drain") == 0;
  if (!use_drain && std::strcmp(argv[2], "nodrain") != 0) return usage();
  int wait_ms = 1000;
  int stop_wait_ms = -1;  // < 0: kStopWaitMs
  double quiet_s = -1.0;  // < 0: drain()'s default
  for (int i = 3; i < argc; i += 2) {
    if (i + 1 >= argc) return usage();
    char* end = nullptr;
    if (std::strcmp(argv[i], "--wait-ms") == 0) {
      const long v = std::strtol(argv[i + 1], &end, 10);
      if (*end != '\0' || v < 0 || v > 10000) return usage();
      wait_ms = static_cast<int>(v);
    } else if (std::strcmp(argv[i], "--stop-wait-ms") == 0 && use_drain) {
      const long v = std::strtol(argv[i + 1], &end, 10);
      if (*end != '\0' || v < 0 || v > 1000) return usage();
      stop_wait_ms = static_cast<int>(v);
    } else if (std::strcmp(argv[i], "--quiet") == 0 && use_drain) {
      quiet_s = std::strtod(argv[i + 1], &end);
      if (*end != '\0' || !(quiet_s > 0.0 && quiet_s <= 3.0)) return usage();
    } else {
      return usage();
    }
  }

  install_stop_handler();
  const int fd = open_port(dev);
  if (fd < 0) return 1;
  std::printf("mode       %s  wait=%d ms", use_drain ? "drain" : "nodrain", wait_ms);
  if (use_drain && stop_wait_ms < 0 && quiet_s < 0) std::printf("  stop()");
  if (stop_wait_ms >= 0) std::printf("  stop-wait=%d ms", stop_wait_ms);
  if (quiet_s >= 0) std::printf("  quiet=%.3f s", quiet_s);
  std::printf("\n");
  const int rc = run(fd, use_drain, wait_ms, stop_wait_ms, quiet_s);
  stop(fd);          // data off -- on every way out of run()
  motor(fd, false);  // motor off (L2)
  std::printf("stopped    STOP sent, motor off\n");
  ::close(fd);
  return rc;
}

기기는 요청과 응답을 짝지어 주지 않는다. 선으로 바이트를 내보낼 뿐이고, 내 쪽에서는 "지금 읽는 7바이트가 기술자다"라고 내가 가정할 뿐이다. 앞서 들어오던 바이트가 남아 있으면 읽는 위치가 그만큼 어긋난다. 프로토콜에는 "여기가 경계다"라고 표시해 주는 장치가 없으므로 오류가 날 자리가 없다. 그 7바이트는 무의미한 값이 아니라 측정점이다. 5바이트짜리 점(l-03 이 다룬다)들이 기술자 자리에서 읽힌 것이고, 그래서 값이 5바이트 주기로 비슷하게 반복되는 모양을 띤다. 그리고 tcflush(fd, TCIFLUSH) 한 줄로 안 되는 이유는 버퍼가 한 군데가 아니기 때문이다. OS 버퍼를 비워도 CP2102 의 FIFO 와 선 위에서 전송 중이던 바이트가 그 뒤에 도착한다(§2-4). 그래서 drain 은 "비우는" 함수가 아니라 "새 바이트가 더 오지 않을 때까지 기다리며 읽어 버리는" 함수다.

6. (안전) 이 쪽의 실습 내내 머리가 돈다고 간주한다. STOP 을 보냈고 데이터가 멎었다 — 이제 센서를 들어 옮겨도 되는가?

안 된다. 데이터가 멎은 것과 회전이 멎은 것은 다른 일이다(§2-3). STOP 뒤에도 모터는 돌고, 데이터가 멈췄다는 인상 때문에 오히려 방심하기 쉽다. 옮기기 전에 모터가 멈춘 것을 확인한다. 머리가 계속 돌면 허브 쪽에서 라이다의 USB 케이블을 뽑는다(l-01 §1 의 L2). 그리고 옮긴 뒤에는 케이블 여유를 다시 본다: 케이블이 당기면 센서가 자리에서 밀리고, 그러면 뒤 쪽들의 거리·각도 판정이 통째로 어긋난다. 레이저 쪽은 더 단순하다 — 785 nm 는 켜져 있어도 보이지 않으므로 "확인하고 조심한다"가 성립하지 않는다. 그래서 "스캔 창을 정면에서 들여다보지 않는다"를 보고 판단하는 일이 아니라 습관으로 둔다. Class I 은 정상 사용에서 안전하다는 등급이지, 들여다봐도 된다는 뜻이 아니다.

7. 내 model · firmware · hardware 가 1세대 기록과 전부 같게 나왔다. "같은 기기다"라고 적어도 되는가?

안 된다. 세 값은 같은 모델이면 같을 수 있는 값이다 — 개체를 가르는 값이 아니다. 같다는 것은 "다르지 않다"까지만 보여 준다. 개체를 가를 수 있는 유일한 값은 serial 인데, 1세대 기록에 시리얼 문자열 자체가 없다 — 대조할 상대가 없다. 그래서 이 표로는 동일성을 증명할 수 없다. 추론은 한 방향으로만 성립한다: 다르면 "다른 개체 또는 다른 상태"의 증거가 된다. 특히 firmware 가 다르면 지원하는 스캔 모드 목록이 통째로 달라질 수 있어 l-05 의 표가 바뀐다. 그래서 이 쪽이 하는 일은 판정이 아니라 재료를 만드는 것이고, 노트에는 값과 "같음/다름"까지만 적는다.
