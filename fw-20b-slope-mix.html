1. 개요 — 기울기는 끊는 조건이 아니라 나누는 입력이다

fw-20a 까지의 듀티는 바퀴마다 PID 하나가 만들었다. 이 쪽은 그 식을 "속도 몫 + 가중치 × PID"로 바꾸고, 가중치를 앞뒤 축의 하중 몫에서 얻는다. 경사에서는 뒤축이 더 무거우므로 뒷바퀴가 더 큰 출력을 받는다. 기울기가 커도 출력을 끊지 않고 버틴다 — 끊으면 차체가 제어 없이 굴러 내려간다.

새로 쓰는 코드는 slope.h(하중 몫 · 경사 상태 · 내리막 직진 · 들림 판정)와 mix.h(속도 몫 표 · PID 출력 범위), 그리고 control.c 의 경사 층과 루프 순서다. 묶음 전체의 순서와 09a 와 나눠 가진 확인은 fw-20a §1 에 있다.

2. 원리 — 하중 몫과 출력 합성

2-10. 경사 출력 조정 — 기울기로 끊지 않고, 하중을 따라 출력을 나눈다

이 프로젝트는 기울기를 안전 조건으로 쓰지 않는다(fw-18 §2-5). 짐을 실은 채 경사에서 출력을 끊으면 차체가 제어 없이 굴러 내려가기 때문이다. 감속기는 일반 기어라 바퀴 쪽에서 돌리면 모터가 따라 돈다(역구동). 듀티 0 의 단락 제동은 속도에 비례하는 힘이라 경사에서 차체를 멈춰 두지 못하고, EN 이 LOW 가 되면 그 제동도 없다.1 그래서 기울기는 출력을 조정하는 입력으로 쓴다. 이 절은 그 조정을 다섯으로 나눠 설명하고, 실습 G(§3-G)가 그것을 만든다.

① 하중 몫 — 가속도계 두 성분으로 앞축 · 뒤축의 수직항력 비를 구한다

오르막에서는 하중이 뒤축으로, 내리막에서는 앞축으로 옮겨 간다. 평지에서 앞으로 가속할 때도 뒤축으로 옮겨 간다. 차체 기준 가속도계의 앞방향 성분 f_fwd 와 위방향 성분 f_up, 무게중심 높이 h, 무게중심에서 앞축 · 뒤축까지의 수평 거리 l_f · l_r 로 앞축이 받는 몫은 다음과 같다.

w_front = (f_up × l_r − f_fwd × h) / (f_up × (l_f + l_r))
w_rear  = 1 − w_front
경사 θ 에 서 있으면 f_fwd = g·sinθ, f_up = g·cosθ 이므로  w_front = (l_r·cosθ − h·sinθ) / L
  • 가속도계는 기울기와 가속을 구분하지 못한다. 하중 이동에는 둘이 다 들어가므로 구분할 필요가 없다 — 각도가 아니라 가속도 성분을 그대로 쓰는 이유다.
  • 질량은 약분되어 필요 없다.
  • w_front 가 0 이 되는 f_fwd / f_up = l_r / h 가 앞바퀴가 뜨는 경계다.

② 듀티 = 속도 몫 + 가중치 × PID

듀티_i = ff_i + w_축 × u_i
  ff_i  = 바퀴 i 의 속도 몫 표(공중에서 잰 값) × (표를 잰 때의 버스 전압 ÷ 지금 버스 전압)
  w_축  = 2 × 그 축의 하중 몫  (아래로 MIX_W_MIN 에서 자름, 평지 = 1)
  u_i   = 바퀴 i 의 속도 PID 출력
  • 속도 몫(앞먹임)은 바퀴를 그 속도로 헛돌리기만 하는 데 드는 듀티다. 하중과 상관없이 어느 바퀴든 필요하므로 가중치를 곱하지 않는다. 곱하면 가벼운 축의 바퀴가 목표 속도를 내지 못하고 차체에 끌려가며 제동이 된다. 같은 속도에 드는 듀티는 버스 전압에 반비례하므로 전압으로 보정한다.
  • 가중치는 PID 출력에만 곱한다. 바퀴가 미끄러지지 않으면 같은 쪽 앞뒤 바퀴는 같은 속도로 돌고, 두 PID 가 보는 속도 오차가 같다. 같은 오차에 다른 가중치를 곱하므로 힘이 하중 비율대로 나뉜다. 바퀴별 PID 만 있을 때는 가벼운 축이 헛돈 뒤에 무거운 축이 더 낸다. 이 식은 헛돌기 전에 나눈다.
  • PID 범위는 틱마다 (LIMIT − ff) ÷ w 로 다시 잡는다. 그래야 합이 듀티 한계를 넘지 않고, pid.c 의 "포화하면 적분을 되돌린다"(fw-13)가 그대로 와인드업을 막는다. PID 뒤에서 곱하거나 자르면 적분은 그 뒤에서 계속 쌓인다.

가중치는 kp 처럼 고정된 값이 아니라 틱마다 바뀌는 값이다. 상황에 따라 게인을 바꾸는 이 방식을 게인 스케줄링이라고 한다. 하중 몫은 h 를 쓰므로 짐을 실으면 실제와 어긋난다. 어긋나도 배분이 덜 맞을 뿐 위험하지는 않다 — 뒤집힘은 ③ 이 막고, ③ 은 h 를 쓰지 않는다.

③ 들림 방지 — 피치 각속도 · 누적 변화 · 거리당 변화가 모두 넘을 때

앞바퀴가 내는 힘은 앞축 하중이 0 으로 가면 함께 0 으로 간다. 그래서 앞바퀴는 자기 힘으로 앞을 들어 올리지 못한다. 뒷바퀴는 앞이 들리는 동안에도 계속 밀 수 있다. 그래서 들림이 시작되면 그 축(앞이 들리면 뒤축)의 PID 상한을 지금 출력에서 묶고 조금씩 내린다. 바닥값(LIFT_CAP_FLOOR) 아래로는 내리지 않는다 — 다 내리면 경사에서 뒤로 밀린다.

상황피치 변화걸러 내는 조건
문턱 · 엘리베이터 틈짧게 몇 도 오르고 멈춘다누적 변화 ≤ LIFT_DPITCH_MAX
경사 진입경사각만큼 오르지만, 차체가 축간거리만큼 가면서 기운다이동 거리당 변화 ≤ LIFT_DPITCH_PER_M_MAX
실제 들림거의 제자리에서 계속 기운다각속도 · 누적 · 거리당 셋을 다 넘는다

거리는 가장 느린 바퀴의 이동 거리로 잰다. 들림 중에 뒷바퀴가 헛돌면 거리가 부풀어 판정을 놓치기 때문이다. 묶을 축은 각속도의 부호로 고른다. 평지의 턱에서는 두 가중치가 다 1 이라 가중치로는 고를 수 없다.

④ 경사 상태 · 버팀 · 주행 불가

  • 경사 상태 — 걸러진 |f_fwd / f_up|(= tan 기울기)가 SLOPE_ON 이상이면 들어가고, SLOPE_OFF 아래가 정해 둔 시간 동안 이어지면 나온다. 두 값 사이의 띠가 상태가 깜박이는 것을 막는다. 경사 상태에서 목표가 0 이면 PID 가 중력을 거스르는 듀티를 내어 정지를 유지한다. 이것을 버팀이라고 부른다. 명령 워치독이 걸려도 경사 상태에서는 PID 를 리셋하지 않는다 — 리셋하면 적분이 지워져 P 항만 남고 미끄러진다.
  • 주행 불가 — 비가 SLOPE_LIMIT(tan 40° = 0.839) 이상이면 들어간다. 그동안 MCU 는 명령의 직진 성분 가운데 내려가는 쪽만 받고 좌우 차이(회전)는 버린다 — 경사에서 돌면 옆으로 미끄러진다. Pi 는 이 상태를 보고 올라온 반대 방향으로 직진해 평지까지 내려간다. 40° 는 정사각형에 가까운 차체에서 무게중심이 가운데일 때 앞축 하중이 0 이 되는 45° 보다 아래로 잡은 값이고, 짐 없는 차체 기준이다. 짐을 높이 실으면 그 경계가 내려간다.2
  • 평지까지 미루는 것 둘 — 저전압의 릴레이 차단과 링크 끊김 10 s 전원 내림은 경사 상태에서 하지 않는다. 저전압이면 버티면서 내려가는 명령만 받고, 평지에 와서 끊는다. 경사에서 버티는 조건은 넷이다: 워치독 · IMU 침묵 · 보호(트립한 바퀴만 0) · 저전압. 과전류는 전류 자체가 위험이라 경사에서도 끊는다.
  • IMU 샘플이 오래되면 가중치는 1 로 돌아가고, 경사 상태와 주행 불가는 마지막 값을 유지한다.

모터로 버틸 수 없는 경우(과전류 차단, 전원 꺼짐, EN LOW)에는 경사에서 굴러 내려간다. 막으려면 전원이 없을 때 걸리는 기계식 브레이크가 필요하다. 이 프로젝트는 다루지 않는다.

3. 실습

실습 G 는 바닥(09a 세팅 D)에서, fw-20a 의 실습 C 뒤에 한다. 호스트 시험은 차체가 없는 날 Mac 에서 먼저 해 둔다.

채울 자리마다 힌트 카드가 있다 — 읽는 순서

골격의 채울 자리에는 TODO(you) [T1] 처럼 번호가 붙어 있고(이 쪽은 T1 ~ T8 — slope.h · mix.h · control.c), 그 주석 안에 번호 걸음이 있다. 먼저 걸음을 보고 직접 써 본다. 막히면 "직접 채우기" 절(§3-G-3)에서 같은 번호의 힌트 카드를 연다. 카드에는 그 자리의 완결 코드와, 그 코드를 줄마다 풀어 쓴 설명이 있다. 칸은 언제나 같다: 할 일 · 완결 코드 · 코드 설명 · 쓰는 API · 흔한 실수 · 확인.

Mac 의 호스트 시험은 PASS slope 309 cases · PASS mix 23 cases 이고, -fsanitize=undefined,address 를 붙여도 경고와 오류가 없다. arm-none-eabi-gcc 컴파일(-c -Wall -Wextra)은 경고 0 이다. T1 ~ T6 은 순수 파일이라 보드 없이 Mac 에서 끝까지 채점된다. T7 · T8 은 펌웨어 빌드(경고 0)와 보드의 관찰로 확인한다.

붙여 넣는 것으로 끝내지 않는다 — 설명을 읽고 줄마다 "왜 이 줄이 여기 있는가"를 말할 수 있게 된 뒤, 카드를 접고 직접 친다.

/* 1차 저역 통과. alpha = dt / (tau + dt). 모터 진동이 가속도계에 그대로 들어오므로 몫이 떨리지 않게 거른다 */
static inline float slope_lpf(float prev, float x, float alpha)
{
  return prev + alpha * (x - prev);
}

/* 경사 비 |f_fwd / f_up| = tan(기울기). f_up <= 0 이면 -1(판정하지 않음) - 호출자는 상태를 그대로 둔다 */

     4) 오래되지 않았으면: 하중 몫 -> 앞 · 뒤 가중치, 경사 비 -> 경사 상태 · 주행 불가 히스테리시스
     5) 가장 느린 바퀴의 이동 거리로 들림 판정. 판정이 서는 틱에 그 축의 지난 출력에서 묶음 상한을 시작하고,
        틱마다 LIFT_DECAY 만큼 내리되 LIFT_CAP_FLOOR 아래로는 내리지 않는다
     6) s_drive 에 DRIVE_SLOPE · DRIVE_NO_GO · DRIVE_LIFT 를 모은다
     채우기 시작하면 아래 두 줄(빌드용 자리표시)은 지운다. */
  (void)meas; (void)s_slope_cfg; (void)s_nogo_cfg; (void)s_lift_cfg; (void)s_ff; (void)s_imu_seq; (void)s_lift_prev;
  s_w[0] = 1.0f; s_w[1] = 1.0f; s_drive = 0u;
}

/* TODO(you) [T8] 의 완결 코드 - 측정 -> 경사 층 -> PID -> 게이트 · 보호 · 안전 -> 출력, 이 순서 */
void control_step_1khz(void)      /* 1 kHz ISR, 선점 우선순위 1 */
{
  /* TODO(you) [T8]: 이 함수를 새 순서로 다시 쓴다 - 힌트 카드 T8
     0) 명령 워치독 - 경사 상태에서는 PID 를 리셋하지 않는다
     1) 엔코더 넷을 연달아 읽는다            2) slope_layer_step(meas)
     3) 목표 정리(버팀 · 저전압 · 주행 불가)   4) 바퀴마다 속도 몫 + 가중치 x PID, PID 범위를 이번 틱 값으로
     5) 1차 게이트(지난 틱 조건 · ARMED · EN)  6) 보호 넷   7) safety_step(이번 틱 보호 비트, 경사 상태)
     8) 2차 게이트(이번 틱 조건, 경사에서 버틸 수 있으면 끊지 않음)   9) motor_set 넷을 연달아   10) step 포획
     채우기 전까지는 아래 옛 본문을 그대로 둔다. 빌드용으로 더한 첫 줄 (void) 은 채우기 시작하면 옛 본문과 함께 지운다. */
  (void)s_on_cfg; (void)s_fx; (void)s_fz; (void)s_nogo; (void)s_lift; (void)s_lcap; (void)s_u; (void)s_cond_prev; (void)slope_layer_step;
  /* 1. 명령 워치독 (2-12) */
  const uint32_t age = (uint32_t)(tick_get_ms() - s_last_cmd_ms);   /* 한 바퀴 돌아도(wrap) 안전한 뺄셈 */
  if (age > CMD_WATCHDOG_MS) {
    s_target_packed = 0u;                                            /* 만료 중에는 틱마다: 목표 둘 다 0 */
    s_wd_stopped = 1u;                                               /* 표시. 지우는 쪽은 control_set_target() 뿐 */
    for (uint8_t i = 0u; i < (uint8_t)NW; i++) { pid_reset(&s_pid[i]); }   /* 과거를 들고 가지 않는다 (2-5) */
  }

  /* 1b. 안전 상태기계 (fw-18 2-10). 입력은 전부 이번 틱보다 먼저 정해진 값이라 PID 앞에 둔다.
         보호 래치는 지난 틱의 것이다 - 트립한 바퀴는 아래에서 같은 틱에 끊기고, 나머지 셋은 1 ms 뒤에 끊긴다 */
  uint16_t prot_bits = 0u;           /* 바퀴 i 의 PROT_* 3 비트를 3*i 에 - EVT_PROTECT 의 detail */
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) { prot_bits |= (uint16_t)((s_prot[i].tripped & 0x7u) << (3u * i)); }
  const uint8_t cond = safety_step(age, prot_bits, false);   /* 조건 래치(SAFE_BIT). 셋째 인자(경사 상태)는 T8 전까지 false (fw-20) */
  const bool    armed   = (power_get_state() == POWER_ARMED);   /* 상태는 ISR 이 바꾸고 */
  const uint8_t en_mask = motor_enable_mask();                  /* EN 핀은 main 이 나중에 쓴다 - 둘 다 봐야 듀티가 실제로 나간다 */

  /* 2..5 바퀴마다: 측정 -> 오차 -> PID -> (보호) -> 부호 -> 듀티 */
  const uint32_t tgt_now = s_target_packed;  /* 이 틱에 쓸 목표를 한 번만 읽는다 - 네 바퀴가 같은 명령을 본다 */
  int16_t duty[NW];                      /* PID 가 낸 명령 [permille]. 전진 = + (목표 · 측정과 같은 부호 규약) */
  float   meas[NW];                      /* 측정 속도 [mm/s]. 6. 의 포획이 다시 쓴다 */
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) {
    meas[i]     = (float)encoder_delta(i) * TICK_TO_MM_S;      /* 1 ms 당 카운트 -> mm/s */
    int16_t tgt = target_side(tgt_now, (uint8_t)(i & 1u));     /* 짝수 = 왼쪽, 홀수 = 오른쪽 */
    float   u   = pid_step(&s_pid[i], (float)tgt - meas[i]);   /* 오차 -> [permille], 이미 ±DUTY_LIMIT_BENCH_PERMILLE 안 */
    duty[i]     = (int16_t)u;

    if (cond != 0u || !armed || (en_mask & (1u << i)) == 0u) { /* fw-18: 어느 조건이든 1 이면 네 바퀴 듀티 0 - 끊는 레벨 0 은 fault 의 정의다 (2-9).
                                                                  계약 바이트가 아니라 cond 로: bit[] 배정과 상관없이 걸린다 (2-3).
                                                                  protect_step() 앞에 둔다: 보호가 실제로 나가는 듀티 0 을 봐야
                                                                  "밀었는데 안 돈다"(STALL · FBLOST) 로 잘못 래치하지 않는다.
                                                                  ARMED 아님 · 이 바퀴 EN LOW 도 같다: 사전충전 중 명령에 네 바퀴가
                                                                  FBLOST 로 래치됐다. 둘 다 보면 EN 이 바뀌는 순간 듀티가 0 이다(power.c I5) */
      duty[i] = 0;
      pid_reset(&s_pid[i]);
    }

    /*c test*/
    /* 2차 (실습 C, 3-3-4 의 3): PID 와 motor_set() 사이에 보호가 앉는다. 실습 B 를 구울 때는 아래 여섯 줄 앞에 // 를 붙여 막는다 (줄 끝 주석 때문에 블록 주석으로 감싸면 중첩된다) */
    const protect_in_t in = { tgt, (int32_t)meas[i], duty[i] };
    if (protect_step(&s_prot[i], &s_prot_cfg, &in) != 0u) {
      duty[i] = 0;                                             /* 이 바퀴만 끊는다. 넷을 다 세울지는 fw-18 의 결정 */
      pid_reset(&s_pid[i]);                                    /* 다시 시작할 때 과거를 들고 가지 않는다 (2-5) */
      HAL_GPIO_WritePin(LD3_GPIO_Port, LD3_Pin, GPIO_PIN_SET); /* 빨강 = fault 래치 */
    }

    motor_set(i, (int16_t)(s_motor_sign[i] * duty[i]));        /* MOTOR_SIGN 이 "전진" 을 드라이버의 부호로 바꾼다 (fw-11).
                                                                  motor_set() 이 내 벤치 상한으로 한 번 더 자른다 */
  }
  

  /* 6. step 실행 중이면 한 행을 포획한다. 저장만 하고 절대 찍지 않는다 (2-9). */
  if (s_cap_left > 0u && s_cap_n < STEP_CAP_MAX) {
    if (s_cap_n == 0u) { s_cap_t0 = tick_get_ms(); }           /* 첫 행의 틱. 그래서 t_ms 는 행 번호와 같다(틱을 빠뜨리지 않았다면) */
    step_row_t *r = &s_cap[s_cap_n++];                         /* 다음 빈 행을 가리키고, 행 수를 하나 올린다 */
    float m = meas[s_cap_wheel];
    if (m >  32767.0f) { m =  32767.0f; }                      /* int16 에 담기 전에 자른다 (2-13: gdb 뒤의 큰 튐) */
    if (m < -32768.0f) { m = -32768.0f; }
    r->t_ms   = (uint16_t)(tick_get_ms() - s_cap_t0);
    r->target = target_side(tgt_now, (uint8_t)(s_cap_wheel & 1u));
    r->meas   = (int16_t)(m + ((m >= 0.0f) ? 0.5f : -0.5f));   /* 반올림: 자르기 전에 0.5 를 더한다(음수는 뺀다) */
    r->duty   = duty[s_cap_wheel];
    r->prot   = s_prot[s_cap_wheel].tripped;                   /* 2차 (3-3-4 의 3). 실습 B 에서는 이 자리에 0u */
    --s_cap_left;
  }
}

3-G-3. 직접 채우기 — 정답 대신 벡터

두 시험 파일은 저장소에 이미 있다(firmware/host_tests/). 전량을 아래에 둔다. 기댓값은 손으로 셈한 값이 아니라 식에 딱 떨어지는 수를 넣어 고른 것이다(무게중심 h = l_f = l_r = 200 mm 이면 앞축 몫 = 0.5 − 0.5 × f_fwd/f_up).

/* firmware/host_tests/test_slope.c - 하중 이동 몫(slope.h)을 Mac 에서. MCU 도 HAL 도 없다. */
#include <stdio.h>
#include "Control/slope.h"

static int cases = 0;
#define CHECK(c) do { cases++; if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); return 1; } } while (0)
#define NEAR(a, b) ((a) - (b) < 1e-4f && (b) - (a) < 1e-4f)

/* 시험용 고정값이지 권고가 아니다. 셈을 눈으로 확인하도록 딱 떨어지는 수를 골랐다:
   h = lf = lr = 200 mm 이면 w_front = 0.5 - 0.5 * (f_fwd / f_up) */
static const slope_cfg_t CFG = { .h_mm = 200.0f, .lf_mm = 200.0f, .lr_mm = 200.0f };

int main(void)
{
  /* 1. 평지 정지: 앞뒤 반반 */
  CHECK(NEAR(slope_front_share(&CFG, 0.0f, 1000.0f), 0.5f));

  /* 2. 오르막(f_fwd / f_up = 0.3): 앞 0.35 - 하중이 뒤로 간다 */
  CHECK(NEAR(slope_front_share(&CFG, 300.0f, 1000.0f), 0.35f));

  /* 3. 내리막은 거울: 앞 0.65 */
  CHECK(NEAR(slope_front_share(&CFG, -300.0f, 1000.0f), 0.65f));

  /* 4. 45 도 정지(f_fwd = f_up): 이 기하(lr / h = 1)에서는 앞 몫 0 = 앞이 뜨는 경계 */
  CHECK(NEAR(slope_front_share(&CFG, 707.0f, 707.0f), 0.0f));

  /* 5. 경계 너머는 0 으로 자른다(앞이 이미 떴다), 반대쪽은 1 */
  CHECK(NEAR(slope_front_share(&CFG, 2000.0f, 1000.0f), 0.0f));
  CHECK(NEAR(slope_front_share(&CFG, -2000.0f, 1000.0f), 1.0f));

  /* 6. 같은 경사라도 앞으로 가속하면 하중이 더 뒤로 간다 - 가속도계가 그것을 이미 담고 있다 */
  CHECK(slope_front_share(&CFG, 400.0f, 1000.0f) < slope_front_share(&CFG, 300.0f, 1000.0f));

  /* 7. 샘플 없음(0, 0) · 뒤집힘(f_up < 0) 은 계산하지 않는다 */
  CHECK(slope_front_share(&CFG, 0.0f, 0.0f) < 0.0f);
  CHECK(slope_front_share(&CFG, 0.0f, -1000.0f) < 0.0f);

  /* 8. 무게중심이 가운데가 아니면 평지에서도 반반이 아니다: lr 250 · lf 150 -> 앞 0.625 */
  { slope_cfg_t k = CFG; k.lf_mm = 150.0f; k.lr_mm = 250.0f;
    CHECK(NEAR(slope_front_share(&k, 0.0f, 1000.0f), 0.625f));
    /* 그리고 뜨는 경계는 lr / h 가 정한다: 250 / 200 = 1.25 */
    CHECK(NEAR(slope_front_share(&k, 1250.0f, 1000.0f), 0.0f)); }

  /* 9. 넓은 범위를 훑어도 몫은 [0, 1] 안이고, f_fwd 가 클수록 줄어든다(같거나) */
  { float prev = 2.0f;
    for (int fx = -3000; fx <= 3000; fx += 50) {
      const float w = slope_front_share(&CFG, (float)fx, 1000.0f);
      CHECK(w >= 0.0f && w <= 1.0f);
      CHECK(w <= prev + 1e-6f);
      prev = w;
    } }

  /* 10. 저역 통과: alpha 0.5 로 0 -> 1000 을 세 번 */
  { float y = 0.0f;
    y = slope_lpf(y, 1000.0f, 0.5f); CHECK(NEAR(y, 500.0f));
    y = slope_lpf(y, 1000.0f, 0.5f); CHECK(NEAR(y, 750.0f));
    y = slope_lpf(y, 1000.0f, 0.5f); CHECK(NEAR(y, 875.0f)); }

  /* 11. 축 고르기: ±1 x · ±2 y · ±3 z, 0 = 없음 */
  CHECK(NEAR(slope_axis(1, 10.0f, 20.0f, 30.0f), 10.0f));
  CHECK(NEAR(slope_axis(-2, 10.0f, 20.0f, 30.0f), -20.0f));
  CHECK(NEAR(slope_axis(3, 10.0f, 20.0f, 30.0f), 30.0f));
  CHECK(NEAR(slope_axis(0, 10.0f, 20.0f, 30.0f), 0.0f));

  /* 12. 경사 비 = |f_fwd| / f_up, f_up <= 0 이면 판정 불가(-1) */
  CHECK(NEAR(slope_ratio(-500.0f, 1000.0f), 0.5f));
  CHECK(slope_ratio(100.0f, 0.0f) < 0.0f);

  /* 13. 히스테리시스: on 0.839(40°) · off 0.7 · 유지 3 ms */
  { const slope_hyst_cfg_t hc = { 0.839f, 0.7f, 3u, 0u, 0u };
    slope_hyst_t h = { false, 0u, 0u, 0u };
    CHECK(!slope_hyst_step(&h, &hc, 0.83f, 1u));          /* 문턱 바로 아래 */
    CHECK(slope_hyst_step(&h, &hc, 0.839f, 1u));          /* 같으면 들어간다 */
    CHECK(slope_hyst_step(&h, &hc, 0.75f, 1u));           /* 띠 안: 그대로 */
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));            /* off 아래 1 ms */
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));            /* 2 ms */
    CHECK(slope_hyst_step(&h, &hc, 0.75f, 1u));           /* 띠로 돌아옴 -> 다시 센다 */
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));
    CHECK(!slope_hyst_step(&h, &hc, 0.6f, 1u));           /* 이어서 3 ms -> 나옴 */
    h.on = true; h.below_ms = 0u;
    CHECK(slope_hyst_step(&h, &hc, -1.0f, 1000u)); }      /* 판정 불가: 마지막 상태 유지 */

  /* 14. 주행 불가 중 명령: 직진 · 내려가는 성분만 */
  { int16_t l, r;
    l = -200; r = -100; slope_clamp_downhill(500.0f, &l, &r);   /* 앞이 들림 -> 뒤로가 내려감, 평균 -150 */
    CHECK(l == -150 && r == -150);
    l = 200; r = 100; slope_clamp_downhill(500.0f, &l, &r);     /* 오르는 방향 -> 0 */
    CHECK(l == 0 && r == 0);
    l = -100; r = 100; slope_clamp_downhill(500.0f, &l, &r);    /* 제자리 회전 -> 0 */
    CHECK(l == 0 && r == 0);
    l = 120; r = 80; slope_clamp_downhill(-500.0f, &l, &r);     /* 앞이 숙여짐 -> 앞으로가 내려감 */
    CHECK(l == 100 && r == 100); }

  /* 15. 들림 판정 - 문턱 30 deg/s · 누적 5 deg · 거리당 40 deg/m · 풀림 3 ms, dt 1 ms */
  { const slope_lift_cfg_t lc = { 30.0f, 5.0f, 40.0f, 3u };
    slope_lift_t L = { false, 0.0f, 0.0f, 0, 0u };
    int i;
    /* (가) 턱: 60 deg/s 로 50 ms = 3 deg 에서 멈춤 -> 누적이 작아 없음 */
    for (i = 0; i < 50; i++) { slope_lift_step(&L, &lc, 60.0f, 0.0003f, 0.001f, 1u); }
    CHECK(L.lifted == 0);
    slope_lift_step(&L, &lc, 0.0f, 0.0003f, 0.001f, 1u);
    CHECK(!L.tracking);
    /* (나) 경사 진입: 40 deg/s 로 250 ms = 10 deg, 그동안 0.3 m 이동 -> 거리당 33 deg/m < 40 -> 없음 */
    for (i = 0; i < 250; i++) { slope_lift_step(&L, &lc, 40.0f, 0.0012f, 0.001f, 1u); }
    CHECK(L.lifted == 0);
    slope_lift_step(&L, &lc, 0.0f, 0.0f, 0.001f, 1u);
    /* (다) 들림: 60 deg/s 로 거의 제자리(1 mm/ms 의 1/10) -> 누적 5 deg 를 넘는 순간 +1 */
    for (i = 0; i < 90; i++) { slope_lift_step(&L, &lc, 60.0f, 0.0001f, 0.001f, 1u); }
    CHECK(L.lifted == 1);
    /* 풀림: 각속도가 문턱 아래로 3 ms */
    CHECK(slope_lift_step(&L, &lc, 0.0f, 0.0f, 0.001f, 1u) == 1);
    CHECK(slope_lift_step(&L, &lc, 0.0f, 0.0f, 0.001f, 1u) == 1);
    CHECK(slope_lift_step(&L, &lc, 0.0f, 0.0f, 0.001f, 1u) == 0);
    /* (라) 앞이 숙여짐 -> -1 */
    for (i = 0; i < 90; i++) { slope_lift_step(&L, &lc, -60.0f, 0.0f, 0.001f, 1u); }
    CHECK(L.lifted == -1); }

  /* 16. 히스테리시스 - 세는 동안의 튐: on 0.839 · off 0.7 · 유지 5 ms · 다시 셈 2 ms */
  { const slope_hyst_cfg_t hc = { 0.839f, 0.7f, 5u, 2u, 0u };
    slope_hyst_t h = { true, 0u, 0u, 0u };
    CHECK(slope_hyst_step(&h, &hc, 0.75f, 1u) && h.below_ms == 0u);   /* 세기 전의 띠: 세지 않는다 */
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));            /* off 아래 1 ms */
    CHECK(slope_hyst_step(&h, &hc, 0.75f, 1u));           /* 띠 1 ms(< 2) -> 계속 센다: 2 ms */
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));            /* 3 ms */
    CHECK(slope_hyst_step(&h, &hc, 0.6f, 1u));            /* 4 ms */
    CHECK(!slope_hyst_step(&h, &hc, 0.75f, 1u));          /* 띠에서 5 ms -> 나옴(튄 시간도 셌다) */
    h.on = true; h.below_ms = 0u; h.above_ms = 0u;

힌트 T1 — slope_front_share() · 앞축 수직항력의 몫

할 일 — 입력은 무게중심 cfg(h · l_f · l_r [mm])와 걸러진 가속도 두 성분 f_fwd · f_up(단위는 비만 쓰므로 [mg] 그대로). 출력은 앞축 몫 [0..1], 판정할 수 없으면 −1. 부르는 곳은 T9(틱마다 한 번)와 호스트 시험.

완결 코드

/* 완결 코드 T1 - User/Inc/Control/slope.h */
static inline float slope_front_share(const slope_cfg_t *c, float f_fwd, float f_up)
{
  const float L = c->lf_mm + c->lr_mm;
  if (f_up <= 0.0f || L <= 0.0f) { return -1.0f; }
  float w = (f_up * c->lr_mm - f_fwd * c->h_mm) / (f_up * L);
  if (w < 0.0f) { w = 0.0f; }
  if (w > 1.0f) { w = 1.0f; }
  return w;
}

코드 설명

  • L = lf + lr — 축간거리. 0 이하이면 키가 비어 있다는 뜻이라 계산하지 않는다(실제로는 가드가 먼저 막는다).
  • f_up <= 0 → −1 — 가속도가 0(샘플 없음)이거나 차체가 뒤집혔다. 그때 나누면 0 으로 나누거나 부호가 뒤집힌 몫이 나온다. 부르는 쪽(mix_weight())은 −1 을 "평지로 본다"로 읽는다.
  • (f_up * lr - f_fwd * h) / (f_up * L) — §2-10 ① 의 식 그대로. 질량이 없어도 되는 이유가 이 식에 있다(분자 · 분모의 g 가 약분된다).
  • [0, 1] 로 자르기 — 0 아래는 "앞바퀴가 이미 떴다", 1 위는 "뒷바퀴가 이미 떴다"는 뜻이다. 몫으로서는 0 과 1 이 끝이다.

힌트 T2 — slope_hyst_step() · 들어감 · 나옴이 다른 상태 하나

할 일 — 입력은 상태 h(켜짐 · 센 시간 · 세는 중 off 위에 머문 시간 · on 이상이 이어진 시간), 문턱 c(on · off · off_hold_ms · rearm_ms · on_hold_ms), 이번 비 ratio, 지난 시간 dt_ms. 출력은 갱신된 켜짐 여부. 경사 상태와 주행 불가가 같은 함수를 쓴다(T7).

완결 코드

/* 완결 코드 T2 - User/Inc/Control/slope.h */
static inline bool slope_hyst_step(slope_hyst_t *h, const slope_hyst_cfg_t *c, float ratio, uint32_t dt_ms)
{
  if (ratio < 0.0f) { return h->on; }
  h->on_ms = (ratio >= c->on) ? h->on_ms + dt_ms : 0u;
  const bool at_on = (ratio >= c->on) && (h->on_ms >= c->on_hold_ms);   /* on 이상이 이어졌다 */
  if (!h->on) {
    if (at_on) { h->on = true; h->below_ms = 0u; h->above_ms = 0u; }
    return h->on;
  }
  if (at_on) {                                 /* 경사로 돌아옴 - 처음부터 */
    h->below_ms = 0u; h->above_ms = 0u;
  } else if (ratio < c->off) {                 /* off 아래 - 센다 */
    h->below_ms += dt_ms; h->above_ms = 0u;
  } else if (h->below_ms > 0u) {               /* 세는 중에 off 위(띠) */
    h->above_ms += dt_ms;
    if (h->above_ms >= c->rearm_ms) { h->below_ms = 0u; h->above_ms = 0u; }   /* 이어짐 - 처음부터 */
    else { h->below_ms += dt_ms; }                                            /* 짧은 튐 - 계속 센다 */
  }
  if (h->below_ms >= c->off_hold_ms) { h->on = false; h->below_ms = 0u; h->above_ms = 0u; }
  return h->on;
}

코드 설명

  • ratio < 0 → 그대로 — T1 · slope_ratio() 가 판정할 수 없을 때 −1 을 준다. IMU 가 끊긴 동안 상태를 바꾸지 않는 것이 이 줄이다.
  • 꺼져 있으면 ratio >= on 이 on_hold_ms 이어질 때 켠다 — 경사 끝의 오목한 꺾임에서 앞바퀴가 바닥에 닿는 충격처럼 몇 ms 짜리 튐으로는 켜지지 않는다. 차체가 경사에 올라타는 데는 축간거리만큼 가는 시간(1 s 안팎)이 걸리므로 수십 ms 기다려도 버팀이 늦지 않다. 같은 값(= on)에서도 센다(벡터 13 의 둘째 줄 — on_hold_ms = 0 이면 그 틱에 켠다).
  • 켜져 있으면 ratio < off 로 내려간 때부터 센다(below_ms). 센 시간이 off_hold_ms 에 닿으면 끈다 — 경사 끝의 턱에서 잠깐 평평해진 순간을 평지로 보지 않게 하는 장치다.
  • 세는 중에 off 위(띠)로 올라가면 above_ms 에 그 시간을 모은다. rearm_ms 에 닿기 전이면 below_ms 도 계속 센다 — OFF 각 바로 아래 비탈에서 진동 · 요철로 비가 잠깐 off 위로 튀어도 세던 시간이 지워지지 않는다. 그렇지 않으면 튈 때마다 처음부터 세어 꺼짐이 계속 늦어진다.
  • off 위가 rearm_ms 이어지면 둘 다 0 — 정말로 다시 기울어진 것이다. on 이상이 on_hold_ms 이어지면 rearm_ms 를 기다리지 않고 0 — 경사로 돌아왔다. 그보다 짧게 on 위로 튄 것은 off 위의 짧은 튐과 같이 센다.
  • 세지 않는 동안 띠에서는 아무것도 안 바꾼다 — 이 띠가 없으면 문턱 근처에서 상태가 틱마다 깜박인다.
  • rearm_ms = 0 이면 off 위로 한 틱만 와도 처음부터 센다. 주행 불가(T7 의 s_nogo_cfg)는 rearm_ms · on_hold_ms 모두 0 을 쓴다.

힌트 T3 — slope_clamp_downhill() · 직진 · 내려가는 성분만 남긴다

할 일 — 입력은 걸러진 f_fwd(부호가 경사 방향)와 좌 · 우 목표 [mm/s](포인터 — 이 함수가 고쳐 쓴다). 주행 불가와 경사의 저전압에서 부른다(T8 의 3)).

완결 코드

/* 완결 코드 T3 - User/Inc/Control/slope.h */
static inline void slope_clamp_downhill(float f_fwd, int16_t *vl, int16_t *vr)
{
  int32_t v = ((int32_t)*vl + (int32_t)*vr) / 2;
  const int32_t down = (f_fwd > 0.0f) ? -1 : 1;
  if (v * down <= 0) { v = 0; }                    /* 오르는 방향 또는 0 */
  *vl = (int16_t)v;
  *vr = (int16_t)v;
}

코드 설명

  • ((int32_t)*vl + (int32_t)*vr) / 2 — 평균이 직진 성분이다. int16_t 둘을 그대로 더하면 C 는 int 로 올려 더하므로 이 보드에서는 넘치지 않지만, 넓은 형으로 바꿔 두면 다른 컴파일러에서도 같다.
  • down = (f_fwd > 0) ? -1 : 1 — 앞이 들려 있으면(오르막을 향함) 뒤로 가는 것이 내려가는 것이다.
  • v * down <= 0 → 0 — 오르는 방향이거나 0 이다. 곱의 부호로 "같은 방향인가"를 한 줄에 본다.
  • 두 목표에 같은 값 — 좌우 차이(회전)를 버린다. 경사에서는 돌지 않는다.
  • *vl 은 "포인터가 가리키는 값"이다. 함수가 값을 돌려주는 대신 부른 쪽의 변수를 고쳐 쓴다(출력 인자).

할 일 — 입력은 상태 l, 문턱 c, 피치 각속도 [deg/s](앞이 들리면 +), 이번 틱 이동 거리 [m], dt(초 · ms 둘 다). 출력은 0 / +1(앞이 들림 → 뒤축을 묶는다) / −1. 부르는 곳은 T7.

완결 코드

/* 완결 코드 T4 - User/Inc/Control/slope.h */
static inline int8_t slope_lift_step(slope_lift_t *l, const slope_lift_cfg_t *c,
                                     float rate_dps, float ds_m, float dt_s, uint32_t dt_ms)
{
  if (slope_absf(rate_dps) > c->rate_th_dps) {
    if (!l->tracking) { l->tracking = true; l->dpitch_deg = 0.0f; l->ds_m = 0.0f; }
    l->dpitch_deg += rate_dps * dt_s;
    l->ds_m       += slope_absf(ds_m);
    l->calm_ms     = 0u;
    const float a = slope_absf(l->dpitch_deg);
    if (l->lifted == 0 && a > c->dpitch_max_deg && a > c->dpitch_per_m_max * l->ds_m) {
      l->lifted = (l->dpitch_deg > 0.0f) ? 1 : -1;   /* 나눗셈 대신 곱 - 거리 0 에서도 정의된다 */
    }
  } else {
    l->tracking = false;
    if (l->lifted != 0) {
      l->calm_ms += dt_ms;
      if (l->calm_ms >= c->release_ms) { l->lifted = 0; l->calm_ms = 0u; }
    }
  }
  return l->lifted;
}

코드 설명

  • 각속도가 문턱을 넘은 동안을 한 구간으로 본다. 구간이 시작되는 틱에 누적 피치와 거리를 0 으로 되돌린다 — 앞 구간(예: 직전의 턱)의 값이 섞이면 경사 진입을 들림으로 본다(흔한 실수 표).
  • dpitch_deg += rate_dps * dt_s — 각속도를 적분해 이 구간에서 기운 각도를 쌓는다.
  • a > dpitch_max — 턱이 만들 수 있는 기울기보다 많이 기울었다.
  • a > dpitch_per_m_max * ds_m — "기운 각도 ÷ 간 거리"가 경사 진입의 값보다 크다를 곱으로 쓴 것이다. 나누면 거리 0(제자리)에서 0 으로 나누게 된다.
  • 한 번 서면 lifted 는 각속도가 문턱 아래로 release_ms 동안 이어질 때까지 유지된다 — 들린 차체가 잠깐 멈칫한 것을 풀림으로 보지 않는다.

힌트 T5 — mix_ff() · 속도 몫 표 보간

할 일 — 입력은 바퀴 하나의 표(n 점, 속도 오름차순)와 목표 속도 [mm/s]. 출력은 그 속도의 속도 몫 [permille], 부호는 목표를 따른다. 부르는 곳은 T8 의 4)(바퀴마다, 전압 보정 배율을 곱해 쓴다).

완결 코드

/* 완결 코드 T5 - User/Inc/Control/mix.h */
static inline float mix_ff(const mix_ff_table_t *t, float v)
{
  if (t->n == 0u || v == 0.0f) { return 0.0f; }
  const float s = (v < 0.0f) ? -1.0f : 1.0f;
  const float a = v * s;
  const uint8_t last = (uint8_t)(t->n - 1u);
  if (a >= t->v_mm_s[last]) { return s * t->duty[last]; }
  uint8_t k = 0u;
  while (k + 1u < t->n && a > t->v_mm_s[k + 1u]) { k++; }
  const float dv = t->v_mm_s[k + 1u] - t->v_mm_s[k];
  const float d  = (dv > 0.0f) ? t->duty[k] + (t->duty[k + 1u] - t->duty[k]) * (a - t->v_mm_s[k]) / dv
                               : t->duty[k];
  return s * d;
}

코드 설명

  • 표 없음(n == 0) 또는 목표 0 → 0 — 속도 몫이 0 이면 듀티는 PID 출력 그대로다(벡터 2 · 6). SLOPE_ENABLE 0 이 이 경로를 쓴다.
  • 부호 s 와 크기 a — 표는 전진 쪽만 잰다. 후진은 같은 크기에 부호만 반대다.
  • 마지막 점 이상이면 마지막 듀티에서 멈춘다 — 잰 범위 밖으로 직선을 늘리지 않는다. 모자라는 몫은 PID 가 맡는다.
  • while 로 칸 k 를 찾고 그 칸의 두 점 사이를 직선으로 잇는다. dv 가 0 이면(같은 속도를 두 번 적었다) 나누지 않는다.

힌트 T6 — mix_pid_limits() · 이번 틱의 PID 출력 범위

할 일 — 입력은 듀티 한계 limit, 속도 몫 ff, 가중치 w. 출력은 PID 의 out_min · out_max 에 넣을 범위. 부르는 곳은 T8 의 4).

/* 완결 코드 T6 - User/Inc/Control/mix.h */
static inline mix_lim_t mix_pid_limits(float limit, float ff, float w)
{
  if (ff >  limit) { ff =  limit; }
  if (ff < -limit) { ff = -limit; }
  if (w <= 0.0f)   { w = 1.0f; }
  const mix_lim_t r = { (-limit - ff) / w, (limit - ff) / w };
  return r;
}

코드 설명

  • 구조체를 값으로 돌려준다 — const mix_lim_t r = { lo, hi }; 처럼 중괄호로 칸 순서대로 채운다.

힌트 T7 — slope_layer_step() · 경사 층 한 틱

할 일 — 입력은 이번 틱의 바퀴 속도 넷 [mm/s]. 이 함수가 갱신하는 것은 파일 안의 상태다: 가중치 s_w[2], 경사 상태 s_on, 주행 불가 s_nogo, 들림 s_lift 와 묶음 상한 s_lcap[2], 상태 프레임으로 나갈 s_drive. 부르는 곳은 T8 의 2), 1 kHz ISR.

완결 코드

/* 완결 코드 T7 - User/Src/Control/control.c */
static void slope_layer_step(const float meas[NW])
{
  s_w[0] = 1.0f; s_w[1] = 1.0f;                                   /* 끔 · 판정 불가일 때의 값 = 평지 */
  if (!(SLOPE_ENABLE)) { s_drive = 0u; return; }

  imu_sample_t im;
  control_get_imu(&im, 0u);                                       /* 더블 버퍼 - ISR 에서 읽어도 찢어지지 않는다 */
  const uint32_t age = (uint32_t)(tick_get_ms() - im.tick_ms);
  const bool fresh = (im.seq != 0u) && (age <= (uint32_t)(IMU_TIMEOUT_MS));
  float rate_dps = 0.0f;
  if (fresh) {
    if (im.seq != s_imu_seq) {                                    /* 새 샘플일 때만 거른다 - 200 Hz 샘플을 1 kHz 로 다섯 번 거르지 않게 */
      const float alpha = 5.0f / ((float)SLOPE_LPF_TAU_MS + 5.0f);   /* dt = 5 ms (WT901 200 Hz) */
      s_fx = slope_lpf(s_fx, slope_axis(IMU_AX_FWD, im.ax_mg, im.ay_mg, im.az_mg), alpha);
      s_fz = slope_lpf(s_fz, slope_axis(IMU_AX_UP,  im.ax_mg, im.ay_mg, im.az_mg), alpha);
      s_imu_seq = im.seq;
    }
    rate_dps = slope_axis(IMU_GY_PITCH, im.gx_ddps, im.gy_ddps, im.gz_ddps) / 10.0f;   /* [0.1 deg/s] -> [deg/s] */
    const float wf = slope_front_share(&s_slope_cfg, s_fx, s_fz);
    const float wmin = (float)MIX_W_MIN_MILLI / 1000.0f;
    s_w[0] = mix_weight(wf, wmin);
    s_w[1] = mix_weight((wf < 0.0f) ? -1.0f : 1.0f - wf, wmin);
    const float r = slope_ratio(s_fx, s_fz);
    (void)slope_hyst_step(&s_on,   &s_on_cfg,   r, 1u);
    (void)slope_hyst_step(&s_nogo, &s_nogo_cfg, r, 1u);
  }                                                                /* 오래된 샘플: 가중치 1, 두 상태는 마지막 값 그대로 */

  float vmin = meas[0] < 0.0f ? -meas[0] : meas[0];               /* 가장 느린 바퀴 - 들림 중 헛도는 뒷바퀴에 속지 않게 */
  for (uint8_t i = 1u; i < (uint8_t)NW; i++) { const float a = meas[i] < 0.0f ? -meas[i] : meas[i]; if (a < vmin) { vmin = a; } }
  const int8_t lift = slope_lift_step(&s_lift, &s_lift_cfg, rate_dps, vmin * PID_DT_S / 1000.0f, PID_DT_S, 1u);

  if (lift != 0) {
    const uint8_t ax = (lift > 0) ? 1u : 0u;                      /* 앞이 들림 = 뒤축을 묶는다 */
    if (s_lift_prev == 0) {                                        /* 묶기 시작하는 틱: 지금 출력에서 시작 */
      const float a = s_u[2u * ax] < 0.0f ? -s_u[2u * ax] : s_u[2u * ax];
      const float b = s_u[2u * ax + 1u] < 0.0f ? -s_u[2u * ax + 1u] : s_u[2u * ax + 1u];
      s_lcap[ax] = (a > b) ? a : b;
    }
    s_lcap[ax] -= (float)LIFT_DECAY_PERMILLE_PER_MS;               /* 조금씩 내린다 */
    if (s_lcap[ax] < (float)LIFT_CAP_FLOOR_PERMILLE) { s_lcap[ax] = (float)LIFT_CAP_FLOOR_PERMILLE; }
  }
  s_lift_prev = lift;

  s_drive = (uint8_t)((s_on.on ? DRIVE_SLOPE : 0u) | (s_nogo.on ? DRIVE_NO_GO : 0u) | (lift != 0 ? DRIVE_LIFT : 0u));
}

코드 설명

  • slope_axis() — 펌웨어에는 WT901 축을 돌리는 코드가 따로 없으므로 키(IMU_AX_*)로 차체 기준 성분을 고른다. 자이로는 [0.1 deg/s] 라 10 으로 나눈다.
  • 앞 · 뒤 가중치 — 뒤 몫은 1 - wf 이다. wf 가 −1(판정 불가)이면 뒤에도 −1 을 넘겨 둘 다 1 이 되게 한다.
  • 두 히스테리시스에 같은 비를 넣는다 — 경사 상태(낮은 문턱)와 주행 불가(높은 문턱)는 문턱만 다르다.

  • 들림이 서는 틱(s_lift_prev == 0)에 묶을 축의 지난 PID 출력(s_u, T8 이 남김) 가운데 큰 쪽에서 상한을 시작한다. 지금 내고 있는 힘보다 갑자기 낮추면 그 순간 뒤로 밀린다. 그다음부터 틱마다 LIFT_DECAY 만큼 내리고 LIFT_CAP_FLOOR 에서 멈춘다.

/* 완결 코드 T8 - User/Src/Control/control.c */
void control_step_1khz(void)      /* 1 kHz ISR, 선점 우선순위 1 */
{
  const bool on_slope = s_on.on;                                  /* 지난 틱에 정해진 경사 상태 - 이 틱 안에서는 한 값으로 쓴다 */

  /* 0) 명령 워치독 (2-12). 경사에서는 적분을 지우지 않는다 - 지우면 P 항만 남아 미끄러진다 */
  const uint32_t age = (uint32_t)(tick_get_ms() - s_last_cmd_ms);
  if (age > CMD_WATCHDOG_MS) {
    s_target_packed = 0u;
    s_wd_stopped = 1u;

  }

  float meas[NW];
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) { meas[i] = (float)encoder_delta(i) * TICK_TO_MM_S; }

  /* 2) 경사 층 */

  /* 3) 목표 정리. 경사에서 버티는 조건이 서 있으면 목표 0(버팀), 저전압이면 내려가는 직진만, 주행 불가면 내려가는 직진만 */

  if (hold_ok_prev && (s_cond_prev & (uint8_t)~SAFE_BIT(SAFE_I_LOWBATT)) != 0u) { tl = 0; tr = 0; }     /* 워치독 · IMU · 보호 = 버팀 */
  else if (s_nogo.on || (hold_ok_prev && (s_cond_prev & SAFE_BIT(SAFE_I_LOWBATT)) != 0u)) { slope_clamp_downhill(s_fx, &tl, &tr); }

  /* 4) 바퀴마다: 속도 몫 + 가중치 x PID. PID 범위는 이번 틱의 속도 몫 · 가중치로 다시 잡는다 */
  const float limit = (float)DUTY_LIMIT_BENCH_PERMILLE;
  int32_t mv = 0;
  const bool v_ok = ina226_get_vbus_mv(&mv);
  const float k = (SLOPE_ENABLE) ? mix_vcomp((float)FF_VREF_MV, (float)mv, v_ok,
                                             (float)MIX_VCOMP_MIN_MILLI / 1000.0f, (float)MIX_VCOMP_MAX_MILLI / 1000.0f) : 1.0f;
  int16_t duty[NW];
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) {
    const int16_t tgt = (i & 1u) ? tr : tl;                         /* 짝수 = 왼쪽, 홀수 = 오른쪽 */
    const float   w   = s_w[i >> 1];                                /* 0,1 = 앞축 · 2,3 = 뒤축 */
    const float   ff  = (SLOPE_ENABLE) ? mix_ff(&s_ff[i], (float)tgt) * k : 0.0f;
    mix_lim_t lim = mix_pid_limits(limit, ff, w);
    if (s_lift.lifted != 0 && (i >> 1) == ((s_lift.lifted > 0) ? 1u : 0u)) {   /* 들림으로 묶은 축 */
      const float c = s_lcap[i >> 1] / w;
      if (lim.hi >  c) { lim.hi =  c; }
      if (lim.lo < -c) { lim.lo = -c; }
    }
    s_pid[i].out_min = lim.lo;
    s_pid[i].out_max = lim.hi;
    s_u[i]  = pid_step(&s_pid[i], (float)tgt - meas[i]);
    duty[i] = (int16_t)mix_duty(ff, w, s_u[i], limit);
  }

  /* 5) 1차 게이트: 지난 틱의 조건 · ARMED 아님 · EN LOW. 보호가 실제로 나갈 듀티를 보게 보호 앞에 둔다 */
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) {
    const bool cut_prev = (s_cond_prev != 0u) && !hold_ok_prev;
    if (cut_prev || !armed || (en_mask & (1u << i)) == 0u) {
      duty[i] = 0;
      pid_reset(&s_pid[i]);
    }
  }

  /* 6) 보호 넷 */
  uint16_t prot_bits = 0u;
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) {
    const int16_t tgt = (i & 1u) ? tr : tl;
    const protect_in_t in = { tgt, (int32_t)meas[i], duty[i] };
    if (protect_step(&s_prot[i], &s_prot_cfg, &in) != 0u) {
      duty[i] = 0;
      pid_reset(&s_pid[i]);
    }
    prot_bits |= (uint16_t)((s_prot[i].tripped & 0x7u) << (3u * i));
  }

  /* 7) 안전 판단 - 이번 틱의 보호 결과까지 넣는다 */
  const uint8_t cond = safety_step(age, prot_bits, on_slope);
  s_cond_prev = cond;

  /* 8) 2차 게이트: 이번 틱에 새로 선 조건까지. 경사에서 버틸 수 있는 조건이면 끊지 않는다(트립한 바퀴는 6) 에서 이미 0) */
  const bool hold_ok = on_slope && (cond & (uint8_t)~hold) == 0u;
  if (cond != 0u && !hold_ok) {
    for (uint8_t i = 0u; i < (uint8_t)NW; i++) { duty[i] = 0; pid_reset(&s_pid[i]); }
  }
  if (on_slope && tl == 0 && tr == 0 && armed) { s_drive = (uint8_t)(s_drive | DRIVE_HOLD); }

  /* 9) 출력 넷을 연달아 */
  for (uint8_t i = 0u; i < (uint8_t)NW; i++) { motor_set(i, (int16_t)(s_motor_sign[i] * duty[i])); }

  /* 10) step 포획 - 출력 뒤 */
  if (s_cap_left > 0u && s_cap_n < STEP_CAP_MAX) {
    if (s_cap_n == 0u) { s_cap_t0 = tick_get_ms(); }
    step_row_t *r = &s_cap[s_cap_n++];
    float m = meas[s_cap_wheel];
    if (m >  32767.0f) { m =  32767.0f; }
    if (m < -32768.0f) { m = -32768.0f; }
    r->t_ms   = (uint16_t)(tick_get_ms() - s_cap_t0);
    r->target = target_side(tgt_now, (uint8_t)(s_cap_wheel & 1u));
    r->meas   = (int16_t)(m + ((m >= 0.0f) ? 0.5f : -0.5f));
    r->duty   = duty[s_cap_wheel];
    r->prot   = s_prot[s_cap_wheel].tripped;
    --s_cap_left;
  }
}

코드 설명

  • on_slope 를 맨 앞에서 한 번 읽는다 — 이 틱 안의 워치독 · 게이트 · 안전 판단이 같은 값을 보게 한다. T7 이 이 틱에 바꾼 값은 다음 틱부터 쓰인다(1 ms 늦음).
  • 0) 워치독 — 목표 0 은 지금과 같다. pid_reset() 만 평지에서 한다.
  • 1) 엔코더 넷을 한 반복문에서 — 계산이 끼지 않으므로 네 값이 거의 같은 순간의 것이다.
  • 3) 목표 정리 — 지난 틱의 조건(s_cond_prev)으로 한다. 이번 틱의 조건은 7) 에서야 나오기 때문이다. 버틸 수 있는 조건만 서 있고(hold_ok_prev) 그 안에 저전압이 아닌 것(워치독 · IMU · 보호)이 있으면 목표 0, 저전압만이면 또는 주행 불가면 T3 으로 내려가는 직진만 남긴다.
  • 4) 바퀴마다 — 속도 몫(T5 × 전압 배율), 범위(T6), 들림으로 묶은 축이면 그 범위를 s_lcap ÷ w 로 한 번 더 좁힌다(묶음 상한은 듀티 단위, PID 출력은 w 를 곱하기 전 단위). mix_lim_t lim 에 const 를 붙이지 않는 이유가 이 좁힘이다(흔한 실수 표).
  • s_pid[i].out_min/out_max 를 pid_step() 앞에서 바꾼다 — 그래야 이번 틱의 포화가 이번 범위로 판정된다. s_u[i] 에 남긴 출력은 T7 이 들림이 서는 틱에 쓴다.
  • 5) 1차 게이트 — fw-18 의 게이트와 같은 자리 · 같은 이유다(보호가 실제로 나갈 듀티를 봐야 한다). 다른 점은 지난 틱 조건이 "경사에서 버틸 수 있는 것뿐"이면 끊지 않는 것 하나다.
  • 6) 보호 — 트립한 바퀴는 그 자리에서 0. 그리고 보호 비트를 이번 틱 값으로 모은다.
  • 7) safety_step(age, prot_bits, on_slope) — 셋째 인자로 경사에서 릴레이 차단을 미룬다(safety.c 의 바꿀 곳 (3)). 결과를 s_cond_prev 에 남겨 다음 틱의 3) · 5) 가 쓴다.
  • 8) 2차 게이트 — 조건이 서 있고 버틸 수 없으면(평지이거나, 과전류 같은 조건이 섞임) 넷 다 0. 보호가 트립한 바퀴는 6) 에서 이미 0 이고, 나머지 셋은 경사라면 버틴다.
  • DRIVE_HOLD — 경사 상태에서 두 목표가 0 이고 ARMED 면 버티는 중이다.
  • 9) motor_set() 넷을 연달아 — CCR 프리로드가 켜져 있어 넷이 거의 언제나 같은 PWM 갱신에 반영된다.
  • 10) 포획은 출력 뒤 — 출력 전의 일을 줄여 측정 → 출력 지연을 짧게 한다. LD3(빨강)는 safety_step() 이 켜고 끈다 — 옛 보호 블록의 LD3 줄은 옮기지 않는다.
  • 실습 C 와 합치기 — 실습 C 의 걸음 3 에서 PID 출력에 슬립 억제 계수 trac[i] 를 곱했다면, 4) 의 w 를 s_w[i >> 1] * trac[i](학습자가 붙인 이름)로 바꾸고 traction_step() 호출을 4) 앞에 둔다. 범위 계산도 같은 w 를 쓴다.

3-G-4. 굽고 보기 — 끈 채 같은지 보고, 재고, 켠다

drive_state 는 Pi 쪽에서 본다 — mcu_probe.py 의 상태 줄 끝 drive=0x..(bit0 경사 · bit1 주행 불가 · bit2 들림 · bit3 버팀), 또는 브리지의 /mcu/drive_state.

  1. SLOPE_ENABLE 0 으로 굽고 전과 같은지 본다. 실습 B 와 같은 step 명령으로 바닥 CSV 를 찍어 B 의 CSV 와 견준다 — 같은 모양이어야 한다(바뀐 것은 루프 순서뿐이다). stat 의 exec_us_max 를 벤치 기록 84 µs 와 견준다. drive=0x00 이다.
  2. 3-G-1 의 값을 채우고 SLOPE_ENABLE 1 로 다시 굽는다. 평지 정지 · 정속 주행에서 drive=0x00 이다(경사로 읽지 않는다). 같은 step CSV 를 한 번 더 찍는다 — 속도 몫이 들어가 오버슈트나 정착 시간이 달라졌으면 실습 B 의 방법으로 게인을 다시 본다.
  3. 경사판(약 10°)을 낮은 속도로 오른다. 판 위에서 bit0 이 1 이 되고, 평지로 나오면 SLOPE_OFF_HOLD_MS 뒤 0 이 된다. 판 위에서 같은 속도의 step 을 앞바퀴 하나 · 뒷바퀴 하나로 찍어 duty 열을 견준다 — 뒷바퀴가 더 크다.
  4. 버팀. 판 위에 멈춘 채 브리지의 송신을 멈춰 명령 워치독을 건다. 차체가 미끄러지지 않고 서 있고 bit3 이 1 이다. 그동안 adc 의 배터리 전류와 버틴 시간을 적는다. 10 s 가 지나도 전원이 내려가지 않는다(경사 상태). 판을 평평하게 내리면 경사 상태가 풀리고, 그때부터 10 s 뒤에 전원이 내려간다.

🤔 이해 확인

1. 속도 몫에는 가중치를 곱하지 않고 PID 출력에만 곱하는 이유는?

속도 몫은 바퀴를 그 속도로 헛돌리기만 하는 데 드는 듀티라서 하중과 상관없이 어느 바퀴든 필요하다. 거기에 가중치를 곱하면 가벼운 축의 바퀴가 목표 속도를 낼 듀티를 받지 못해 차체에 끌려가며 제동이 된다. 하중에 따라 달라지는 것은 바닥을 밀어 차체를 움직이는 힘이고, 그 몫을 PID 가 낸다. 그래서 가중치는 PID 출력에만 곱한다(§2-10 ②).

2. 들림 판정에 각속도 하나만 쓰지 않고 누적 변화와 거리당 변화를 더하는 이유는?

문턱을 넘을 때와 경사로에 들어설 때도 앞이 들리는 방향의 각속도가 생긴다. 각속도만 보면 그때마다 짐이 실린 뒤축을 묶어 차체가 멈칫한다. 문턱은 몇 도에서 멈추므로 누적 변화로 거르고, 경사 진입은 축간거리만큼 가면서 기울므로 거리당 변화로 거른다. 실제 들림은 거의 제자리에서 계속 기울어 셋을 다 넘는다(§2-10 ③).
